## GitHub 推送故障排查（17:38）

- 根因：仓库级 .git/config 存在空 proxy 行（http.https://github.com.proxy=，空值=强制直连），覆盖了全局 gitconfig 的 7897 代理；且会话环境变量代理指向死端口 58934。直连 github.com:443 被间歇性阻断。
- 修复：仓库级 proxy 设为 http://127.0.0.1:7897（实测 200）；推送时清掉死代理环境变量（env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY）。0362ce9 已推送，本地与 origin/main 同步。
- 注意：7897 是 Clash 代理端口，若以后代理关闭，push 会失败——届时 git config --unset http.https://github.com.proxy 恢复直连即可。
