## PRC-R2：方法审计（01:00–03:00）——结论 NO-GO

- **模拟器重建**（simulator_v2）：潜在预测 + 协议变换（cap/覆盖），符号反转来自"分段偏差 × 协议覆盖"交互而非改均值符号。四场景验证：A_dominant [+4.4,+0.8,+7.1,+4.9]、B_dominant 全负、sign_flip [−1.3,−0.7,**+18.6**,**−18.3**]、near_zero 全 |δ|<0.4。
- **条件 vs 无条件**：显式分离（条件=折/种子常数固定；无条件=零期望+每次重抽）。旧版 sigma_s=0 的运行不再被当作种子效应证据。
- **一致性检验**：E[δ̂] 比总体目标低 3-5%（δ≈7 时 bias −0.5，Jensen 效应）——真实存在，已记录。
- **覆盖率门槛未过**：band 覆盖 0.84-0.86（要求 0.93），即使 Bonferroni 分位也保守不足；根因是 basic bootstrap 无法校正随估计量放大的偏差。
- **IUT 完胜 PRC**：dominant 场景 IUT 89-93% 正确 vs PRC 23-31%（α/k 分割使 band 半宽 3.3，最小真值 0.79 永不显著）。四态 IUT 的拒绝域互斥 → 无需多重校正，FWER ≤ α 可证。**PRC 作为新推断方法 NO-GO**。
- 两个实现 bug 修复：决策规则（min<0 ≠ B 稳健）、dependence 检验（max/min 的 LCB/UCB 用反，导致 sign_flip 判 0%）。
- 残余价值：四态 IUT 框架（组合性创新）、条件/无条件区分（方法学要点）、协议变换模拟器（基础设施）、预算分配器（未验证）。

## CET 训练调试：三个致命结构缺陷（16:05–16:40）

- 40 epoch run 跑完（16:05 早停 ep17）：rmse_last **35.2**、cover90_last **0.15** —— 远不能与对照（10–14）相比。GPU 0% 是因为进程已结束，不是卡死。
- 三个致命 bug（每个单独都足以让模型失效）：
  1. **信念无法变尖**：倾斜用 12 个 raised-cosine 基函数覆盖 320 bin，每个跨 ~27 bin、log-LR 幅度 O(1)，最窄只能到 ~15 周期。改为显式 Student-t 似然头 (loc, scale) + 有界基函数残差。
  2. **门控有吸收态**：`gate=clip(temp*log_e/log(1/α),0,1)`，一旦撞到 0 下界梯度恒为 0，永久无法恢复。调试跑 ep2 起 gate=0，预测恒为 125.00。改为 2 参数 sigmoid 映射（θ0 init −1.5 → 0.18）。
  3. **高斯倾斜使 softmax 饱和**：−z² 在远端达 −4e4，全部质量塌到单一 bin、其余 bin 梯度为 0，一个 epoch 内 16.7→113。改为 Student-t（ν=4）重尾。

## CET 训练：七个缺陷与 NO-GO（16:40–17:20）

- 评价口径先修正：训练循环的 `rmse_last` 是在发动机真实失效周期算的（RUL≡0，恒预测 0 即得 0 分），无意义。新增 `scripts/cet_eval.py` 用项目截断协议（seed 2026）评估。
- 截断协议下最好的 checkpoint：**RMSE 29.5 / CRPS 45.6 / 90% 区间宽 145**（对照 CRPS 6.6–10.1），不可比。
- **训练中发现并修掉的 7 个缺陷**（每个单独都致命）：
  1. 证据头输出标量广播到基函数 → log 空间常数 → softmax 抹掉，gate 6 个 epoch 完全无效
  2. 赌注 λ 初值 0 → d(loss)/d(score)≡0 → gate 永不离开 0
  3. `clip(gate,0,1)` 是**吸收态** → ep2 起 gate=0，永远预测 125
  4. 高斯倾斜 −z² 远端达 −4e4 → softmax 饱和 → 一个 epoch 内 16.7→113
  5. 信念建在 **RUL** 上并逐步平移 → 宽先验平移 150 次后尾巴流进低 R 区（q[:6]=0.017、sd 35，而均值几乎正确）→ 改到**绝对失效时间 T**，存活条件化改为截断
  6. `to_rul` 把 age+R 截到末 bin → 数百个 R 混叠到同一 bin → 均值钉在水平线上
  7. 观测模型读 `e[:,t]`（已含 y_t）→ ŷ≈y → 创新恒为 0 → 改用 `e[:,t−1]` 做一步预测
- **残余失败是结构性的**：gate 恒等于 0.1345（std 1.5e-8），输入时间反转后预测只变 2e-5。机制是死锁——信念只通过 gate×tilt 依赖证据；gate≈0 ⇒ 证据通路无梯度 ⇒ direction 被 weight decay 压到 0 ⇒ score 恒 0 ⇒ gate 永不上升。常数下限不携带信息。全 BPTT 在 320–600 步上被梯度裁剪吃掉；截断 BPTT 反而删掉了唯一能推动信念的梯度（实测冻结在 125）。
- **判定：递归 600-bin 分布信念 + 乘性门控 这一参数化不可训练 → NO-GO**（paper/CET_TRAINING_FAILURE.md）。
- 下一代结构（下一步）：递归改为 **8–16 维紧凑状态**，分布由状态解码（discrete-hazard / Weibull 头，WTTE-RNN 式）；递推梯度路径短，生存语义保留在解码器里。
