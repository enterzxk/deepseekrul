## 条件覆盖审计的可检测性（主线，已提交 f169783）

上一轮 `CALIBRATION_DECISION.md` 留下的悬置项「条件覆盖审计的功效判据」已完成，
产出是 `paper/COVERAGE_AUDIT_RESULTS.md`（中文）与 `paper/COVERAGE_AUDIT_DRAFT.md`
（英文投稿草稿）。

**核心结论**：C-MAPSS 与 N-CMAPSS 上，按 RUL 分箱的「条件覆盖率是否达名义」这个
判决，在任何现有规模下都做不出来，包括把 C-MAPSS 全部 653 台合并之后。

**判据**：最小可检测偏离 δ*(n_b)，闭式解 + 4000 次蒙特卡洛验证（一致到 0.012）。
δ* ≤ 0.10 需 143 台/箱（5 箱 Bonferroni），即 715 台/测试集。C-MAPSS 给 100。

**命题 1**（关键）：n_b 数的是标签不是预测，所以 δ* 由基准与分箱边界固定，
与预测器无关。这条把限制从「某篇论文的问题」升级为「整类文献的结构限制」。

**实测 21 个单元**：
- C-MAPSS 12 cells：最小箱 11–29 台，δ* 0.23–0.46，同时下界 0.48–0.59，
  边际检验 12/12 不拒绝
- N-CMAPSS 9 fleets：175–384 行但设计效应 1.0–16.0，有效样本 2–3，δ* 0.55–0.87；
  忽略设计效应低估 δ* 中位 1.8 倍、最差 3.9 倍
- 合并 653：δ* 0.079–0.131，无任何 band 能被证明低于 0.90；
  最紧的 [50,75) 0.833，区间 [0.740, 0.904]

**能判定的是分布不是分段**：边际检验 0/12 拒绝，随机化 PIT 的 CvM 8/12 拒绝
（N-CMAPSS 9/9）。

## 第二轮：重标定上限（提交 e2393f6）

用户要求"必须有一个新的创新方法和好的结果"。系统试了 8 个重标定族（1–4 参数、3 种目标），
全部 dev 拟合 / test 评估，0/8 优于不矫正（mean|err| 0.0621 基线 vs 最好 0.0632）。

根因（实测，非假设）：dev 与 test 不可交换。KS(ŷ) p ≤ 0.008（4/4 显著），
KS(|误差|) 3/4 不显著 → 协变量漂移而非质量漂移；RUL 均值 dev 比 test 高 7.4–15.4；
PIT CvM dev/test = 7.9/4.4/41.6/8.4 倍。任何 dev 拟合的矫正都被放大。

第二个发现：整数端点覆盖把 PICP 抬高 0.014–0.024（90%）与 0.071–0.119（50%），
由网格与 125 处原子决定，与模型无关。同一批预测自报 0.929–0.935、实测随机化 0.790–0.857
→ 真实过度自信 0.078–0.141。

否掉的路线（都有数字，勿重复）：
- 决策代价轴：cens 距 oracle 仅 1.7–4.2%
- 三骨干池化：误差相关 0.85–0.94，池化差 5–8%
- N-CMAPSS 轨迹投影：末周期 RUL 恒为 0，标签由轨迹长度决定 → 泄漏（"50% 提升"是假的）
- dev 拟合决策偏移：test 上恶化 30–86%

下一步唯一有希望的正路：部署 K 折集成使校准集与部署模型同质量（CV+/jackknife+），
需在 A40 上跑 5 折 × 4 子集的重训并把折模型预测打到 test 上。
