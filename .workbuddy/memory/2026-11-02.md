## 条件覆盖审计的可检测性（主线，已提交 f169783）

上一轮 `CALIBRATION_DECISION.md` 留下的悬置项「条件覆盖审计的功效判据」已完成，
产出是 `paper/COVERAGE_AUDIT_RESULTS.md`（中文）与 `paper/COVERAGE_AUDIT_DRAFT.md`
（英文投稿草稿）。

**核心结论**：C-MAPSS 与 N-CMAPSS 上，按 RUL 分箱的「条件覆盖率是否达名义」这个
判决，在任何现有规模下都做不出来，包括把 C-MAPSS 全部 653 台合并之后。

**判据**：最小可检测偏离 δ*(n_b)，闭式解 + 4000 次蒙特卡洛验证（一致到 0.012）。
δ* ≤ 0.10 需 143 台/箱（5 箱 Bonferroni），即 715 台/测试集。C-MAPSS 给 100。

**命题 1**（关键）：n_b 数的是标签不是预测，所以 δ* 由基准与分箱边界固定，
与预测器无关。这条把限制从「某篇论文的问题」升级为「整类文献的结构限制」。

**实测 21 个单元**：
- C-MAPSS 12 cells：最小箱 11–29 台，δ* 0.23–0.46，同时下界 0.48–0.59，
  边际检验 12/12 不拒绝
- N-CMAPSS 9 fleets：175–384 行但设计效应 1.0–16.0，有效样本 2–3，δ* 0.55–0.87；
  忽略设计效应低估 δ* 中位 1.8 倍、最差 3.9 倍
- 合并 653：δ* 0.079–0.131，无任何 band 能被证明低于 0.90；
  最紧的 [50,75) 0.833，区间 [0.740, 0.904]

**能判定的是分布不是分段**：边际检验 0/12 拒绝，随机化 PIT 的 CvM 8/12 拒绝
（N-CMAPSS 9/9）。

## 第二轮：重标定上限（提交 e2393f6）

用户要求"必须有一个新的创新方法和好的结果"。系统试了 8 个重标定族（1–4 参数、3 种目标），
全部 dev 拟合 / test 评估，0/8 优于不矫正（mean|err| 0.0621 基线 vs 最好 0.0632）。

根因（实测，非假设）：dev 与 test 不可交换。KS(ŷ) p ≤ 0.008（4/4 显著），
KS(|误差|) 3/4 不显著 → 协变量漂移而非质量漂移；RUL 均值 dev 比 test 高 7.4–15.4；
PIT CvM dev/test = 7.9/4.4/41.6/8.4 倍。任何 dev 拟合的矫正都被放大。

第二个发现：整数端点覆盖把 PICP 抬高 0.014–0.024（90%）与 0.071–0.119（50%），
由网格与 125 处原子决定，与模型无关。同一批预测自报 0.929–0.935、实测随机化 0.790–0.857
→ 真实过度自信 0.078–0.141。

否掉的路线（都有数字，勿重复）：
- 决策代价轴：cens 距 oracle 仅 1.7–4.2%
- 三骨干池化：误差相关 0.85–0.94，池化差 5–8%
- N-CMAPSS 轨迹投影：末周期 RUL 恒为 0，标签由轨迹长度决定 → 泄漏（"50% 提升"是假的）
- dev 拟合决策偏移：test 上恶化 30–86%

下一步唯一有希望的正路：部署 K 折集成使校准集与部署模型同质量（CV+/jackknife+），
需在 A40 上跑 5 折 × 4 子集的重训并把折模型预测打到 test 上。

## 副线：鹈鹕骑自行车 SVG 动画（独立小交付）

按用户要求不使用 skill、不做测试，产出 `pelican_bicycle.html`（单文件，纯 SVG + CSS + SMIL）。

- 踩踏动作不是手调：用两段等长骨骼（54+54，髋 (440,310)，曲柄中心 (455,392)，半径 20）
  解 IK，按 24 等分采样，得到大腿/小腿相对角度序列，写成 SMIL `animateTransform`
  的 keyTimes/values；小腿组嵌在大腿组内、以膝点为旋转中心，即得精确啮合。
- 车轮、曲柄、脚踏（反向补偿保持水平）、链条 dashoffset、身体上下 3px 微颠（周期=曲柄半周）同步。
- 背景用重复图案平移实现无缝视差：云 1500px、远山 560px、近山 680px、路面虚线 90px。
- 注意：SVG 中嵌套旋转的旋转中心必须用**未变换的局部坐标**，否则关节会漂移。

## 第三轮：交叉拟合保形（提交见下）

协议 `paper/CVPLUS_PROTOCOL.md`（冻结 + 修正案 1 + Outcome），结果 `paper/CONFORMAL_RESULTS.md`。

**先补产物**：E21 在写盘前把 15 个折模型平均掉了，CV+ 需要的逐折 test 预测不存在。
`scripts/calx/dump_fold_test.py` 在 A40 上补出 60 个 CSV；15 个平均后与已发布预测差 2e-07，
这条校验是全部结论的前提。

**核心结果**：文献默认的**对称**带（`±q(|r|)`）在四个舰队一致过覆盖 0.95–0.98、宽度 41–60，
比参数化层宽 35–95%。换成**带符号残差分位数**（下/上臂各取 q05/q95）后覆盖 0.900–0.925、
宽度 29–37，与 66 参数层（30.3–32.0）持平；配对自助宽度差 95% CI 四舰队全部为正（省 18–34%）。
机制：残差下臂比上臂长 1.3–1.6 倍，对称带被迫按长臂两侧展开。**FD004 偏度为正但下臂仍更长**
（三阶矩被少数大正残差拉走）→ 该用分位数不要用矩。

**没守住的**：50% 水平上非对称也给 0.36–0.58（±0.14）。n=93–235 上 q25/q75 的抽样误差本身
±0.03–0.05。保形只在被构造的那个水平可证，不要跨水平外推。

**base 仍赢 Winkler 4/4**（36.7–50.0 vs 43.0–52.1）。层的位置头是真值钱，保形买到的是
"水平的舰队不变性"不是锐度。试过用层的位置做中心：反而更宽更差（FD001 38.8 宽、55.8）。

**发现并修正一个产物级坑（最重要）**：仓库里并存两份 66 参数层——
`experiments/cal/audit/*_A.npz`（`layer.LocationScale`，高斯，尺度 0.9）与
`experiments/cal/calibrators/calibrator_A.json`（`calibrate.CalibNet`，t5，尺度 1.2）。
同一批 653 台 test 上覆盖差 0.012–0.142（FD003 最大）。两份都自洽可复现，论文从没说清是哪份。
部署的是前者：20 个种子重拟合 sd 0.002–0.008，覆盖 0.924/0.869/0.932/0.842。
`RECALIBRATION_LIMITS.md` 的 0.79–0.86 与"过度自信 0.078–0.141"出自后者，已在文首加更正
（部署层的过度自信均值是 0.038）。0/8 的结论不受影响（同一对象内部比较）。
