# STG-MambaNet Ablation Protocol

Date frozen: 2026-10-20

## Variants

| Name | Spatial branch | Temporal branch | Loss |
|---|---|---|---|
| w/o A-GCN | independent per-sensor MLP | multi-scale selective SSM | PhysicsGuidedLoss |
| w/o SSM-Block | A-GCN | 2-layer LSTM | PhysicsGuidedLoss |
| w/o Physics Loss | A-GCN | multi-scale selective SSM | MSE |
| Full Model (Ours) | A-GCN | multi-scale selective SSM | PhysicsGuidedLoss |

The w/o A-GCN control removes inter-sensor graph propagation but retains a
learned per-sensor encoder and sensor pooling. The w/o SSM control replaces
the complete multi-scale selective state-space block with an LSTM of matching
input/output width. The w/o Physics control changes only the objective.

## Data isolation

- Official training engines are split into training and validation engines.
- Validation fraction: 20%, fixed independently for each seed.
- Min-Max statistics are fitted only on training engines.
- Validation and official test engines are transformed with training statistics.
- Training windows use length 30 and stride 1.
- Official test uses one final window per engine and original RUL labels.
- Test engines are never used for early stopping, checkpoint selection, or
  hyperparameter decisions.

## Training protocol

- Optimizer: AdamW
- Learning rate: 1e-3
- Weight decay: 1e-4
- Batch size: 256
- Maximum epochs: 80
- Early stopping: patience 20 on validation RMSE
- Gradient clipping: 1.0
- Checkpoint selection: lowest validation RMSE
- Test evaluation: once after loading the selected checkpoint

## Metrics

- RMSE
- NASA asymmetric score (sum over test engines)
- MAE
- Mean signed error (positive = late prediction)
- Late-prediction fraction
- Severe late-prediction fraction (error > 20 cycles)

## Seed handling

All variants for a given seed use the same engine split and DataLoader order.
Results are reported across all seeds without seed selection. The summary
reports mean, standard deviation, and per-seed paired differences against the
full model.

## Main command

~~~bash
python scripts/run_ablation.py \
  --subset FD001 \
  --seeds 42 67 123 \
  --variants wo_agcn wo_ssm wo_physics full \
  --epochs 80 --patience 20 --batch-size 256 \
  --num-workers 4 --device cuda
~~~

## Aggregating multiple run directories

~~~bash
python scripts/summarize_ablations.py \
  experiments/ablations/RUN_A experiments/ablations/RUN_B \
  --output-dir results/ablations_FD001
~~~

## Integrity rule

No ablation result is written into a paper table before the corresponding
metrics.json and per-engine predictions have been generated by the runner.
Expected or desired directions of effect are not treated as evidence.
