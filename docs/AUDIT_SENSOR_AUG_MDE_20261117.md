## 0. 结论

1. **clean 通道的 NO_GAIN 是「未检出」，不是「证明无效」**——和 schemes234 同一个问题。
   预注册门槛 +1.0pp（两子集平均），五个增强臂的**宏观 MDE80 是 3.83%–9.38%**，
   门槛比它低 **3.8–9.4 倍**。五个臂的宏观配对 |t| 全部 ≤ 1.76，一个都不显著。

2. **但有一个格子是显著劣化，报告目前只写了数值没写显著性**：

   > **G5 / FD001 = −1.605%**，配对 |t| = **13.74**（df=2，t_crit=4.3027），
   > 自身 MDE80 = **0.660%**。三个 seed 的配对劣化是 +1.79% / +1.53% / +1.49%，**方向与量级都一致**。

   这是本轮 clean 通道**唯一**可检出的效应，而且方向是负的。

3. **G4 的 −2.45% 宏观不能当效应**：它最大的单格 FD001 −3.754% 是 |t|=2.05、MDE 10.33%，
   三个 seed 的劣化是 −2.49% / −1.34% / −7.67%，**不稳定**；FD004 只有 −1.145%（|t|=0.62）。
   「最差子集 −3.75%」这个写法容易被读成已建立，实际没有。

4. **三个通道的检出力不一样，「NO_GAIN」的含义也不一样**（§4）：

   | 通道 | 宏观 MDE80 | 门槛 | 门槛 vs MDE | 结论 |
   |---|---:|---:|---|---|
   | clean | 3.83–9.38pp | 1.0pp | 门槛远低于 MDE | **检不出**，不能说无效 |
   | missing | 1.77–4.61pp | 10pp | 门槛远高于 MDE | 检出力充足 |
   | noise | 3.64–13.79pp | 10pp | 多数臂充足 | 检出力基本充足 |

   噪声通道有两个显著臂：**G2 +8.66%（\|t\|=5.82，达门槛 87%）**、**G5 +6.95%（\|t\|=6.83，70%）**。
   它们是真实的、可检出的鲁棒性收益，只是没到预注册的 10pp 实用门槛——
   和 clean 通道「什么都检不出」是两回事，论文不能写成一个「NO_GAIN」了事。

## 1. 口径

与 `reports/AUDIT_SCREEN_POWER_ZH.md` 完全一致，便于横向比较：

- **配对**：同一 seed、同一子集内配对（G0 − 臂），`gain% = 100·mean(d)/mean(G0)`，**正 = 增强臂更好**；
- **检出力**：精确非中心 t 的 80% 功效解，`MDE80 = λ·SE`，`df = n_seed − 1 = 2`，
  系数 **5.6535**（不是正态近似式的 5.2807，那个低估 7.1%）；
- **宏观量**：逐 seed 先算两子集增益的均值，再对 3 个 seed 做配对检验——因为预注册门槛
  「两子集平均 ≥1%」定义在宏观量上，不能拿子集 MDE 去比。

**与 `scripts/mde.py` 的区别**（同一提醒）：那个脚本是「逐发动机」口径（n=发动机数、正态 Z）；
本文是「逐 seed」口径（n=3、非中心 t）。两者回答不同问题，不能互相替代。

## 3. 唯一可检出格：G5 / FD001

| 臂 | 子集 | gain% | se% | MDE80% | \|t\| | t_crit | 显著 |
|---|---|---:|---:|---:|---:|---:|:--:|
| G5 | **FD001** | **−1.605** | 0.117 | **0.660** | **13.74** | 4.3027 | **是** |
| G5 | FD004 | +0.624 | 1.349 | 7.628 | 0.46 | 4.3027 | 否 |

逐 seed 配对（G0 − G5，RMSE；负 = 增强臂更差）：

```
s101: 11.317 - 11.520 = -0.203  (-1.79%)
s202: 11.470 - 11.645 = -0.175  (-1.53%)
s303: 10.705 - 10.864 = -0.159  (-1.49%)
mean: -0.179 / 11.164 = -1.604%
```

**三个 seed 全部为负、幅度 1.5%–1.8%**，se 只有 0.117%——这不是噪声。
换句话说：**Mask p=.10 + Noise α=.25 这个组合，在 FD001 上买到了一个可复现的 ~1.6% clean 代价。**

同时它在噪声通道是 **+7.02%**（CI [+3.81, +10.45]）。所以这个臂的真实画像是
**「用 FD001 上 1.6% 的干净精度，换噪声通道 7% 的鲁棒性」**，而不是「无效」。
FD004 上 clean 是 +0.624%（不显著），噪声通道点估计 +2.3%（CI 跨 0）——
**这个取舍是子集相关的**，不能推广成「增强总有 1.6% 代价」。

## 4. 缺失/噪声通道（补算，2026-11-17 追加）

脚本 `scripts/audit_sensor_aug_channels.py`，数据 `tmp/audit_sensor_aug/stage1_cells.csv`（37 行，逐 run）。

**先对齐口径**：报告里噪声通道的 `+8.73% / +7.02%` **不是**逐格百分比的均值。它的定义是

```
每个 (臂, 子集)：把 RMSE 对 seed 与三个档位一起平均
每个子集：gain = (G0_avg − arm_avg)/G0_avg
宏观：两个子集增益的平均
```

按这个定义复算得 G1 +5.326 / G2 +8.734 / G5 +7.018，与报告 +5.33 / +8.73 / +7.02 一致，
且 `noise123` 聚合值也对上（G0 FD001 15.180、FD004 16.984）。
**若按「逐格百分比再平均」算，会得到 G2 +6.91 / G5 +5.37——和报告差 1.8pp，那是口径不同，不是错。**

| G5 | FD001 | +12.674 | 3.184 | 3.98 | 否（差一点） | 18.002 | 0.70 |
| G5 | FD004 | +1.228 | 1.407 | 0.87 | 否 | 7.953 | 0.15 |

**结论：FD004 上的小增益不是「没有收益」，是「这套设计测不出」。**
FD004 的 MDE80 是 **3.50%–11.89%**，而观测到的增益只有 **1.2%–2.1%**——离可检出线差 3–6 倍。
报告 §0 那句「FD004 点估计 +2.3% 且 CI 跨 0，这不能反过来声称 FD004 没有收益」是对的，现在有数了。

**最强的单格是 G2/FD001：+15.192%，|t|=6.96，且超过自身 MDE80（12.343%，1.23 倍）。**
它在 FD001 上就已经超过 10pp 门槛的 152%，但 FD004 测不出来，所以**宏观 +8.66% 是「一个大效应 + 一个测不出的格子」的平均**，不是「中等效应在两个子集上一致」。
这也说明**「两子集平均」这个门槛结构本身对「只能在一个子集上测出来」的设计不利**——
下一轮若要评价鲁棒性，门槛应写成「每子集门槛 + 该子集的 MDE」，而不是先平均再比一个固定数。

**三个通道的检出力结论不一样，不能一概而论：**

| 通道 | 宏观 MDE80 | 门槛 | 门槛 vs MDE | 判定 |
|---|---:|---:|---|---|
| clean | 3.83–9.38pp | 1.0pp | 门槛远低于 MDE | **检不出门槛以下的效应** |
| missing | 1.77–4.61pp | 10pp | 门槛远高于 MDE | 检出力充足 |
| noise | 3.64–13.79pp（FD004 单格 3.50–11.89pp） | 10pp | 多数臂充足（G4 例外） | 检出力基本充足 |

所以「NO_GAIN」在三个通道里的含义**互不相同**：
**clean 是「这套设计检不出 1%」；missing 是「真的没到 10%」；
noise 是「FD001 上有可检出的大效应（G2 +15.2%），FD004 测不出」。** 论文必须分开写，不能合成一句。

**噪声通道的具体读法**：G2 的 +8.66% 显著、且达到门槛的 **87%**，G5 的 +6.95% 显著、达门槛 70%。
两者都是**真实的、可检出的鲁棒性收益，但都没到预注册的 10pp 实用门槛**。
报告 §0 那句「存在一个可检出但未达门槛的信号」是对的，现在有了区间与 MDE 支撑。

## 5. 对论文的影响

1. **不能只写「sensor-aug NO_GAIN」。** 准确写法是：
   「五臂在 clean 上均未检出宏观增益（宏观 MDE80 3.83%–9.38%，门槛 1.0pp）；
   G5 在 FD001 上检出 −1.6% 的显著劣化（|t|=13.74），在 FD004 上未检出；
   同一臂在噪声通道 +7.0%，构成一个子集相关的鲁棒性–干净精度取舍。」
2. **不能把 G4 的 −3.75% 写成已建立的劣化**（|t|=2.05，MDE 10.33%，seed 间不稳）。
3. **论文禁止承诺宏观口径结论**这条按通道分开适用：
   clean 通道宏观 MDE 3.83%–9.38pp，而五个臂的宏观效应绝对值最大只有 2.49%——**宏观均值不可报告**；
   missing/noise 通道的 MDE（1.77–4.61pp / 3.64–13.79pp）低于其 10pp 门槛，宏观量在那里是可报告的，
   但仍要报 MDE 与「未达门槛」的比值（G2 噪声 +8.66% = 门槛的 87%）。

## 7. 未解决

1. **G5/FD001 的 1.6% 代价没有机制解释**。它只在 FD001 出现（FD004 +0.62%），
   而 FD001 只有 100 台训练机、单工况；FD004 有 248 台、6 工况。

   所以「FD004 上没检出」这句话目前只能说「CI 跨 0」，不能说「MDE 不足」。
3. **G5 的 +6.95% 与 −1.605% 已确认同批**：两者都来自 `stage1_cells.csv` 的同一批 run
   （clean 列与 noise 列），逐 seed 可对齐；本轮已核。
