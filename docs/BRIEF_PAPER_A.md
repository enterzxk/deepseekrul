# 论文 A 技术简报：CQR 保形区间预测

> 用途：供独立评审方判断。所有数字均可从仓库 `docs/` 与 `experiments/` 复算。
> 撰写原则：只写有证据的，失败与限制全部列出。

## 1. 问题

C-MAPSS 涡扇发动机 RUL **区间预测**（不是点预测）。
给定传感器历史，输出一个区间 `[lo, hi]`，要求**边际覆盖率**接近名义水平（δ=0.1 → 90%）。

## 2. 方法

### 2.1 端到端双分位数训练

单个网络同时输出中心与半宽：
```
μ(x) = 中心头输出
s(x) = 半宽头输出（Softplus）
原始区间 = [μ - s, μ + s]
```

损失 = 归一化 pinball 损失 + 非对称惩罚（对晚预测更重）。

### 2.2 CQR 保形校准

在校准集上计算不符合分数 `E_i = max(lo_i - y_i, y_i - hi_i)`，
取 `q̂ = Quantile_{1-δ}(E)`，测试时区间扩张为 `[lo - q̂, hi + q̂]`。

**这是标准的 CQR（Romano et al. 2019），不是新方法。**

## 3. 创新点（诚实评估）

**作者自评：没有方法学创新。**

- 双分位数训练 + CQR 是已有构造
- 贡献限于：在冻结协议下，**CQR 相对常数宽度基线的经验效率收益**

**已被 Codex（L2）两次判定"不足以支撑 IEEE TIM"**，理由：
1. 自适应分位数回归 + 保形校准是既有 CQR 的核心构造，效率收益本身不建立新颖性
2. 相对 CRULP（IEEE TIM 2025，UACQR）等直接竞争工作无差异化
3. 分层/审计/条件覆盖这条线已被两个 2026 Zenodo 审计包占住

## 4. 实验协议

| 项 | 设置 |
|---|---|
| 数据 | C-MAPSS FD001–FD004 |
| 划分 | 5 折 engine-disjoint，训练发动机 80%/20% |
| seed | 42, 7, 13, 2024（4 个） |
| 格数 | 4 子集 × 5 折 × 4 seed = **80 格** |
| 名义水平 | δ = 0.1（90%） |
| 指标 | PICP（覆盖）、PINAW（宽度）、Winkler（综合） |
| 基线 | 常数宽度共形 / 点预测共形 / MC-Dropout 共形 / 分位数回归（不校准） |
| 跨域 | FEMTO/PRONOSTIA 轴承 6 个 |
| 官方 test | 封存，仅用于最终评估，不用于选择 |

## 5. 实验结果

### 5.1 主结果（名义水平 δ=0.1）

| 口径 | 结果 |
|---|---|
| **格级（80 格）** | **75/80 胜**，均值 **−10.22%**，中位 −11.30% |
| **折级（20 单元，seed 先平均）** | **20/20 胜**，均值 −10.22%，中位 −10.20% |

### 5.2 覆盖率是否匹配（关键）

| 子集 | CQR picp | 常数宽度 picp | 差 |
|---|---|---|---|
| FD001 | 0.9106 | 0.9114 | −0.08pp |
| FD002 | 0.8760 | 0.8803 | −0.43pp |
| FD003 | 0.9213 | 0.9348 | −1.36pp |
| FD004 | 0.8729 | 0.8710 | **+0.19pp** |

**覆盖差 ≤1.36pp，CQR 甚至略低 → 效率收益不是靠多覆盖换来的。**

### 5.3 逐机覆盖（平均达标掩盖单机失效）

| 子集 | 平均覆盖 | 引擎级最小 | 引擎 5% 分位 |
|---|---|---|---|
| FD001 | 0.908 | **0.421** | 0.481 |
| FD002 | 0.872 | **0.238** | 0.530 |
| FD003 | 0.926 | **0.493** | 0.542 |
| FD004 | 0.876 | **0.122** | 0.409 |

**FD004 最差发动机只有 12.2% 覆盖。**

### 5.4 跨域（FEMTO）

6 个轴承中 **5/6 胜**，均值 **−12.2%**（唯一败绩 Bearing2_2：0.75 vs 0.69）。

### 5.5 消融

| 消融 | 结果 |
|---|---|
| A4 置换 σ_T（先验不确定性） | **+0.25%，11/20 折变差** → **σ_T 冗余，不是有效机制** |
| 局部化 CQR | 40 格上无收益，FD003 +11.7% → 推翻 |
| 宽度缩放 a≠1 | a=1 最优 → 推翻 |
| 分层 / Mondrian | 全部更差 |
| 引擎级校准 | 等价于放宽区间 |
| 非对称校准 | 最优=对称 |
| seed 集成 | n=2 有效，n=4 退化 |

### 5.6 统计严谨性

- 基线冻结：`scripts/freeze_audit.py` **50/50 断言通过**
- 噪声底线：两遍独立抽样，|Δ| 中位 0.63pp、p90 3.20pp、**方向翻转 0/80**
- seed 方差：折内占 **46.8%**
- **限制**：80 格非独立（4 seed 共用同一 5 折划分）；20 折也不是 20 个独立样本（交叉验证训练集重叠）→ 只能描述性陈述
