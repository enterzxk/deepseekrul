## 2. 四个候选缺口（按"可检验 + TIM 相关 + 未被占"排序）

### G1（最强）**右删失下的保形 RUL**
现场数据的发动机大多**未观测到失效**（C-MAPSS 的测试单元就是截断轨迹）。
现有保形 RUL 工作全部假设"标签=真实 RUL"；一旦单元在观测窗内未失效，标签是**删失**的，
直接回归会把"至少还剩这么多"当成"正好这么多"→ 系统性低估 RUL、区间偏移。

- **可检验**：在训练折上**人为截断**轨迹（删失比例 0/25/50/75%），比较标准 CQR 与删失感知方法的覆盖与偏差。
- **TIM 相关**：现场测量窗口有限是仪器与运维的现实约束。
- **空位**：conformalized survival 处理删失但不含退化动力学；RUL 文献不处理删失。**两者的交集看起来是空的**。
- **风险**：需要核实是否已有"censored conformal RUL"（外部通道恢复后第一件事）。

### G2 **有效性代价的量化**
"要让 RUL 区间在单位级有效，需要多宽？"——C 的合成结果显示至少 1.5 倍。
作为**测量学结论**有价值，但作为方法贡献不足。

### G3 **故障条件下的覆盖包络**
A 的失败在于方差分解不可识别；但"检测故障传感器并降权"是另一条路（故障指示可由重建误差直接估计）。
风险：工程模式成熟，创新度可能不足；且需外部检索确认占位。

### G4 **单位级证书**
给定 $n$ 台校准发动机，能对多少比例的发动机保证覆盖 ≥1−α？这是"certificate"问题，
与 DriftGuard 的边际边界不同，但需要新的有限样本理论，超出 2–3 周可完成的范围。

## 4. G1 的实测前提（2026-11-09，`scripts/censoring_pilot.py`）

模拟：把校准集中"在观测窗结束时仍未失效"的发动机当作删失并丢弃（现场最省事的做法），
在冻结 CQR 预测上测覆盖与 Winkler（4 子集 × 5 折，seed 42，0 GPU）。

| 保留比例 $\tau$ | 校准发动机数 | PICP | ΔPICP | Winkler 变化 |
|---|---|---|---|---|
| 1.00（无删失） | 10.8 | 0.8958 | — | — |
| 0.75 | 7.8 | 0.9036 | +0.79 pp | +2.78% |
| **0.50** | **5.7** | **0.9181** | **+2.23 pp** | **+5.10%** |
| 0.25 | 3.0 | 0.9246 | +2.88 pp | **+11.40%** |

**结论**：删失 + 丢弃的失败模式是**过度保守**（区间变宽 5–11%），不是覆盖崩塌。

**机制（可解释）**：标签按 clip125 截断，长寿命发动机有大量 RUL=125 的平台窗口，
模型在这些窗口上残差很小；丢弃它们等于把低分样本从校准集移除 → 分位数抬高 → 区间变宽。
这是**截断标签协议与删失的交互**，是 C-MAPSS 协议本身的产物，值得写进论文。

**对 G1 的意义（比原设想更强）**：
- 问题真实存在，且**代价可量化**（τ=0.5 时 Winkler +5.1%，τ=0.25 时 +11.4%）；
- 修复方向明确：用删失单元的部分信息（生存分析式重加权 / 下界约束）替代"直接丢弃"，
  目标是**把丢掉的效率拿回来**——这是 TIM 喜欢的"性能 + 能力"双叙事，而不是 C 的"有效但更宽"。

**风险**：τ=0.25 只剩 3 台校准发动机，极端；主实验应以 τ∈{0.5, 0.75} 为主。
**下一步**：外部通道恢复后先查 "censored conformal RUL" 占位；若空位成立，写 G1 的两天设计门。

### 4.1 clip-aware 修复的原型验证（2026-11-09）

机制假设：标签截断在 125，所以删失发动机的早期窗口（$t\le c^*-125$）标签其实是**已知的 125**，
丢弃整台发动机等于扔掉这些已知样本。原型：保留这些窗口，只丢真正未知的部分。

| $\tau$ | 朴素丢弃 PICP / Winkler | clip-aware PICP / Winkler |
|---|---|---|
| 0.75 | 0.9036 / +2.78% | 0.8935 / +2.02% |
| **0.50** | 0.9181 / +5.10% | **0.8998** / +4.90% |
| 0.25 | 0.9246 / +11.40% | 0.9044 / +11.19% |

**结论（如实）**
- **覆盖偏差可修**：τ=0.5 时 PICP 从 0.9181 回到 0.8998（偏差 +2.23 pp → +0.40 pp）；
- **效率不可回收**：Winkler 仅从 +5.10% 降到 +4.90%（判据要求至少减半 → **NO**）。
  效率损失主要来自**可用校准发动机变少**（10.8 → 5.7），不是来自偏差本身。

**对 G1 定位的影响**：G1 目前只能主张**有效性/正确校准**（删失下不再过度保守），
不能主张性能回收。这与候选 C 的处境相似：**能力成立、性能故事弱**。
若 L2 认为 TIM 需要性能优势，则 G1 与 C 都需要重新设计评分/估计，或转 G3。
