## 1. 候选 C1：面向维护决策的保形风险控制（CRC-RUL）

**问题（一句话）**：区间方法的评价口径是覆盖率，但维护决策要控制的是**成本**；
90% 覆盖不能推出期望成本上界，而单机级覆盖又不可认证（D021 的结论）。

**机制**：把区间膨胀量 λ 当作决策变量，定义单调损失
ℓ(λ) = c_PM·1[提前更换] + c_CM·1[漏换致失效] + c_early·提前量，
用 conformal risk control（Angelopoulos et al., ICLR 2023）选 λ，使
E[ℓ] ≤ τ 有有限样本保证（引擎级可交换）。技术难点：非对称成本下损失对 λ **不单调**，
需要构造单调包络或分段单调的替代损失——这正是可写成公式、可单独消融的机制点。

**为什么不是已知工作的重排**：CRC 的原始形式要求损失对集合大小单调；RUL 的非对称成本
（漏换 ≫ 早换）破坏了单调性。若能把"非对称成本 → 单调包络 → 保证"这条链写清楚，
它是一个**新的估计量**，不是"把 CRC 套到 RUL 上"。

**判定门（预注册）**：
- G1：在 80 格上，CRC 选出的 λ 在留出引擎上的**实现期望成本** ≤ τ 的比例 ≥ 90%（名义 1−δ，δ=0.1）。
- G2：在相同实现覆盖率下，CRC 的期望成本低于固定 α 的 CQR（配对，折级 n=20）。
- G3：把非对称成本换成对称成本，方法退化为标准 CRC（正确性自检）。
- 失败分支：若 G1 不达标，说明引擎级可交换性被破坏，结论收窄为"需多少校准引擎"的边界分析。

**风险**：CRC 本身是成熟工具；**必须先查新**是否存在 maintenance/RUL 的 CRC 工作。
本次快速检索未发现直接对应项，但未穷尽。

## 2. 候选 C2：骨干迁移下区间结论的稳健性（H-TRANSFER）

**问题**：我们所有区间结论都来自 IDA-PE 一个骨干；四篇 TIM 点预测论文说明骨干差异极大。

**机制**：不是新方法，是**受控实证**——把同一套 split conformal + CQR 校准套到 2–3 个
不同容量的骨干（LSTM / 小 Transformer / IDA-PE），同划分同协议重跑 80 格。

**判定门**：若"边际达标但单机覆盖 0.12–0.49"与"尺度异质性"在三个骨干上方向一致 →
区间结论是方法层的；若翻转 → 必须限定到具体骨干。

**定位问题**：它是**支撑性证据**，不构成 TIM 要的方法创新；只能作为 C1 论文里的一个节，
不能单独成稿。

## 3. 候选 C3：把"不可认证"变成可操作的弃权规则（abstain-CRC）

**问题**：部署时若某台发动机的区间不可信，正确动作是**拒绝出区间**并转人工，
而不是给一个覆盖 0.12 的区间。

**机制**：在 C1 的框架上加一个弃权动作，使
E[成本 + c_abstain·1[弃权]] ≤ τ，并保证弃权率 ≤ ρ。
这在形式上把 selective prediction 的风险控制与保形结合。

**风险**：RESS 2026 similarity-CP 已有 holds/violated/indeterminate 三态诊断，
位置接近；若查新显示其已含成本控制，则 C3 并入 C1 或放弃。

## 4. 建议的裁决顺序

1. 先查新 **C1**（CRC + maintenance/RUL + 非对称成本）——这是唯一同时满足
   "正向方法""有有限样本保证""与已占空间不重叠"的候选。
2. C3 作为 C1 的扩展，若 C1 成立再考虑。
3. C2 只作 C1 的支撑实验，不单独立项。

**交 L2 的三个问题**：
- Q1：C1 的"非对称成本破坏单调性"是否构成足够的方法贡献，还是会被判为"CRC 的应用"？
- Q2：若 C1 被判不足，是否退回 C2（受控实证）作为 TIM 稿的主贡献？还是承认当前无 TIM 级方法贡献？
- Q3：C3 与 RESS similarity-CP 的重叠是否已使其不可行？
