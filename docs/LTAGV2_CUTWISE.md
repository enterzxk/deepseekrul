## 2. 结论

1. **LS-ctx 的优势集中在早期 cut（0.40–0.55）**，在 0.95 上：
   - FD001：K1-Calib 最好（3.322），LTAG 3.437，LS 3.705；
   - FD002：**LTAG 最好**（2.942），LS 3.534；
   - FD003：LS 最好（4.395），LTAG 4.671；
   - FD004：**LTAG 最好**（3.459），LS 4.310。
2. **validation 均值掩盖了 cut 组成**：早期 cut 误差大、权重大，LS 的均值优势主要来自那里。
3. **test 是 end-of-life 单窗口**，更接近 cut 0.95；LTAG 的 test +0.39 与 late-cut 表现一致，
   不与“validation 均值 LS 更好”矛盾。
4. 因此：
   - **选项 A（LS-ctx 主方法）证据弱**：它在 test-like cut 上并不占优；
   - **选项 B（LTAG test 主 + 分 cut 对照）更诚实且更有解释力**；
   - 论文应报告分 cut 表，而不是只报 validation 均值。

## 3. 对论文叙事的修正

- 不能写“LS-ctx 全面优于 LTAG”；只能说“LS-ctx 改善早期 cut 的 RMSE，但在 end-of-life
  上 LTAG/K1-Calib 更稳”。
- LTAG 的贡献应定位为 **end-of-life 的推理期门控**；早期 cut 的校准是另一个问题。
- 这解释了 test +0.39 与 validation 均值的表面矛盾，是论文的一个诚实卖点（cut-dependent）。
