# LTAG v3 Phase 3：机制与指标分析（post-hoc）

> 日期：2026-11-21。对象：Phase 1 的 LS-ctx（p_k1 + p_med + context 的 ridge 后校准）。
> 目的：回答“增益是不是常数偏差/尾部刷分”。**test 封存；validation only。**

## 1. K1 + 常数偏差

在训练发动机上拟合常数 b，最小化 engine_mean RMSE；再应用到验证集。

| subset | K1 | K1+b（b） | LS-ctx |
|---|---:|---:|---:|
| FD001 | 11.865 | 11.890（−1.2） | **9.735** |
| FD002 | 11.527 | 11.470（−1.2） | **10.677** |
| FD003 | 12.793 | 12.528（−1.2） | **11.939** |
| FD004 | 13.608 | 13.523（−1.2） | **13.108** |

- 常数偏差只带来 0–0.27 的改善；**LS-ctx 的 1.1–2.1 增益不是常数偏差**。
- 最优 b 都是 −1.2，说明 K1 系统性高估；但只修正偏差不够。

## 2. 尾部误差分析（Δ|e| = |e_LS| − |e_K1|，负 = LS 更好）

按 K1 绝对误差分位（0–50%、50–90%、90–100%）：

| subset | 0–50% | 50–90% | 90–100% |
|---|---:|---:|---:|
| FD001 | +0.86 | −1.05 | **−13.00** |
| FD002 | +0.86 | −1.17 | **−5.65** |
| FD003 | +0.47 | −1.27 | **−5.51** |
| FD004 | +1.14 | −1.49 | **−3.27** |

- LS-ctx **牺牲小误差、集中改善大误差尾部**；这是典型的 RMSE 导向校准。
- 这解释了为什么 RMSE 大幅改善，而 MAE 改善较小；也意味着在小误差样本上 LS-ctx 更差。

## 3. 偏差与 NASA

FD001 例：

| arm | engine_mean | MAE | bias | NASA late | NASA early |
|---|---:|---:|---:|---:|---:|
| K1 | 11.865 | 8.936 | +0.876 | 0.659 | 2.393 |
| K1+b | 11.890 | 9.005 | −0.324 | 0.774 | 2.069 |
| LS-ctx | **9.735** | **7.645** | **−2.208** | 0.790 | **0.584** |

- LS-ctx 把偏差从 +0.88 推到 −2.21；NASA early（高估项）大幅下降，但 bias 更负。
- 这不是“只刷 NASA 高估项”，MAE 也改善；但 bias 变差需要在论文中说明。

## 4. 结论

1. **LS-ctx 的增益不是常数偏差**；它来自 context 条件化的尾部校准。
2. **增益集中在 90–100% 大误差尾部**；小误差样本变差（+0.47 到 +1.14）。
3. 这是“RMSE 导向的后校准”，机制上不新；论文若写，必须同时报告尾部/小误差的 trade-off 与 bias 变化。
4. 指标口径注意：Phase 3 用 per-seed rows（每个 engine×cut 有 3 seeds），Phase 1b 用 seed-ensemble；
   两者 LS-ctx 数值不同（9.735 vs 9.256），不得混在同一列。
5. 由于 Gate 1 已 FAIL，本分析只用于决定“后校准是否值得写”，不用于推进 Phase 2。
