## 4. 论文可写的诚实叙事（选项 B）

1. **主结果**：LTAG 在 B0 test 上 15/15，平均 +0.39 RMSE；相对 K1/Median 稳定。
2. **机制边界**：validation 上 K1-Calib/LS 更强；LTAG 的“学习门控”不是最优聚合器。
3. **负结果**：RHSE-TSH 删除（公平 R5b/R5m 在 bias/drift 追平/超过 R3）。
4. **贡献定位**：不是“新 SOTA 聚合器”，而是“年龄对齐多窗口 + 推理期门控的系统性证据，
   以及何时不该用学习门控”。
5. 若审稿人要求方法创新，这篇更适合短文/负结果报告；IEEE TIM 正刊风险高。
