## 1. 误差恒等式（修正版）

记号：清洁窗口 $x$，扰动 $\varepsilon_\nu\sim(0,\nu^2\Sigma)$，部署观测 $z=x+\varepsilon_\nu$，
预测器 $\mu$，$r_0=y-\mu(x)$，$d_\nu=\mu(x+\varepsilon_\nu)-\mu(x)$，
$b_\nu(x)=\mathbb E[d_\nu\mid x]$，$v_\nu(x)=\mathrm{Var}[d_\nu\mid x]$。

条件于 $(x,y)$ 并对 $\varepsilon$ 取期望：

$$\boxed{\ \mathbb E\big[r_\nu^2\mid x,y\big]=r_0^2-2r_0b_\nu+b_\nu^2+v_\nu\ }$$

- $v_\nu\ge0$：扰动**总是**增加方差；
- $b_\nu^2\ge0$：偏移也增加二阶矩；
- $-2r_0b_\nu$：唯一可**减少**期望平方误差的项——当 $r_0$ 与 $b_\nu$ 同号时。
  这解释了为什么"清洁方差 + $\nu^2$·单位方差"会**高估或低估**，取决于 $\mu$ 在噪声下的偏移方向。

**反例（为什么不能乘 $\nu^2$）**：$\mu(t)=t^2$、$x=0$、$\varepsilon\sim N(0,\nu^2)$ ⇒ $v_\nu=2\nu^4$，
而"单位噪声方差 × $\nu^2$"给 $2\nu^2$。**两者一般不等**，故必须逐 $\nu$ 估计。

## 2. 可部署估计量（回答"部署时没有清洁锚点"）

部署时只有 $z$。因此**估计对象定义为**

$$\sigma_\nu^2(z)\;=\;\mathbb E\big[(y-\mu(z))^2\ \big|\ z\big],$$

即"在观测到 $z$、且已知噪声等级 $\nu$ 的条件下，残差平方的条件期望"。它**只依赖可观测的 $z$ 与 $\nu$**。

**监督信号（训练期可构造）**：训练时有清洁 $x$ 与标签 $y$；抽样 $\varepsilon\sim P_\nu$ 得 $z=x+\varepsilon$，
直接计算 $r_\nu=y-\mu(z)$。于是 $\sigma_\nu^2$ 可用 NLL 在**模拟的带噪残差**上直接训练——
不需要在部署时知道 $x$，也不需要恒等式。

**恒等式的作用**（这是与"直接噪声增强"的区别）：它给出一个**跨测量质量的约束**，
把数据稀缺的带噪区间与数据充足的清洁区间联系起来（见 §3）。

## 3. 技术机制：恒等式约束的尺度迁移（ICST）

在清洁区间我们能用大量样本估出 $\hat\sigma_0^2(x)$；在带噪区间，同一 $x$ 的带噪版本样本少、方差大。
恒等式给出二者的一阶关系：

$$\mathbb E[r_\nu^2\mid x]=r_0^2-2r_0b_\nu+b_\nu^2+v_\nu .$$

取条件期望并写成尺度形式：

$$\sigma_\nu^2(x)\;\approx\;\sigma_0^2(x)\;-\;2\,\mathbb E[r_0b_\nu\mid x]\;+\;b_\nu^2(x)\;+\;v_\nu(x).$$

- $\hat b_\nu(x)$、$\hat v_\nu(x)$ 由**冻结的 $\mu$** 做 $K$ 次扰动前向的 MC 估计（无标签、无梯度回传）；
- $\hat\sigma_0^2(x)$ 由清洁残差 NLL 得到；
- 交叉项 $\mathbb E[r_0b_\nu]$ 用训练期的**配对样本** $(x,\ y)$ 估计（只在训练期可得，部署不需要）。

**损失**

$$\mathcal L=\underbrace{\mathcal L_{pinball}+\lambda_1\mathcal L_{NLL}^{clean}}_{\text{基础}}
+\underbrace{\lambda_2\mathcal L_{NLL}^{noisy}(\sigma_\nu(z))}_{\text{直接监督}}
+\underbrace{\lambda_3\big\|\sigma_\nu^2(z)-\big[\hat\sigma_0^2(x)-2\widehat{r_0b_\nu}+\hat b_\nu^2+\hat v_\nu\big]\big\|_1}_{\text{恒等式约束（ICST）}} .$$

**为什么这不是"多一个损失"**：ICST 把带噪尺度的估计**锚定**到清洁尺度的可识别量上，
并显式包含偏移与交叉项；去掉它，带噪尺度只能靠模拟样本单独拟合（数据效率低、方差大）。
**消融预测**：去掉 ICST 后，带噪区间的尺度估计方差上升、P3 误差变大——这是可检验的。

## 4. 保形层：单一全局阈值 + 可检验的稳定性条件

**分数**：$s_\nu=\dfrac{|y-\mu(z)|}{\hat\sigma_\nu(z)}$。

**主方案（单一 $q$）**：在校准集上按部署噪声**混合分布** $\pi(\nu)$ 抽样扰动，得到 $\{s_i\}$，
取 $k=\lceil (n+1)(1-\alpha)\rceil$，$\hat q=s_{(k)}$（$k>n$ 时取 $+\infty$ 并报告）。
在**有效可交换采样单位**（发动机级重采样，不把重叠窗口当独立）下，标准 split-conformal 给出
混合分布上的边际覆盖 $\ge1-\alpha$。

**逐 $\nu$ 覆盖的充分条件（本方法声称的技术结果）**：
若标准化分数满足**随机占优** $F_\nu(t)\le F_{\nu'}(t)$ 对所有 $t$ 与 $\nu\le\nu'$ 成立，
则单一 $\hat q$ 在**所有** $\nu\le\nu_{\max}$ 上仍满足 $\mathbb P(s_\nu\le\hat q)\ge1-\alpha$。
这是可检验的：在留出引擎上逐 $\nu$ 估计 $F_\nu$ 并做占优检验；**若不成立，报告违反的 $\nu$ 区间**，
退化为逐 $\nu$ 校准（作为对照，不宣称创新）。

**不声称**：发动机级条件覆盖；扰动机制失配下的保证。
