# C4 查新结论：关闭

> 时间：2026-11-10 00:05。对象：`docs/NOVELTY_CHECK_C1.md` §3 提出的 C4
> （以置信度 1−δ 保证"至多 β 比例的发动机单机覆盖 < 1−α"）。
> 执行范围：L2（Codex，threadId `01a1c0f1-14b5-75d0-931a-0709a55b4149`）批准的一次限时查新，
> **0 GPU**，关键词按裁决指定。

## 0. 结论：关闭

按 L2 预设的判据——「若最近邻只需把样本改称发动机、把分数改为轨迹分位数即可得到 C4，立即关闭」——
**该条件成立**。C4 不是新机制，是**经典容忍区间定律 + 聚类保形**在同一对象上的重新命名。

## 1. L2 给出的归约（先于查新，已足够定案）

对预先固定的嵌套区间族，令

  S_E = inf{ λ : C_E(λ) ≥ 1−α }（引擎 E 达到名义覆盖所需的最小膨胀量）

则 C4 等价于对**引擎级分数 S_E** 做 PAC 容忍界：取 λ = S_(k)（第 k 个次序统计量），使

  P{ Bin(n, 1−β) ≤ k−1 } ≥ 1−δ。

由此立刻得到样本量要求：**β=0.10, δ=0.05 需 ≥29 台独立校准引擎；β=0.05, δ=0.05 需 59 台。**
我们的冻结协议每折只有 6/16/6/15 台校准引擎，且**重复 seed 不增加独立引擎数**。
→ C4 在现有数据上**不可行**，与新颖性无关也做不了。

## 2. 查新命中（四条，覆盖 C4 的三个组成）

| 组成 | 命中 | 出处 |
|---|---|---|
| **有限样本"实现覆盖的稳定性"** | 经典容忍区间：Wilks (1941) 起问的正是"n 要多大，容忍区间才有给定的稳定性"，Wald (1943)、Scheffé–Tukey (1945) 等后续 | 综述与推导见 Johnstone 等 2026（PMLR v329）与 CP 讲义（Da Veiga, HAL hal-04690218） |
| **双层概率（PAC）保证** | "BPCI 与 training-conditional CP 都提供 PAC 保证，只是作用对象不同"；训练条件 CP 给出的是条件覆盖的下界 | arXiv **2502.07497** |
| **聚类/层级数据下的保形** | 层级医疗数据中"同簇内不独立"破坏可交换性，需按簇处理——与"发动机是簇"结构同构 | Scientific Reports 2026（s41598-026-37450-w） |
| **子组覆盖随校准格变小而坍塌** | "per-subgroup (Mondrian) coverage drops when the calibration cell is small"，并给出闭式机制 | arXiv **2608.04254** |

第 4 条尤其致命：它把我们观测到的"校准引擎少 → 单机覆盖坍塌"解释成**已知机制**，
而不是新发现。

## 3. 与 C1 的关系：同一条死路

C1（CRC + 非对称维护成本）死在"理论已被占 + 应用已被占"；C4 死在"目标可归约为经典容忍界"。
两者共同的病根：**在"保形 + RUL"这个交叉点上，剩下的都是把成熟统计工具换一个对象名。**
