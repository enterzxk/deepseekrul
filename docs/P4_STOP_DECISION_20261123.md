## 3. 判定：**均值判终止，不是「结构不可达」**

- **主判定（对 V0 clean）**：均值 **1.84** 落在 `1.5–2.5` 灰带 → 按事前规则**终止**；
- **附（对自身 clean）**：均值 **1.16** `< 1.5` → **终止**；
- **两个口径的均值都判终止，结论稳**。

**必须写清的一件事（经理 2026-11-23 要求）**：`s303` 单格是 **2.72 > 2.5**，单看它按规则应判「进 Stage 1」。
**是均值把它压回终止的**，所以**不得**写成「三个 seed 全部低于止损线」——审稿人会逐 seed 看。

**⚠ 撤回本文件 v0.1 的一句定性**：v0.1 写过「结构不可达，不是跑了没达到」。第三格出来以后这句**不成立**——
`s303` 的自身残差是 **1.804 > 1.5**，那一格是有空间的。本判定的依据是**均值 + 事前灰带规则**，
不是「按构造不可达」。这个区别必须留痕：前者是规则判定，后者是设计缺口，论文写法完全不同。

## 4. 为什么要报两个口径

止损规则原文写「距 `clean` 的残差」，**没指明哪个 clean**。`MaskAug` 是**重训**骨干，它的 clean 变了：

- **对自身 clean**：问的是「这个臂在损坏下比它自己能做的最好差多少」——鲁棒性缺口的定义；
- **对 V0 clean**：问的是「最终绝对性能离原始基线多远」——把 clean 代价也算了进去。

两者差的就是 clean 代价（+0.52 ~ +0.91）。**两个都报**，读者可以自己复算；**主判定用对 V0 clean**
（更保守，且它是「最终交付的模型有多差」），附对自身 clean。

## 5. 这次止损带回来的三条发现（比「方向终止」值钱）

**5.1 损伤主要来自训练/测试不匹配，不是「信息缺失」。** 同一个骨干，**只在训练时见过通道损坏**，
就把 36.0 修到 15.2，回收 **94.8% / 95.2%**（s101 / s202），**零模块**。
「用观测通道估计故障通道」这件事，骨干自己学会就够了，不需要外挂重构器。

**5.2 修复模块与增强训练是替代关系，不是互补关系。** `MaskAug + Ridge` 在**全部 6 格**上都比
`MaskAug` 单用更差（FD004 drop40：**21.34 / 18.36 / 18.96** vs **15.22 / 15.64 / 16.45**）。
骨干已学会直接吃带缺失的输入，再拿 ridge 去「修好」，等于把输入推出它训练时的分布。
**这一条独立于止损线，直接否掉 v3 的模块定位。**

**5.3 `MaskAug` 不是免费的。** clean 代价：FD004 **+0.515 / +0.593 / +0.914**（均值 +0.674），
FD001 **+0.54 / +1.35 / +1.61**。按 v0.3 的三段判据（`MDE` 0.65–1.14，分界 0.33–0.57），
FD004 三格**全部落在灰带或「确有代价」一侧**——它也不是「白捡的强基线」。

## 6. 对 v3 的影响

v3 的模块定位（外挂重构器）**被否**：空格已被增强训练填掉 95%。
真正剩下的问题换了：**「怎么在拿到鲁棒性的同时，不付 clean 代价」**。
