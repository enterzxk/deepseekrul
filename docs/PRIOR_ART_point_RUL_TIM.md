## 0. 一句话结论

四篇都是**点预测**论文，评估只有 RMSE / Score，**没有一篇报告覆盖、区间宽度或单机级失效**。

| ST-KDFormer | 纯深度表示缺乏结构化动力学约束 | 时空 Koopman 自编码器（z_{t+1}≈K z_t）+ 双分支 + 动态损失权重 + 谱归一化 | 无区间/覆盖；隐空间无直接物理含义；线性近似质量依赖数据 |

## 4. 对本项目的三条硬结论

### 4.1 方向一（点预测）的四个入口已被占满

物理先验图 → STGATN；动态关系图 → HDA-GNN；状态动力学约束 → ST-KDFormer；
工况–传感器交互 + 多尺度图 → SFI-STHGAT。**任何新点预测 idea 必须先过 §5 的五问门**，
否则就是「已知模块的重新组合」。

### 4.2 方向二（区间/可靠性）：它们是骨干，不是基线

区间方法的对照必须是：**CRULP（UACQR + ensemble + cross-conformal）、标准 CQR、split conformal、
异方差/尺度类方法、以及分组/单机级保形**（见 `docs/difftable_crulp_ijphm.md`、`docs/wiki/literature.md`）。
这四篇的作用只有两个：① 作为**骨干**（若要检验「骨干变强后区间结论是否仍成立」）；
② 作为**写作范本**（机制级消融、替换式对照、多数据集）。

### 4.3 一个它们集体留下的空白，正好可检验

四篇全部只报 RMSE/Score。由此有一个**便宜且可证伪**的问题：

> **H-TRANSFER：本项目的区间结论（边际覆盖达标但单机覆盖 0.12–0.49、CQR 相对常数宽度的效率收益）
> 是否依赖 IDA-PE 这一个骨干？**

- 若换骨干（例如把同一套 split conformal + CQR 校准套在更强/更弱的点预测器上）结论方向不变 →
  区间结论是**方法层**的，可写进论文的「骨干无关」段落。
- 若结论随骨干翻转 → 说明我们报告的失效主要是**骨干误差结构**的产物，必须在论文里限定到具体骨干。

这条**不需要复现这四篇**：只需用我们已有的训练脚本换 1–2 个更简单的骨干（LSTM / 小 Transformer），
在相同划分、相同校准协议下重跑 80 格。预算约 1–2 GPU-h。
（是否执行待 L2；本条只登记为候选，不自行立项。）

## 5. 五问门（任何新机制进入实验前必须回答）

从这四篇的组织方式提炼，写死成验收清单：

1. **问题**：新机制对应的是哪一个**具体的失效假设**（在什么条件下、现有方法的哪个假设不成立）？
2. **公式**：区别能否写成一条可分离的方程/估计量，而不是只出现在框架图里？
3. **替换式消融**：去掉新机制后，用**更简单的替代方案**（拼接代替交互、单层代替分层、无约束代替约束）
   是否显著更差？只做「删除模块」不算。
4. **公平比较**：同骨干、同参数预算、同划分、同 seed 数、同评估口径。
5. **最近邻**：在最接近的那一篇的方法上仍成立，而不是只跟自己搭的弱基线比。
