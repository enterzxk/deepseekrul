# 问题搜索协议（选项 B 的第一步）

> 背景：六条候选（C1/C4/C5/测量协议/同时轨迹带/cap-125）全部因「工具转移」被占。
> 本文件定义**怎样才算找到了一个新问题**，以及用最便宜的方式证伪每个候选问题空间。
> 目的：避免再出现"想一个方法 → 查新 → 被占 → 再想一个"的循环。

## 0. 判别标准：新问题 vs 新方法

一个候选只有在**同时满足**下面三条时才算"新问题"：

1. **对象不同**：推断/保证/优化的对象不是"区间""覆盖率""成本期望"这些已有对象，
   而是一个此前没有被形式化的量（例如：某个决策规则的后悔、某类失效的可探测性、
   某个测量协议下的可辨识性）。
2. **不是换名**：把新对象代入后，不能用一篇已知论文的定理直接得到结论；
   必须至少需要一个新的引理或一个新的可检验条件。
3. **有便宜的证伪测试**：能在 **0 GPU、≤2 小时**内判断它是否已被占或是否平凡。

不满足第 1 条的，是"新方法"（当前已饱和）；不满足第 2 条的，是"换名"；
不满足第 3 条的，先不做。

## 1. 候选问题空间（每个附最便宜的证伪测试）

### P1 · 维护决策的**后悔**而非区间的覆盖

- **对象**：给定区间方法 M，维护策略 π(M) 相对 oracle 策略的期望后悔 R(π)。
  问题：区间的哪个**可观测属性**（宽度分布？单机覆盖下尾？校准集规模？）决定 R(π)？
- **为什么不是换名**：现有工作（Shi 2026、CRC 系列）控制的是**成本期望**或**覆盖率**，
  没有把"后悔"作为推断对象，也没有给出"区间属性 → 后悔"的映射。
- **最便宜证伪**：查新 `regret bound conformal maintenance policy`、
  `interval property determines decision regret`。若已有映射定理 → 关闭。
- **若成立的形态**：一个"区间诊断量 → 后悔上界"的定理 + 在 80 格上验证该诊断量与
  模拟策略后悔的秩相关。TIM 会喜欢"可操作的诊断量"。

### P2 · 失效的**可探测性**（detectability）而非可识别性

- **对象**：给定一台发动机的在线轨迹，**在什么时刻**可以判断它的区间正在失效？
  这是一个"检测延迟"问题，不是"预测哪些对象会失效"（后者已被 D021 否决、
  且被 similarity-CP 的 abstain 占位）。
- **为什么不是换名**：abstain 方法回答"要不要出区间"，不回答"最早什么时候能知道"。
  检测延迟是有独立意义的量（维护响应时间）。
- **最便宜证伪**：查新 `change detection conformal coverage online`、
  `detection delay coverage failure`。若有在线检测定理 → 关闭。
- **若成立的形态**：一个序贯检测规则 + 检测延迟的有限样本界 + 在 80 格逐机轨迹上的
  经验延迟分布。

### P3 · 校准发动机的**选择**（active calibration）

- **对象**：给定预算 n_cal 台发动机，**选哪几台**去跑失效，能使下游区间的最差单机覆盖最好？
  这是实验设计问题，不是校准方法问题。
- **为什么不是换名**：现有工作都假设校准集是给定的随机样本；没有"选哪些单位"的准则。
- **最便宜证伪**：查新 `active calibration conformal sample selection`、
  `design of experiments calibration set conformal`。
- **风险**：在 C-MAPSS 上"选择校准发动机"需要额外的可观测特征，可能退化为分层抽样（已关闭）。

### P4 · 测量协议的**构造效度**（construct validity）

- **对象**：C-MAPSS 的 RUL 标签与评估窗口，究竟在测什么？
  这不是"审计别人的数字"，而是给出**协议的形式语义**（每个指标对应哪个估计量）。
- **为什么不是换名**：现有讨论停留在"cap=125 是惯例"，没有把指标写成估计量并给出偏差分解。
- **最便宜证伪**：查新 `construct validity prognostics benchmark`、
  `estimand RUL evaluation metric`。
- **风险**：用户已否决审计型；且统计内核可能被"评估框架"类综述占位。

## 5. 最终结论（写给 10:00 的决策）

1. **不是搜索不充分**：六条方法候选 + 四条问题候选，共十条，全部被占或前提不成立。
   每条都有可定位的出处，不是我觉得。
2. **共同病根**：这些工作的形式都是「把一个成熟统计工具换一个对象名」。
   2023–2026 年保形/风险控制/决策理论的方法扩散速度，快过我们在这个小数据集上能做出的增量。
3. **唯一出路是换问题域**（离开 C-MAPSS 的区间质量），或投入 3–6 个月做真正的新理论；
   在现有资产上继续找，期望收益已经为负。
4. **已交付的可复用资产**：饱和地图（10 条）、两个审计更正（FEMTO 泄漏、截断前提）、
   台账全项独立复算、问题搜索协议与停止规则。这些在任何后续路线里都不会浪费。
