# T1 数学对象草案：逐机覆盖下尾的可估性

> Phase 0 候选 T1（见 `docs/THEORY_PROGRAM.md` §2）。本文件只写**对象、命题、假设、失效条件**，
> 不写证明。若 L2 立项门通过，才进入 Phase 1 的证明。

## 1. 对象（estimand）

设总体中有 N 台发动机。对第 i 台，定义其**真实逐机覆盖**

  C_i = P( Y ∈ Ĉ(X) | engine i ) ∈ [0,1]，

其中 Ĉ 是给定的保形区间族（冻结，不再训练），Y 是该发动机在部署轨迹上的 RUL。

**目标量**：逐机覆盖分布 F_C 的**下尾**，具体取

  θ_q = F_C^{-1}(q)，  q = 0.10（即"最差 10% 发动机"的覆盖水平）。

我们的实证动机：边际覆盖 ≈0.88，而 80 格真实最小单机覆盖低到 0.1217；
ICC(1,1)=0.780 说明 C_i 是稳定属性，不是噪声。所以"下尾"是真实存在的量，不是抽样噪声。

## 2. 抽样模型

- 抽 n 台发动机（**物理发动机是独立单位**；重复 seed、重叠折、同机多窗口都不增加 n）。
- 对第 i 台，观测 m_i 个窗口，每个窗口的覆盖指示 H_ij ∈ {0,1}，
  H_ij | C_i ~ Bernoulli(C_i)，**机内相关**由 C_i 的异质性承担（条件独立假设）。
- 成本：每台发动机 K，每窗口 k（K ≫ k）。

**关键约束（来自我们协议的实测）**：n 只能是 6/16/6/15（各子集校准发动机数），
m 约 100–200（每机窗口数）。**在这个 (n, m) 下，θ_0.1 是否可估？**

## 3. 要证的命题（可证伪）

**主命题（下界）**：存在常数 c > 0，使得对任意估计量 θ̂，

  sup_{F_C ∈ F} E|θ̂ − θ_0.1| ≥ c · (n^{-1/2} + (m·n)^{-1/2} · σ_F)，

其中 σ_F 是机内二项噪声的相对尺度；且当 n ≤ n*(q, ε) 时，下界**大于**任何区间估计的半宽 ε。

**推论（对我们协议的判读）**：若 n=6，则 θ_0.1 的 95% 区间半宽 ≥ 某阈值（待算），
即"最差 10% 发动机覆盖"这个量在现有校准规模下**不可估**——这解释了为什么我们的
逐机最小覆盖在不同 seed 下能到 0.12 也可能到 0.49（见 `a2_rectifier.csv` 的 min 列）。

**可证伪点**：若存在一个估计量在上述 (n, m) 下达到远优于下界的精度
（例如利用跨 seed 稳定性做借力估计），则主命题的常数被推翻。

## 4. 假设与边界

- **A1** 发动机独立同分布（同一子集内）。
- **A2** 条件独立：给定 C_i，窗口指示独立。若机内还有残余相关（超出 C_i 的部分），
  下界要乘一个设计效应因子 deff ≥ 1——**这是必须写清的**，也是 D034 指出的击穿点之一。
- **A3** C_i 的支撑在 (0,1) 内，下尾 q=0.10 处密度有界远离 0。
- **失效条件**：若 A3 不成立（下尾处密度为 0，例如 C_i 高度集中），
  则 θ_0.1 的估计问题退化，命题需改写为对分位数的置信上界。

## 5. 与最近邻的非等价性（初步，待 Phase 0 第 3 步补全）

| 最近邻 | 它做什么 | 我们的差别 |
|---|---|---|
| 小区域估计（small-area estimation） | 估计区域内均值/分位数，含测量误差 | 我们的"区域"是**发动机**，且关注的是**覆盖比例的下尾**；需要核对是否已有"cluster-level proportion 的 quantile"结果 |
| 容忍区间（Wilks 起） | 单个对象的覆盖稳定性 | 我们问的是**对象间分布**的分位数，不是单个对象的覆盖 |
| 聚类保形（Sci. Rep. 2026 等） | 簇内相关下的保形构造 | 我们不改构造，只问**给定构造下逐机覆盖下尾的可估性** |
| 累积带/超限设计效应（2026） | 覆盖受校准单元数限制 | 他们给的是**边际**覆盖的界，我们给的是**对象间分位数**的 minimax 界 |

## 7. 查新结果（2026-11-10）：**关闭**

T1 的数学对象（聚类数据的样本分位数、其有效样本量与下尾可估性）已被占，且占得很准：

| 最近邻 | 占住了什么 |
|---|---|
| **Noonan 2026**《effective sample size / shared ancestry》(Zenodo `10.5281/zenodo.21629688`) | 明确写「Theorem 1 governs **any decision threshold set at a sample quantile of clustered data**」——把若干文献放到同一条曲线上，并给出水平依赖的修正。这正是 T1 的「聚类数据分位数 + 设计效应」核心。同一作者另有 exceedance design effect（Zenodo `10.5281/zenodo.21798943`） |
| **Chen & Liu (2019)**《Small Area Quantile Estimation》Int. Stat. Rev. 87(S1):S219–S238, DOI `10.1111/insr.12293` | 小区域分位数的估计方法与精度评价，覆盖「子总体样本很少时的分位数估计」这一结构 |
| 容忍区间（Wilks 1941 起） | 单对象覆盖稳定性与样本量问题 |

**判定**：T1 =「聚类数据分位数 + 二项测量误差」的特例，可用 Noonan 的有效样本量框架 + 小区域分位数方法组合得到。
按 Phase 0 的判据（能否用一篇已知论文的定理直接得到结论），**T1 不通过**。

**保留价值**：T1 的数值实例（n=6/16/6/15 下的下尾区间宽度）仍可作为**应用性数字**写进任何后续稿件，
但不构成理论贡献。
