# 新理论程序：结构与 Phase 0 计划（2026-11-10）

> 用户 2026-11-10 00:56 选择「2#」：投入 3–6 个月做新理论程序，而不是转 measurement 稿。
> 本文件定义程序结构、阶段门与 Phase 0 的具体动作。**不预设一定能产出论文。**

## 0. 为什么需要"程序"而不是"再找一个候选"

过去 11 条候选全部死在同一个地方：它们都是**把一个成熟统计工具换一个对象名**。
根因不是想象力不够，而是**没有一个属于我们自己的理论对象**——
我们有的是一个实证现象（边际覆盖掩盖稳定的逐机失效），不是一个可证明的命题。

程序的目标：把那个实证现象**升级成一个理论对象**，并证明它值得一篇论文。

## 1. 程序结构（3–6 个月）

| 阶段 | 时长 | 产出 | 门 |
|---|---|---|---|
| **Phase 0 选问题** | ≤2 周 | 六件套草案 + L2 立项裁决 | 数学对象明确、可证伪、与最近邻非等价 |
| Phase 1 理论 | 4–8 周 | 主命题 + 证明（或反例）+ 失效条件 | 证明通过独立复核（proof-checker / Codex） |
| Phase 2 验证 | 4 周 | 在 80 格 + 仿真上验证理论预测 | 预注册判定门 |
| Phase 3 成稿 | 4 周 | TIM 稿 | 引用审计 + claim 审计 |

**硬规则**：Phase 0 不通过就不进 Phase 1；Phase 1 证明不成立就如实记录并回到 Phase 0，不硬写。

## 2. Phase 0 的候选理论对象（按与现有证据的连接强度排序）

### T1 · 逐机覆盖的可估性（estimation theory）

- **对象**：给定 n 台校准发动机、每台 m 个窗口，估计**逐机覆盖的分布** F_C（或它的下尾）。
- **与证据的连接**：ICC 0.780 说明 C_i 是稳定属性；单机覆盖 0.12–0.49 说明下尾才是问题。
- **可证伪命题**：在机内相关结构下，F_C 的下尾存在一个 minimax 下界，
  且该下界在 n_cal=6 时**高于**任何估计量能达到的精度 → 现有协议的"逐机失效"结论不可估。
- **风险**：小区域估计/测量误差文献可能已覆盖（D034 的容忍界分析是近邻）。

### T2 · 稳定失效的可利用性（learnability theory）

- **对象**：C_i 在跨 seed 上稳定（ICC 0.78）意味着它可由**无标签部署特征**预测。
  问题：在什么条件下存在一个预测器，其最差对象覆盖的后悔有界？
- **与证据的连接**：直接建立在 ICC 与 ρ(rmse, engine_min)=−0.78（循环性已标注）之上。
- **可证伪命题**：存在一个可计算的、只用校准集信息的风险评分，其在留出引擎上的
  AUROC 显著优于随机；否则给出不可识别边界。
- **风险**：D021 已否决过这个方向的**提案**（形式化缺陷）；similarity-CP 占 abstention。
  作为理论程序必须修掉 D021 指出的三处计数混淆，并给出严格的对象定义。

### T3 · 维护策略认证的样本复杂度（decision theory）

- **对象**：给定策略类 Π 与 run-to-failure 数据，认证 π 的风险 ≤ τ 需要多少台发动机？
- **与证据的连接**：我们有 80 格策略评估的实证；D034 的容忍界只针对区间，不针对策略。
- **可证伪命题**：存在策略类 Π 与损失，使认证的样本复杂度**严格高于**区间认证，
  且差距由策略对区间尾部的敏感性决定。
- **风险**：off-policy evaluation 的样本复杂度理论成熟；需要证明"维护策略"这一对象带来新结构。

## 3. Phase 0 的执行步骤（≤2 周）

1. **逐条查新**（每条 ≤1 天，0 GPU）：T1/T2/T3 各做一次定向检索，
   判据是「能否用一篇已知论文的定理直接得到结论」。
2. **写出数学对象**（每条 ≤1 页）：估计量/命题/假设/失效条件。
3. **非等价性论证**：与最近邻逐项对照，说明为什么不是换名。
4. **六件套草案**：只对通过 1–3 的候选写。
5. **交 L2 立项门**。

## 4. 停止规则

- 若 T1–T3 全部被占或不可证伪 → 记录，回到"候选理论对象"的生成，但**不重复同一类**。
- 若连续两轮生成的新对象都属于"估计/认证"这一类 → 说明我们只会这一类，
  此时应承认能力边界，而不是继续生成。
