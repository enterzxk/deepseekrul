## 2. 协议

- **轴承是独立单位**：留一轴承（LOBO）。
- 归一化统计量只来自训练轴承。
- 评价窗口：留出轴承的**最后 15%**（RUL 小、测量问题真正重要的区间）。
- 窗口长度 20 快照，步长 2；波形按 8 倍降采样（2560→320）。
- 主指标：RMSE（快照单位）；辅：MAE。

## 3. 三个臂（首轮）

| 臂 | 内容 |
|---|---|
| **A** 直接 | 共享 CNN 编码双通道 → GRU → RUL |
| **C** 通用门控 | 双编码器 + 只看 $h_t$ 的学习门控（等容量对照） |
| **D** 一致性门控 | 门控输入含**跨通道一致性**（余弦相似度）与**持续性**（通道差范数的 EMA） |

**机制主张**：D vs C 检验"跨通道测量一致性"是否携带通用学习门控拿不到的信息。
若 D ≈ C，则一致性不是机制。

## 4. 与最近邻的差异（待正式查新）

- 鲁棒滤波（Huber/自适应 Q,R）：抑制**残差幅度**异常；
  D 的门控依据是**两个测量通道之间的一致性**，不是单通道残差大小。
- 自适应传感器融合：按**通道可靠性**加权融合；
  D 不融合，而是**决定是否更新状态**。
- 振动 RUL 方法：多为直接回归或 CNN/LSTM；
  D 把"测量质量"显式接到状态更新上。

**必须核实**：跨通道一致性作为门控信号是否已被用于轴承 RUL（尚未检索）。
