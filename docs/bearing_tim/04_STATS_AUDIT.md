# 轴承统计与协议审计（C vs C-Fixed / C-MLP）

## 1. 审计对象与方法

**统计量（全篇统一）**：
$$D=\frac1{17}\sum_{b}\frac{\mathrm{RMSE}_{b}^{\text{cand}}-\mathrm{RMSE}_{b}^{\text{base}}}{\mathrm{RMSE}_{b}^{\text{base}}},$$
其中 $b$ 是轴承，RMSE 由该轴承 4 个寿命阶段（50/70/85/95%）的误差汇总。

- **重采样单位 = 轴承**（不是窗口、不是种子）。5000 次百分位 bootstrap 给 CI。
- **P 值**：配对**符号翻转**置换检验（H0：两臂在某轴承内的差异关于 0 对称），
  20000 次，双侧。**这是真正的检验，不是"bootstrap 中候选更优的比例"。**
- 上一版报告的 `P(rel<0)` 只是 bootstrap 比例，**不是 p 值**，已废弃。

## 2. 修正后的结果（17 台轴承）

| 比较 | D | 95% CI | p（双侧） | p（单侧） | 胜率 |
|---|---|---|---|---|---|
| **C vs A** | **−22.62%** | [−42.11, −3.41] | **0.043** | 0.022 | 11/17 |
| C vs C-Fixed | −3.97% | [−29.55, +24.02] | 0.788 | 0.394 | 9/17 |
| C vs C-MLP | −2.76% | [−21.92, +14.63] | 0.778 | 0.389 | 7/17 |
| C-Fixed vs A | −4.02% | [−29.81, +33.10] | 0.902 | 0.451 | 11/17 |
| **C-MLP vs A** | **−17.39%** | [−33.02, −1.77] | **0.053** | 0.027 | **13/17** |

## 3. 审计得出的关键结论

**C 相对 A 的收益，不是门控带来的。**

- C（双编码器 + 学习门控）相对 A：−22.6%，p=0.043；
- **C-MLP（双编码器 + 等容量 MLP，无门控）相对 A：−17.4%，p=0.053，13/17 胜**；
- C vs C-MLP：−2.76%，p=0.778 —— 两者没有差别。

即：**双编码器 + 更高容量融合**就能拿到几乎全部收益；乘性门控的增量不成立。

## 4. 逐台归因（误差方向）

偏差（正 = 高估 RUL）显示，**C 相对 A 的主要改善是"长寿命轴承上少高估"**：

| 轴承 | 寿命（快照） | A 偏差 | C 偏差 |
|---|---|---|---|
| Lear_Bearing3_1 | 604 | +1418 | +1153 |
| Lear_Bearing2_1 | 1062 | +756 | +112 |
| Full_Bearing2_7 | 200 | +1792 | +1646 |
| Lear_Bearing2_2 | 797 | +572 | +21 |

A 在所有长寿命轴承上都严重高估；C 把偏差压低。

**C vs C-Fixed 的差异由单台轴承主导**：`Full_Bearing1_4` 上 C-Fixed 崩溃
（RMSE 1907.5，偏差 −1892.1，即严重低估），而 C 是 375.4。去掉这一台，
C 与 C-Fixed 的差距会大幅缩小。

## 5. 协议层面的已知局限（必须写进论文）

1. **LOBO 折之间训练集重叠 15/16**：17 个模型不是独立的，轴承之间的误差相关。
   bootstrap 把轴承当可交换，是近似。
2. **17 台是设备层面的样本量**；增加随机种子**不会**增加独立设备数。
3. 每配置目前只训练一次，**没有种子重复**，因此不能区分"方法差异"与"初始化噪声"。
4. 40 次旧实验（v1）存在早停泄漏，**仅作历史记录，不引用其性能结论**。

## 6. 对"末期稳定性"的限定

之前观察到 C 在 95% 寿命处 MAE 不升（505.5 vs 50% 的 509.5）。审计后必须限定：

- 这只是 17 台、单种子、**未预注册**的探索性观察；
- 偏差表显示 A 在长寿命轴承上系统性高估，C 的低估/高估更接近 0 ——
  "末期不退化"很可能就是"长寿命轴承上少高估"的另一种说法；
- 尚未做：按寿命长度分层的误差、相对寿命误差、门控是否只是平滑输出。

**因此不把末期稳定性当作机制证据。**
