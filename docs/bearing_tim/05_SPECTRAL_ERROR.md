# 频域退化信息与预测误差：关联分析（n=17 轴承）

> 数据：`data/femto_spec/*.csv`（原始 25.6 kHz 波形逐快照特征，全部因果）
> × `experiments/bearing_tim2/*/*.csv`（四臂逐阶段预测）。
> 设备级 n=17；4 个寿命阶段是同一设备的重复测量，**不是独立样本**。

## 1. 先修正一个数据完整性 bug

`Full_Bearing1_4` 的 CSV 用**分号**分隔（其余轴承用逗号）。原加载器
`pd.read_csv(header=None)` 读成单列 → 转 float 失败 → 被 `except: continue` 跳过 →
**该轴承在模型里是全程零输入**。

这解释了它在 C-Fixed 上的崩溃（RMSE 1907、偏差 −1892）。修复加载器
（`sep=None, engine="python"`）后重跑该轴承 4 个臂，并重算全部统计。

## 2. 修复后的审计（17 轴承，配对符号翻转检验）

| 比较 | D | 95% CI | p（双侧） | 胜率 |
|---|---|---|---|---|
| C vs A | −23.91% | [−43.58, −4.39] | 0.037 | 11/17 |
| **C-Fixed vs A** | **−19.71%** | **[−33.08, −6.51]** | **0.013** | 12/17 |
| **C-MLP vs A** | **−18.07%** | **[−33.80, −2.43]** | **0.046** | 13/17 |
| C vs C-Fixed | −1.69% | [−26.29, +25.24] | 0.903 | 9/17 |
| C vs C-MLP | −3.79% | [−23.08, +14.00] | 0.703 | 7/17 |

**结论比修复前更强也更清晰**：
**双编码器单独（C-Fixed，固定 0.5 融合）就拿到全部收益（−19.7%，p=0.013），
等容量 MLP（C-MLP）也一样（−18.1%，p=0.046）；乘性门控增量为零（p=0.90/0.70）。**

## 3. 频域特征与 |误差| 的关联

### 3.1 设备级（末期，n=17，未做多重比较校正）

| 臂 | 最强关联 |
|---|---|
| A | `coh_mean` ρ=−0.48 (p=0.05)、`v_rms` −0.44 (0.07)、`h_rms` −0.41 (0.10) |
| **C** | **`v_rms` ρ=−0.63 (p=0.01)**、**`hv_energy_ratio` +0.61 (p=0.01)**、`h_rms` −0.48 (0.05) |
| C-MLP | `v_rms` −0.56 (p=0.02)、`h_rms` −0.45 (0.07) |

### 3.2 控制寿命阶段后的偏相关（全部阶段）

| 臂 | 最强关联 |
|---|---|
| A | 无（最强 |ρ|=0.19，p=0.13） |
| **C** | **`hv_energy_ratio` +0.42 (p=0.000)**、**`h_band4`(8–12.8 kHz) −0.36 (p=0.000)**、`h_band1` +0.34 (p=0.000)、`v_rms` −0.28 (p=0.02) |
| C-MLP | `hv_energy_ratio` +0.28 (p=0.02)、`h_band4` −0.28 (p=0.02)、`h_band1` +0.26 (p=0.03) |

**方向**：
- **垂直通道能量越高，误差越小**（`v_rms` 负相关）；
- **水平/垂直能量比越失衡，误差越大**（`hv_energy_ratio` 正相关）；
- **高频带（8–12.8 kHz）能量占比越高，误差越小**；中频带（1–2.5 kHz）相反。

### 3.3 C vs C-MLP 的配对差异

只有 `h_env_peak_f` 有弱关联（ρ=+0.42，p=0.09，n=17）——不构成解释。

## 4. 判读（必须限定）

1. **这些关联是探索性的**：14 个特征 × 3 个臂，未做多重比较校正；
   n=17 且已被多轮方法选择使用过，**不能当作独立确认**。
2. **关联的是"误差大小"，不是"可用于更新的信息"**：它说明"信号强、通道平衡时预测更准"，
   这与"测量质量→误差"的直觉一致，但**还不是一个可操作的更新机制**。
3. A 臂上这些关联基本消失（控制阶段后全不显著），说明关联依赖于模型结构，
   **不是数据本身的不变量**。
4. 方向与"高频冲击携带退化信息"的假设部分一致（band4 负相关），
   但 band4 与 `v_rms` 高度共线，**无法区分是"高频"还是"能量强"**。

## 5. 因此：证据不足以提出新机制

按用户设定的判据（"若某项前缀可观测特征与误差有稳定关系 → 验证跨轴承、跨工况一致性
→ 与 RMS/峭度比较 → Codex 精读 → 设计机制"）：

- 关系**方向一致但统计强度弱**（|ρ| 0.28–0.63，未校正）；
- **与 RMS 不可分离**（最强关联就是 `v_rms`/`hv_energy_ratio`，都是简单时域量）；
- **未做跨工况分层**（Bearing1/2/3 家族各 4–5 台，样本太小）；
- **A 臂不复现**，说明不是稳健的数据规律。

**结论：证据不足，不启动新模型训练。**
