# E0–E3：高频信息的增量价值（决定性实验）

## 1. 两个审计结论

### 1.1 CI 与 p 值

- 统计量：$D=\frac1{17}\sum_b(\mathrm{RMSE}^{cand}_b-\mathrm{RMSE}^{base}_b)/\mathrm{RMSE}^{base}_b$。
- **bootstrap CI**：重采样**轴承**（n=17），百分位区间；零模型是"重采样"，隐含 $D=0$。
- **符号翻转 p**：$H_0$ 为两臂在某轴承内的差异关于 0 对称（可交换），随机翻转符号构造零分布。
- 两者同统计量、同 17 台，**零模型不同**。n=17、分布右偏时，区间下界可刚好排除 0 而置换 p 略高于 0.05。
- **正式口径：以符号翻转 p 为准，CI 只作效应量描述。** 不挑有利于显著性的口径。

### 1.2 8 倍盒式平均的频率响应

$|H(f)|=\left|\frac{\sin(8\pi f/f_s)}{8\sin(\pi f/f_s)}\right|$，$f_s=25.6$ kHz：

| 频率 | 0.8 kHz | **1.6 kHz（抽取后 Nyquist）** | 2.4 kHz | 3.2 kHz（首零点） |
|---|---|---|---|---|
| 衰减 | −0.7 dB | **−9.7 dB** | −12.6 dB | −∞ |

抽取到 1.6 kHz 后，1.6–3.2 kHz 会折叠进来；盒式滤波在 1.6 kHz 只衰减 9.7 dB。
**准确表述：8 倍盒式平均 + 抽取，阻带泄漏明显，不是理想低通。**
频带特征同时报告**绝对能量**（`band_frac × rms²`）与**相对比例**（`band_frac`），
E2 用绝对，E3 用相对 + RMS。

## 2. E0–E3 结果（17 轴承，三重互斥 LOBO，68 次训练）

| 臂 | 输入 | 宏平均 RMSE |
|---|---|---|
| E0 | ds=8 波形 | 616.3 |
| E1 | E0 + 双通道 RMS | 679.7 |
| **E2** | E0 + 8–12.8 kHz **绝对**能量 | **567.9** |
| E3 | E0 + 相对频带比例 + RMS | 684.3 |

设备级配对（n=17，符号翻转 p，bootstrap CI）：

| 比较 | D | 95% CI | p | 胜率 |
|---|---|---|---|---|
| E1 vs E0 | **+45.90%** | [−0.90, +112.41] | 0.108 | 6/17 |
| E2 vs E0 | +23.01% | [−15.76, +81.11] | 0.539 | 12/17 |
| E3 vs E0 | **+74.15%** | **[+10.05, +148.14]** | **0.055** | 6/17 |
| E2 vs E1 | −3.62% | [−23.98, +17.58] | 0.740 | 10/17 |
| E3 vs E1 | +105.15% | [−11.02, +263.87] | 0.206 | 9/17 |

**D 为正 = 加了特征后更差。** 三个特征臂**没有一个优于 E0**；
E3（相对频带）甚至显著更差（CI 不含 0）。
E2 的宏平均最好（567.9 vs 616.3），但配对 D 仍为正（+23%），
说明改善集中在少数轴承、被其余轴承的退化抵消。

## 3. 判断

**高频信息（8–12.8 kHz）在当前骨干与 17 台样本下没有可复现的增量预测价值。**

这与之前的两个发现一致：
1. band4 确实随寿命上升（15/17，符号检验 p=0.002）——**它是真实的退化信号**；
2. 但它与控制 RMS 后的模型误差无关（偏相关 ≈0）；
3. 现在直接喂给模型也不改善——**信号存在 ≠ 模型能获益**。

**因此：**
- **不进行 ds=1 全采样率重训**（按你设定的条件）；
- **不堆叠频域注意力、质量门控或多分支 Mamba**；
- 不把"高频趋势"写成"预测增量"，更不写成"方法创新"。

## 5. 对 TIM 的意义

本轮把"高频信息是否有增量价值"这一具体假设**证伪**了。
加上此前门控归因未确立、双编码器归因在干净数据上消失，
**当前 FEMTO 分支没有可支撑 TIM 方法论文的机制**。

剩下的可交付价值是**负向但可复现的证据**：
在 17 台轴承、严格三重互斥协议下，
（a）门控与双编码器都不能稳定解释收益；
（b）高频带是真实退化信号但不改善 RUL；
（c）数据解析错误会系统性伪造方法优势（本轮实测）。
