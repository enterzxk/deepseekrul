# 05 · 实验协议（冻结）

> 依据 `01_BASELINE_ARCHITECTURE.md`。所有方法共用，不得逐方法调整。

## 1. 数据与划分

| 项 | 冻结值 |
|---|---|
| 数据 | FEMTO 17 台（6 Learning + 11 Full_Test），原始 25.6 kHz 双通道 |
| 加载 | `bearing_data.load_bearing_strict`（严格校验，失败即中止） |
| 标签 | `RUL = N − i` |
| 降采样 | ds=8 盒式平均（**非理想低通**；1.6 kHz 处 −9.7 dB） |
| 输入 | `(B, W, 2, T=320)` |
| 历史长度 | 主：W=20；扩展：W=64（必要时 128） |
| 滑窗步长 | 2 |
| 归一化 | 逐通道 mean/std，只用训练轴承拟合 |
| 划分 | **三重互斥 LOBO**：留出轴承（评价）/ ES 轴承（早停，按寿命中位数确定性选）/ 其余 15 台（训练） |

## 2. 训练

| 项 | 冻结值 |
|---|---|
| 损失 | MSE（RUL 除以训练集最大 RUL） |
| 优化器 | AdamW；CNN-GRU lr=1e-3，Transformer lr=5e-4；wd=1e-4 |
| 梯度裁剪 | 1.0 |
| batch | 64 |
| 轮数 | ≤40，早停 patience 8（按 ES 轴承 RMSE） |
| 随机种子 | 0（固定） |

## 3. 评价

- 评价点：寿命 50% / 70% / 85% / 95%（只用于**定位**；输入只含该点前 W 个快照）。
- 指标：逐轴承 RMSE、MAE、偏差（正=高估）。
- 聚合：**设备级宏平均**（先逐轴承，再平均）；另报**按设备相对收益**的聚合，两者不混用。
- 统计：配对符号翻转置换检验（n=17），百分位 bootstrap CI 作效应量描述。
- 多重比较：跨方法比较时用 BH 校正。

## 6. 已知的公平性风险

1. **T3 的 token 数是 T1 的 10 倍**，计算量不同；必须同时报告推理成本，
   且不得把"更多 token/更长计算"直接解释为"时频表示更好"。
2. W=64 的对比必须同时报告 W=20，不能只报有利的历史长度。
3. 17 台已参与多轮方法选择，**本轮结果只能作为开发证据**。
4. E2/E3 的教训：把频带能量拼进模型没有稳定收益，因此 T3 的收益（若有）
   必须证明来自**token 表示 + 注意力**，而不是"多给了几个频带标量"。
