## 5. 已修的一个实现缺陷

T3 的因果掩码原用 Python 双重循环构造（200×200 = 4 万次/前向），导致训练极慢、
矩阵卡住。已改为向量化：
```python
tix = torch.arange(n_tok) // step
mask = tix.unsqueeze(0) > tix.unsqueeze(1)
```
修复后 T3 单次训练约 3–5 分钟。
