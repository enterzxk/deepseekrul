## 18. Round 15：按寿命阶段拆解后，matched-cutoff 的排序无法复现（重要）

**Protocol C（绝对周期）逐点 RMSE，FD002：**

**Protocol B（寿命比例）：**

| 单元 | 0.5 | 0.7 | 0.9 |
|---|---:|---:|---:|
| M0 | 21.866 | 15.213 | 4.843 |
| M6 | 19.807 | 12.563 | 5.685 |
| M1 | 20.047 | 11.583 | 4.920 |
| M5 | 20.912 | 12.524 | **4.746** |
| **M4** | **19.375** | **9.885** | 5.142 |

**矛盾点：**

* 在**寿命 70% 阶段**，M4 是 9.885，M1 是 11.583 —— **M4 好 1.70**；
* 在 **50% 阶段**，M4 19.375，M1 20.047 —— M4 仍更好；
* 在 **90% 阶段**，M1 4.920，M4 5.142 —— 基本持平；
* **但 matched-cutoff 上 M1（12.930）比 M4（15.078）好 2.15**。

三个阶段 M4 都不差于 M1，却在 matched-cutoff 上大幅落后。这说明
**matched-cutoff 的 RMSE 被少数发动机/少数极端样本主导**：它的截断点
`U[40, 0.95T]` 在不同发动机上落在极不相等的寿命阶段，短寿命发动机的
"0.95T" 可能仍是早期窗口，于是该指标混合了阶段与发动机难度两个因素。

**结论（必须写进报告）：**

1. **不能只用 matched-cutoff 下结论**，尽管它最接近部署场景；
2. 三个协议给出三个不同的赢家：matched→M1，B→M4，C→M4/M5（分段看 M4/M5 各赢两点）；
3. 之前的"M1 四条指标全胜"只对 matched 成立，且该指标本身不稳定；
4. 若要以"部署口径"为主指标，必须先给出该指标的**稳定性证据**（例如按寿命阶段分层、
   或对截断分布做敏感性分析），否则等于用噪声选模型。

**下一步（不新增训练即可做）**：对 matched-cutoff 做截断分布敏感性分析
（多个 cutoff_seed），看 M1 vs M4 的排序是否稳定。若不稳定，则主指标必须改为
分层报告（早/中/晚三段），而不是单一平均。

## 19. Round 16：稳健性检验——"M1 更好"是单次截断的产物（关键更正）

**方法**：用 Protocol C 已评估的 5 个绝对截断 {60,100,140,180,220}，对每台发动机
随机抽取一个截断（模拟部署时"不知道观测到寿命哪个阶段"），重复 2000 次，
得到每个单元 RMSE 的抽样分布。

| 单元 | 均值 | 5% 分位 | 95% 分位 |
|---|---:|---:|---:|
| **M4 分工况参考 + 门控** | **11.690** | 9.198 | 14.007 |
| M5 全局参考 + 门控 | 11.862 | 9.672 | 13.940 |
| M1 全局参考 + A | 12.052 | 9.948 | 14.248 |
| M0 原始 Transformer | 13.241 | 11.005 | 15.432 |
| M6 同特征 Transformer | 13.561 | 11.083 | 16.157 |

**排序概率：**

* P(M1 优于 M4) = **0.438** → 即 P(M4 优于 M1) = 0.562
* P(M1 优于 M6) = 0.765
* P(M4 优于 M6) = 0.816

**这与 matched-cutoff（cutoff_seed=2026）的结论相反**：那里 M1 = 12.930、M4 = 15.078，
M1 领先 2.15；这里 M4 领先 0.36。

**结论（必须取代此前所有"M1 最优"的表述）：**

1. **matched-cutoff 单次实现的排序不可靠**。它每台发动机只取一个点，
   该点落在哪个寿命阶段由随机种子决定，而不同阶段的误差差异可达 2 倍以上
   （见 Protocol C：60 周期 13.9，180 周期 5.8）。
2. **M1 与 M4 之间没有稳定赢家**（P=0.44 vs 0.56，实质是五五开）。
3. **相对 Transformer 的改善是稳定的**：M1 和 M4 都稳定优于 M6（P=0.77 / 0.82），
   而 M6 又优于 M0 的边缘不稳定。也就是说**"特征 + 通道独立主干/参考策略"的收益
   是稳健的，"具体哪一种是最好"是不稳健的**。
4. 因此内部 5% 挑战**不能**用 matched-cutoff 单点判定；必须以**多截断抽样分布**判定，
   即"在随机部署点上，候选优于基线的概率与中位差"。

**这一条应成为方法论贡献的一部分**：在 C-MAPSS 这类单点部署评估中，
常用"每机取一个截断"的做法会引入与种子相当的方差，足以翻转方法排序；
应当报告重采样分布而不是单点值。

## 21. Round 18：H2 决定性检验——证据门控与固定门控不可区分

采用共同随机数配对（同发动机、同截断比较），2000 次抽样，FD002：

| 对比 | P(前者更好) | 中位差 | 95% CI |
|---|---:|---:|---|
| **M4b（证据门控）vs H2_fixed1（固定门控=1）** | **0.538** | **−0.094** | [−2.117, +1.870] |
| M4b vs M1（全局参考 + A） | 0.677 | −0.593 | [−3.264, +1.891] |
| M4b vs M4（分工况参考 + 证据门控） | 0.588 | −0.237 | [−2.084, +1.676] |
| M4b vs M6（同特征 Transformer） | **0.909** | −2.198 | [−5.444, +0.827] |

**结论：把门控从"证据驱动"换成"恒等于 1"，性能差 0.094 RMSE，P=0.538——纯属噪声。**

因此 H2（收益来自"用证据估计可靠性"）**被否定**。真正起作用的是
"存在一条被门控的参考残差通路"这一结构，而门控的取值是否随证据变化无关紧要。
换句话说：**"可靠性门控"这个命名不成立；它实际上是一个可学习的参考抑制通道。**

## 23. 对"新在哪里"的最终回答（当前证据下）

**不是**"条件参考"（错），**不是**"可靠性估计"（无效），**不是**"Sensor-ID"（未启用）。

**是**两点：

1. **方法学**：C-MAPSS 类"每机单截断"部署评估的排序不可靠，其方差足以翻转方法优劣；
   应报告重采样分布（P(更优)、中位差、分位数）。这是可复现、可核查的贡献，
   也解释了文献中同类方法排序互斥的现象。
2. **经验结论**：在已工况归一化的数据上，再引入"分工况健康参考"会二次校正并损害性能；
   门控结构有效但"证据"无效。两条负结果都有同种子、同预算的对照支持。

**性能主张的边界**：带参考残差特征的变体相对同特征强 Transformer 的
P(更优) 为 0.84–0.91、中位差 −1.9 至 −2.2 RMSE，但**所有 95% CI 跨零**，
在 52 台验证发动机上不构成统计显著。

## 24. Round 19：风险校准——一个真实的精度–安全权衡（正面结果）

**方法**：在验证集发动机上做 50/50 划分；在一半发动机上拟合单一非对称偏移 δ
（最小化 `sum w(e)e²`，其中晚报 e>0 权重 ×2），在另一半上评估；重复 200 次取均值。
无人为泄漏：拟合与评估用不同发动机。

**FD002 结果：**

| 单元 | RMSE 基线 → 校准 | 变化 | late 基线 → 校准 | severe 基线 → 校准 |
|---|---:|---:|---:|---:|
| M0 原始 Transformer | 16.92 → 17.82 | +5.3% | 0.487 → 0.323 | 16.9 → 13.1 |
| M6 同特征 Transformer | 14.74 → 15.24 | **+3.4%** | 0.535 → 0.354 | 19.7 → **13.9** |
| M1 全局参考 + A | 12.75 → 13.82 | +8.4% | 0.439 → 0.272 | 14.6 → 10.9 |
| M4b 群体参考 + 门控 | 16.07 → 16.95 | +5.5% | 0.443 → 0.331 | 21.0 → 14.6 |
| M4 分工况参考 + 门控 | 14.64 → 15.52 | +6.0% | 0.484 → 0.334 | 19.4 → 12.2 |
| M5 全局参考 + 门控 | 13.95 → 14.52 | +4.1% | 0.536 → 0.323 | 19.2 → 13.3 |

**这是本研究中第一个"正面且可量化"的结果：**

1. 单一非对称偏移即可把 **严重晚报减少 30–40%**（如 21.0 → 14.6），
   同时把 late_fraction 从约 0.48 压到 0.33（远低于 0.52 门禁）；
2. 代价是 RMSE 上升 **3.4%–8.4%**——**不是免费的午餐**，必须如实报告为权衡；
3. **权衡效率因方法而异**：M6 只花 3.4% RMSE 就把 severe-late 降 5.8；
   M1 花 8.4% 只降 3.6。也就是说**RMSE 最优的模型不一定风险可塑性最好**。

这一条同时解决了目标里两个悬而未决的问题：
* "没有降低严重晚报不能声称安全收益"——现在有可测量的降低，且代价被量化；
* "RUL 晚报风险"作为研究支柱有了具体、可复现的机制（非对称后处理 + 权衡曲线）。

**尚缺**：完整的 Pareto 曲线（扫描 w_late 与 δ 网格），以及在 FD001 上的复现。
脚本 `scripts/dsh_risk_calibration.py` 已保存，产物 `results/dsh/risk_calibration.csv`。

## 25. Round 20：精度–安全 Pareto 曲线（跨两个数据集）

产物：`scripts/dsh_risk_pareto.py` → `results/dsh/risk_pareto.csv`
（每个 w_late 值下，发动机 50/50 划分、拟合非对称偏移、留出评估、100 次重复）

**FD002（RMSE / severe-late）：**

| 单元 | w=1.0 | w=2.0 | w=4.0 | w=6.0 |
|---|---|---|---|---|
| M1 全局参考 + A | **13.10 / 14.02** | 13.64 / 12.15 | 15.33 / 9.27 | **16.37 / 8.43** |
| M6 同特征 Transformer | 14.58 / 15.73 | 15.31 / 13.52 | 16.76 / 9.62 | 17.96 / **7.38** |
| M5 全局参考 + 门控 | 13.74 / 16.79 | 14.64 / 12.54 | 16.22 / 10.33 | 17.42 / 8.85 |

| M0 原始 Transformer | 16.89 / 15.49 | 18.17 / 12.62 | 18.88 / 11.50 | 20.64 / 8.64 |

**FD001（RMSE / severe-late）：**

| 单元 | w=1.0 | w=2.0 | w=6.0 |
|---|---|---|---|
| M1 | **13.56 / 6.36** | 13.92 / 5.24 | 16.69 / 2.74 |
| M4b | 13.13 / 6.03 | 13.79 / 4.04 | 16.42 / 2.41 |
| M6 | 13.52 / 5.70 | 14.05 / 4.66 | **16.45 / 3.32** |

**三条可写进论文的结论：**

1. **权衡是可控且单调的**：w_late 从 1 到 6，severe-late 下降 40–60%，
   RMSE 上升 12–25%。同一套方法可以在曲线上任选工作点。
2. **不存在全域最优**：FD002 上 w=1 时 M1 全面占优（13.10/14.02）；

3. **交换率可量化**：FD002 上大约 **1.5–2.5 RMSE 换 1 个 severe-late**，
   部署方可以据此按成本比选工作点。

**这构成了本研究的正面贡献**：不是"更准的模型"，而是
**"在给定成本比下，如何在精度与晚报风险之间选点"的可复现证据链**，
并附带两条被否定的机制假设与一项评估协议批判。

## 26. Round 23：预登记复验结果（split_seed=8）——规则判定"支持"，但更基本的结论被推翻

**按预登记规则（先于结果写死）评估 M1 vs M6：**

| 判据 | 阈值 | 实测 | 是否满足 |
|---|---|---|---|
| 中位差 | < 0 | **−1.713** | ✓ |
| P(M1 更好) | ≥ 0.80 | **0.885** | ✓ |
| severe-late | ≤ 1.1 × M6 | 28 vs 35（阈值 38.5） | ✓ |

**规则判定：支持。**

**但必须同时报告：配对差的 95% CI = [−4.29, +1.04]，仍跨零。**
我的预登记规则只要求 P ≥ 0.80，没有要求 CI 排除零——这是**预登记本身的宽松缺陷**，
我不据此宣称统计显著。诚实表述是：
**"方向在新划分上重现（P=0.885），但未达到 95% 显著。"**

**更重要的发现：更基本的结论没有复现，甚至反转。**

split_seed=8 上的重采样均值：

| 单元 | split 7（主线） | split 8（复验） |
|---|---:|---:|
| M0 原始 Transformer | 13.320 | **13.221** |
| M1 全局参考 + A | 12.029 | 13.475 |
| M6 同特征 Transformer | 13.577 | 15.147 |

* **M0 vs M6**：split 7 上 M6 更好（13.58 vs 13.32，P=0.57 接近持平）；
  split 8 上 **M0 明显更好**（13.22 vs 15.15，P=0.848）。
  → "加入参考残差特征能改善 Transformer"这一结论**没有复现**。
* **M1 vs M0**：split 7 上 M1 好 1.29；split 8 上 **M0 略好**（13.22 vs 13.47）。
  → "通道独立主干 + 特征优于原始 Transformer"**没有复现**。
* 唯一在两个划分上一致的是：**M6（特征 + Transformer 主干）最差**。

**结论（必须取代此前全部性能表述）：**

1. 本研究中**没有任何方法层面的优势能跨划分复现**；
2. 之前观察到的 M1 优势、特征优势，**均为 split_seed=7 特有的现象**；
3. 唯一可复现的规律是"**把参考残差特征接到标准 Transformer 主干上会变差**"
   ——这是一个负向的方法学提示，而非正面贡献。

**这与 Round 16 的发现一致并强化**：C-MAPSS 上的方法排序对评估选择
（截断点、划分）极度敏感，单次划分/单点截断足以制造 1.5–2.5 RMSE 的"优势"。

**预登记已执行完毕，此后不再对同一候选调参。**

## 27. Round 30：传感器对应关系消融——机制闭环（决定性证据）

**设计**：保持原始传感器通道完全对齐，仅把 14 维"逐传感器健康基线残差"在传感器之间
随机置换（同一模型、同划分、同预算、同种子）。

| 条件 | seed 2027 | seed 2028 | seed 2029 | 平均 matched |
|---|---:|---:|---:|---:|
| **特征与传感器对齐**（M1） | 12.63 | 12.80 | 13.35 | **12.93** |
| **特征在传感器间打乱** | 34.36 | 40.67 | 36.75 | **37.26** |

**打乱后误差上升 2.9 倍，三个种子无一例外。**

这一结果排除了"这些特征只是增加了输入维度/噪声"的解释——如果是那样，打乱应当
几乎无影响；实际是灾难性退化。说明**特征携带的是传感器级别的退化信息，
必须与对应传感器绑定**。

结合三划分结果，机制链条闭合：

1. 逐传感器参考残差只有在**通道独立**处理时才保留其"每个传感器一条信息"的结构；
2. 标准 Transformer 在输入层立即混合通道 → 结构被破坏 → 同一套特征有害
   （三划分一致 +0.81）；
3. 通道独立主干（A）保留了结构 → 稳定优于同特征 Transformer（−1.70 ± 0.24）；
4. 打乱传感器对应 → 结构被破坏 → 误差上升 2.9 倍（决定性）。

**这条机制是本项目唯一同时具备（i）数学上可陈述、（ii）三划分复现、
（iii）有针对性证伪实验支持 的正面发现。**

## 28. Round 31：打乱消融在 FD001 上复现（更强）

| 数据集 | 对齐（M1） | 打乱 | 倍数 |
|---|---:|---:|---:|
| FD002（六工况） | 12.93 | 37.26（34.36/40.67/36.75） | **2.9×** |
| FD001（单工况） | 12.40 | 50.41（46.72/53.19/51.33） | **4.1×** |

**两个数据集、各三个种子，打乱传感器对应关系都把误差抬升 2.9–4.1 倍。**

单工况上的效应更大，说明这些"逐传感器健康基线残差"携带的信息在被错配时
不是"无用的噪声"，而是**方向错误的信号**——模型会把它当作真实退化证据使用。

**机制主张至此具备：**

* 数学陈述：特征 `b_s(t) = x_s(t) − x̄_s(早期)` 是**逐传感器**量，其语义依赖于 s 的身份；
* 三个划分的交互证据（−1.70 ± 0.24 与 +0.81）；
* 两个数据集的破坏性消融（2.9× / 4.1×）；
* 由此得到的可操作结论：**这类特征必须配通道独立的主干；配标准 Transformer 会变差，
  错配传感器会灾难性失败。**

这是可以写进论文的方法学结论，且**不依赖"我们的模型更好"**——它是对一类特征使用方式的
因果性说明。
