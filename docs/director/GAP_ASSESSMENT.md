# 差距评估（面向高水平审稿，P4）

## 现在能主张什么（有证据）

1. **机制**：逐传感器健康参考残差要求通道独立主干；错配传感器身份会灾难性退化
   （FD002 2.9×、FD001 4.1×，各 3 种子）。
2. **评估**：单点/单划分评估的方差足以翻转方法排序（三划分效应量 −1.46 ~ −1.94，
   且 M1 vs M0 符号翻转）。
3. **两条否定性结论**：分工况健康参考有害（同种子差 3.77）；证据门控与固定门控不可分（P=0.538）。
4. **权衡工具**：非对称风险校准把 severe-late 降 30–40%，代价 3.4–8.4% RMSE。

## 现在不能主张什么

1. **没有**统计显著优于任何强基线的单一模型（所有单划分 CI 跨零）；
2. **没有**外部数据集验证（FD003/FD004 封存，无独立来源数据）；
3. **没有**文献核实的新颖性（IEEE 全文付费墙，8–12 篇对照表未完成）；
4. **没有**五种子确认（除 M1/M6/M0 的三种子外）。

## 面向审稿的主要风险

| 风险 | 严重度 | 现状 |
|---|---|---|
| "通道独立"是已知技术（PatchTST 等），交互结论可能已有人报告 | **高** | 未核实，必须先查文献 |
| 单划分不显著，审稿人会质疑效应量 | 高 | 以三划分一致性 + 破坏性消融回应，但需在正文明确 |
| 无外部验证 | 中高 | 数据权限受限，需如实声明 |
| 基线偏弱（无文献方法复现） | 中高 | 未实现任何已发表方法 |

## 若要达到"高于 TIM 常规水准"，还需要的三件事

1. **文献对标**（最关键）：至少 5 篇可读原文，证明交互结论未被报告，或明确增量；
2. **一个已发表方法的公平复现**作为第三基线（同切分、同预算、同特征）；
3. **外部或半外部验证**：哪怕是同源不同子集，也需明确披露重合。
