## 二、对 Claude 原 LSC-RUL 三头提案的数学修正

原式 `phi=c/T_hat` 和 `RUL=T_hat*(1-phi)` 恒等于 `RUL=T_hat-c`。所以：

- 仅仅在最终输出层使用 `phi` 没有模型创新；RUL与寿命的一致性损失恒等于0，必须删除。
- 已运行周期 `c` 输入寿命尺度头，不能再声称网络没有时间捷径；应以 **age-only** 和 **age+operating-settings** 对照实际检验传感器信息增量。
- `HI=sum softplus(increment)` 只保证数学单调，不保证表示的是物理退化。必须审计 `HI` 是否只等于时间累加器；不能将它自身等同于信息增量或新颖性。
- 对数正态总寿命在已存活到 `c` 的条件下必须使用 `T>c` 的**截断条件分布**，训练似然采用 `log p(T|x)-log P(T>c|x)`，对失效前样本 `c<T` 有效；不要把0/125的封顶标签视为真实失效时间。若临近终点的风险不符合对数正态，用离散风险模型进行有约束的等预算比较。
- 早报/晚报不应靠大幅调整非对称权重破坏概率校准。应保留 proper loss（NLL等）并在分离的决策层采用成本敏感分位数或阈值。

## 三、阶段1：寿命尺度的可辨识性闸门（现在执行）

使用附带 `lsc_feasibility.py`，它通过现有 `src/dataset.py` 读取 `train_FDxxx.txt`，仅在训练集内划分发动机，按相同绝对年龄的前缀预测真实**完整寿命T**。

运行：

```bash
cd /home/user/yr/zxk/bearing-rul-pi
# 将交付的 lsc_feasibility.py 放在项目根目录
PYTHONPATH=src python lsc_feasibility.py --subsets FD002 \
  --data data/CMAPSS --out results/lsc_probe/fd002.json
PYTHONPATH=src python lsc_feasibility.py --subsets FD001 FD002 FD003 FD004 \
  --data data/CMAPSS --out results/lsc_probe/all_fleets.json
```

方法固定：5个 engine-disjoint 折，训练折拟合 `OperatingConditionScaler`，固定绝对观测周期 c∈{50,75,100,125,150,175,200}。某发动机未存活到 c 时不进入该c的条件样本。所有模型只看 `x_{1:c}`、`u_{1:c}`、`c`，完整寿命仅作开发训练/验证标签。所有训练前缀对每台发动机**总权重相同**。

三臂、相同 HGB 算法/训练预算：

- A0：仅已运行周期 c，衡量存活选择条件带来的寿命信息；
- A1：c + 工况统计，衡量可观测工况信息；
- A2：c + 工况 + 前缀传感器水平、趋势、方差、早晚差，衡量传感器增量。

按每个 c 报告 `corr(T_hat,T)`、寿命MAE/RMSE、系统偏差、年龄+工况基线相对增益；独立重抽样单位为发动机。额外报告年龄基线残差与传感器模型增量的相关。全局混合年龄的相关系数不可替代分年龄证据。

**解读：** 旧研究中要求相关系数≥0.5的阈值是一个预登记门槛，不是科学定理。现在应同时看条件残差增量及配对bootstrap；高相关但不优于A1并不算有效发现。HGB在此是廉价的可辨识性探针，不证明神经网络学习的最终上限。

## 四、阶段2：如果可辨识性通过，设计真正改变前向计算的结构

**候选名称：Phase-Conditioned Degradation Transformer (PCDT-RUL)**，该名称仅作工作代号，**不预先宣称原创**。

1. **因果传感器编码器**：工况归一化后的14传感器、工况、已运行周期。主骨干采用现有Transformer；所有编码只访问当前及历史观测。
2. **单调退化状态**：`a_t=softplus(g(e_{≤t},u_{≤t}))`，`h_t=h_{t-1}+a_t*Δt`。这只是物理合理性约束，不独立算创新。确保无新观测时与持续时间增长时的定义一致。鼓励健康阶段近零增量；以训练引擎终点标签可构造校准锚，不在验证或测试引擎上使用终点值。
3. **先导寿命分布**：由当前HI、HI趋势、传感器状态和运行年龄得到初步 `p0(T|prefix,T>c)`。输出有不确定性的尺度，不是固定寿命常数。`T_hat0`应是该生存条件分布的期望或明确的分位数。
4. **真正的相位条件计算算子**：先导尺度作用于Transformer内部的**相对相位位置偏置或时间核**，例如 `B_ij=b((i-j)/T_hat0, uncertainty(T0))`，在传感器特征汇聚和寿命分布更新之前生效；在置信度低时可退回常规绝对时距处理。这与最终输出后计算 `c/T_hat` 不同：改变了输入特征如何被编码和交互，具有可独立消融的作用。
5. **最终生存分布与RUL读出**：基于相位重编码预测 `p(T|x_{≤c},T>c)`，RUL分布为 `T-c` 的平移；预测值、区间、失败视野概率由同一个分布导出。避免再开一个代数恒等的RUL头。

**核心科学假设：** 若设备存在可以从前缀推断的寿命尺度，则时间差除以该尺度将改善对不同退化速率的跨设备对齐，尤其减少短寿命机组的系统性高估；该假设在强年龄/条件基线下必须由实验验证。

**原创性闸门**：重点审查寿命比例归一化、time warping、relative positional attention、单调HI、deep survival、multiplicative time embeddings是否已有等价实现。仅将它们叠加不能当创新；只有条件时间核的数学作用、机制消融及相近工作实质差异均成立，才能主张原创算子。

## 五、必须采用的有效训练与检验

- 训练目标：真实完整寿命 `T`，不使用官方125截断做寿命似然。对每台完整训练发动机构造多个外生绝对周期前缀 `c<T`，发动机级均衡加权。
- 不使用 `c=0.5*T_true` 或完整寿命决定的截断窗口进行确认性验证；不为留出设备计算任何使用其未来健康轨迹的特征。
- 预测分布若为对数正态，显式考虑 `T>c` 的截断生存似然；检查极端寿命、数值稳定性以及参数预测是否退化到年龄。
- 多任务损失：真实T的proper NLL（主）；适量RUL平方误差或Huber（辅助）；仅当存在独立定义时添加HI约束。删除恒等式一致性损失；所谓单调性若已结构保证，不再对同一约束重复计罚。
- 统一强基线：原plain Transformer、同参数LSTM、age-only/age+工况、多任务但无相位偏置的Transformer、仅HI、仅寿命头、仅时间缩放、随机错配寿命相位与oracle-仅研究用上界。
- 主要指标：五折×≥3 seeds 的发动机级配对RMSE与NASA分数；短/中/长寿命组相对误差及高估概率；离散/分位点概率分布的NLL、CRPS、区间覆盖和宽度；按相同绝对年龄评估T预测的条件相关及MAE；运行代价。跨窗口评估应以设备为统计独立单位。
- 官方 C-MAPSS test已经在历史研究反复查看：视为探索性，不得将其作为新结构调参环节。新结论优先来自开发集engine-disjoint持出及后续独立数据集。
- 依实际预登记做 GO / NO-GO。若只获得寿命头监督带来的增益，而相位条件算子移除后不损失性能，认定为多任务学习、不是新的框架贡献。

## 六、汇报时应准确表述的研究进展

“已经诊断出模型对短寿命发动机系统性高估；真实寿命oracle相位曾在FD002某一开发探针上提供8.23周期的RMSE差距，但它含有部署时不可得到的真寿命。严格修复未来泄露后，历史线性寿命估计器的corr仅0.196，未显示可检测的性能改进。因此我们正在先检验传感器前缀是否含有超出已运行时间与工况的总寿命信息，再考虑在Transformer内部使用预测寿命尺度调节相对时间核，并以同骨干消融证明机制效应。目前它是有针对性的研究假设，而不是已完成的模型创新成果。”
