# 机制陈述：逐传感器参考残差必须与通道独立主干匹配

状态：证据闭合（三划分 + 两个数据集 + 破坏性消融）。以下为形式化陈述。

## 1. 定义

对发动机 `i`、传感器 `s`、时刻 `t`：

```
健康基线   x̄_s^(i) = mean{ x_s(i, τ) : τ ≤ τ_0 }         （τ_0 = 前 5 周期）
参考残差   b_s^(i)(t) = x_s(i,t) − x̄_s^(i)                 （逐传感器）
EMA        e_s^(i)(t) = β e_s(t−1) + (1−β) x_s(t),  β=0.5
周期坐标   c(t) = min(t / 300, 1)
```

输入表征：`z_s(t) = [ x_s(t), b_s(t), e_s(t), c(t) ]`，每个传感器一条独立的 `z_s`。

## 2. 主张（可证伪）

> `b_s` 是**带身份**的量：它的语义是"传感器 s 相对其自身健康水平的偏离"。
> 只有在主干**先按传感器独立编码**（不跨通道混合）时，这一身份才被保留；
> 一旦主干在输入层混合通道，`b_s` 的语义被破坏，同一套特征从有益变为有害。

## 3. 三条推定预测与检验结果

| 预测 | 实验 | 结果 |
|---|---|---|
| P1：同特征下，通道独立主干优于混合主干 | A vs tfA，三划分 | **−1.70 ± 0.24，三划分一致** |
| P2：特征接到混合主干上会变差 | tfA vs 原始 Transformer，三划分 | **+0.81，三划分全为正** |
| P3：破坏 `s` 身份应使优势消失并造成严重退化 | 固定通道、置换 14 维 `b` | **FD002 12.93→37.26（2.9×）；FD001 12.40→50.41（4.1×）** |

P3 是关键：若 `b` 只是"额外输入维度"，置换应几乎无影响；实际是灾难性退化。

## 4. 适用边界

* 数据：多传感器、传感器位置固定、存在可辨识的早期健康阶段；
* 特征：任何**逐传感器**的健康参考类特征（`b_s`、逐传感器统计量、逐传感器趋势）；
* 主干：必须保持通道独立（per-sensor 编码 + 跨传感器/时间共享权重）；
* 不适用：已经做过跨传感器手工融合的特征；传感器数量/顺序在部署时变化的场景。

## 5. 与已有工作的差异（**待文献核实，切勿写成已确立**）

"通道独立处理"在长时序预测（PatchTST 一类）中已有先例；本工作的差异点在于：
**不是"通道独立能提升精度"，而是"逐传感器健康参考特征的有效性以通道独立为前提，
错配会造成数量级退化"**。这一交互是否已被报告，需要拿到相关原文才能判断。
在核实前，本文件只作为**本项目的实验结论**，不作为对外的创新主张。

## 6. 测量学解释

`b_s` 是逐通道的**测量偏差**估计（相对该通道自身基线）。它的物理意义绑定在
具体测点上；把它跨测点混合等于把不同物理量的偏差相加，得到的是无意义的量。
这解释了为什么错配比缺失更糟：错配的特征仍然"看起来像"退化信号，
模型会照常使用它，只是用在了错误的测点上。
