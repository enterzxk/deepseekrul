## 2. 请求：3 个单元，检验风险感知训练

**科学问题**：现有模型优化的是条件均值，因此晚报率（0.46）无法通过训练直接控制；
只能在事后整体下移估计（见共形实验），代价是大量提前更换（α=0.2 时 43% 提前 >10）。
**若改为直接优化条件分位数（如 τ=0.1 或 τ=0.25）**，模型会在训练中学会“倾向低估”，
从而在**不整体平移**的前提下降低晚报率。

**可证伪预测**：
1. 分位数模型与均值模型预测相关 **< 0.95**（可分辨性门槛）；
2. 晚报率显著低于 0.462，且严重晚报（>10）减少；
3. RMSE 上升（这是预期代价），但上升幅度小于事后下移同样晚报率所需（共形 α=0.2 时 RMSE 与宽度代价已知）；
4. **若 1 不成立**（相关仍 >0.97），该路线放弃。

**预算**：3 个单元（1 配置 × 3 种子），并发 ≤3。

**前置检查（不花预算）**：先用现有 predictions 估算“若整体下移 X 使晚报降到 0.25，RMSE 会变成多少”，
作为分位数模型必须打败的基线。若该基线已经很难打败，则不申请训练。
