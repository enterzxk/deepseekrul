# 预登记：重划分复验（DSH，2026-10-21 编写，结果未出）

## 目的
检验"参考残差特征变体优于同特征 Transformer"这一结论能否在**另一个发动机划分**
上重现。这不是独立数据（同一批 FD002 训练文件、同一批发动机池），只是不同划分，
**不得**表述为"未见数据验证"。

## 固定的实验设置（写在此处，不得事后更改）
- 数据：FD002（多工况），官方 test 未使用，FD003/FD004 封存。
- 划分：`split_seed = 8`（开发主线一直用 7，本检验首次使用 8）。
- 单元：M1（A 主干 + 全局参考特征）、M6（同特征 Transformer）、M0（原始 Transformer）。
- 种子：2027 / 2028 / 2029，各 30 epochs，patience 10，d_model 64，1 层。
- 损失：与主线完全一致（late_weight = 1.8）。
- 预算：9 个单元（≤ 18）。

## 固定指标（写在此处，不得事后更改）
主指标：**随机单点重采样的中位差与 P(更优)**（`scripts/dsh_resampled_metric.py`），
因为单点 matched-cutoff 已被证明会被截断实现翻转（Round 16）。

同时报告：pooled/macro Protocol B、Protocol C、NASA、late_fraction、severe-late、
发动机级配对 bootstrap 95% CI。

## 固定的判定规则（看到结果前写死）
设 Δ = median(RMSE_M1 − RMSE_M6)（负值表示 M1 更好）。

1. **支持**：Δ < 0 且 P(M1 更好) ≥ 0.80 且 severe-late 不高于 M6 的 1.1 倍；
2. **不确定**：Δ < 0 但 P < 0.80，或 CI 跨零；
3. **不支持**：Δ ≥ 0，或 severe-late 超过 M6 的 1.1 倍。

无论落在哪一档，**结果只报告一次，不再用于修改同一候选**。

## 已知的风险（诚实记录）
- 主线上该效应 P=0.82–0.91 但 CI 跨零，因此**"不确定"是最可能的结果**；
- 重划分只改变 20% 验证发动机的身份，**不改变总发动机数**，因此功效不会提高；
- 若结果落在"不支持"，则主线结论必须收窄为"仅在 split_seed=7 上观察到"。

必须由主控批准新的研究问题与预算，不能在本候选上反复调参。
