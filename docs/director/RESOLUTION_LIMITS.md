# C-MAPSS 评估的分辨率下限（可复算）

产物：`results/dsh/resolution_limits.csv`、`scripts/dsh_resolution_limits.py`、`results/dsh/power_analysis.csv`

## 1. 经验方差

在本项目协议下（FD002，80/20 划分，52 台验证发动机，3 seeds），
**逐发动机 RMSE 配对差的标准差**：

| 统计量 | 值 |
|---|---:|
| 中位数 | **4.24** |
| 25% 分位 | 3.62 |
| 75% 分位 | 4.77 |

样本：78 个方法对，每对 52 台共同发动机。

## 2. 最小可检出效应（80% 功效，α=0.05，配对设计）

`MDE(N) = sd · sqrt((z₀.₉₇₅ + z₀.₈₀)² / N)`

| 发动机数 | MDE（sd=4.24） | MDE（sd=3.62） | MDE（sd=4.77） |
|---:|---:|---:|---:|
| 20（FD001 验证集） | 2.66 | 2.27 | 2.99 |
| **52（FD002 验证集，本项目）** | **1.65** | 1.40 | 1.85 |
| **100（官方 test 规模）** | **1.19** | 1.01 | 1.34 |
| 200 | 0.84 | 0.72 | 0.95 |
| 500 | 0.53 | 0.45 | 0.60 |
| 1000 | 0.38 | 0.32 | 0.42 |

## 3. 这条结果说明了什么

**在官方 test 规模（约 100 台发动机）下，只有当两个方法的 RMSE 差距超过约 1.2
时，才有 80% 的把握被检出。**

而 C-MAPSS 文献中大量被报告为"优于 SOTA"的改进量在 0.3–1.5 RMSE 量级。
这意味着：**其中相当一部分差异处于该基准的分辨率极限附近或以下**，
其可复现性不应被默认为已确立。

## 4. 必须写的限制（防止过度推论）

1. 方差来自**本项目协议**（80/20 划分）。文献常用"全量训练 + 官方 test"，
   训练集更大、模型不同，方差结构可能不同，**MDE 数值不能直接搬到别处**。
   可以搬的是**方法**：任何人可用自己的逐发动机预测复算同样一张表。
2. 该表给出的是**统计分辨率**，不涉及任何模型的优劣判断。
3. 配对设计假设同一台发动机被两种方法共同评估，这是标准做法，但要求逐发动机预测公开。
4. 4.2 的 sd 是**本基准上的经验值**；不同子集（FD001 vs FD002）差异明显
   （FD001 只有 20 台，MDE 约 2.7）。

## 5. 可操作建议（面向作者与审稿人）

1. 报告**逐发动机预测**与**配对 CI**，而不只是单点 RMSE；
2. 报告**达到结论所需的样本量**；
3. 避免"每机取一个截断点"的单点评估，改用重采样分布；
4. 当改进量小于该基准的 MDE 时，使用"观察到的差异"而非"优于"的措辞。

## 6. 与文献的关系

arXiv 2610.04278（RUL 归因稳定性）研究的是**解释的稳定性**；
本文这一条研究的是**指标的分辨率**。二者互补，但不重复。
arXiv 2610.01530 研究**非对称代价的超参优化**，与分辨率问题无关。

## 7. 自证伪检验：预测失败（重要更正）

**预测**：发动机越少 → MDE 越大 → 未定排序的配对比例越高。
按 MDE 表，20 台（FD001）应明显高于 52 台（FD002）。

**实测**（同一脚本、同一重采样流程，`scripts/dsh_resolvability_check.py`）：

| 数据集 | 发动机 | 单元数 | 配对数 | 未定比例（0.25<P<0.75） | 抛硬币（0.4–0.6） |
|---|---:|---:|---:|---:|---:|
| FD002 | 52 | 13 | 78 | **46.2%** | 26.9% |
| FD001 | 20 | 7 | 21 | **42.9%** | 14.3% |

**预测失败**：20 台发动机的未定比例并不更高，反而略低。

### 原因

MDE 是**逐对**的量：`MDE = sd·sqrt(Z/N)`。**未定配对的比例**还取决于
被比较方法集合中**真实效应量的分布**。FD001 上我比较的 7 个单元差异本来就大
（10.9–14.1 RMSE，跨度 3.2），因此尽管 N 更小，配对仍更容易被分辨。

### 因此必须修正的两处表述

1. **"44.9% 的方法对无法分辨"不是该基准的普遍属性**，而是
   **"在我这 13 个单元构成的方法集合上"** 的属性。换一组方法，这个比例会变。
2. **能普遍主张的只有 MDE 公式与 sd 的经验值**：
   `MDE(N) = sd·sqrt(7.85/N)`，`sd ≈ 4.2`（本协议下）。
   由此得到"100 台发动机时约 1.2 RMSE"这一**量级**结论依然成立，
   但"某比例的对比不可分辨"必须绑定到具体的方法集合。

### 这条更正的意义

它把原本容易被审稿人攻击的"普遍性主张"收缩为可辩护的"条件性结论"。
如果我不做这个检验就写进论文，"44.9%"会被正确地指为对特定集合的过拟合描述。

## 8. 分辨率的不确定度（Bootstrap，2000 次）

因为 MDE 完全由 sd 决定，所以给 sd 加区间即可给 MDE 加区间。
做法：对 52 台发动机重采样（同时保持配对结构），重算 78 个配对的 sd 中位数。

| 量 | 点估计 | 95% CI |
|---|---:|---|
| sd（配对的逐发动机 RMSE 差） | **4.11** | [3.64, 4.58]（按发动机重采样） |
| | | [3.60, 4.68]（按配对重采样） |

由此得到 MDE 的区间：

| 发动机数 | MDE | 95% CI |
|---:|---:|---|
| 52（本项目） | 1.60 | [1.41, 1.78] |
| **100（官方 test 规模）** | **1.15** | **[1.02, 1.28]** |
| 200 | 0.81 | [0.72, 0.91] |
| 500 | 0.52 | [0.46, 0.57] |

**最终可普遍主张的表述（带不确定度）**：

> 在本项目的评估协议下，逐发动机 RMSE 配对差的标准差为 **4.11（95% CI [3.64, 4.58]）**；
> 因此在约 100 台发动机上，**小于约 1.15 RMSE 的差异（95% CI [1.02, 1.28]）
> 在 80% 功效、α=0.05 下无法被稳定检出。**

这一句是可以写进摘要的：它有明确的定义、可复算的脚本、附带区间，且不依赖任何模型优劣。

产物：`results/dsh/sd_bootstrap.csv`、`scripts/dsh_sd_bootstrap.py`。
