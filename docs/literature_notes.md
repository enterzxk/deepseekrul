# 文献精读笔记：RUL 与时序 Conformal 校准的六篇工作

## 对比表

## 1. Similarity-calibrated conformal prediction（SCC）

**解决什么问题**：conformal 的覆盖保证依赖可交换性；源工况校准、目标工况部署时该假设失效，区间"静默"失覆盖。加权 conformal 需目标域失效数据，无量纲迁移学习只改点预测、无覆盖保证（p.1–2）。

**方法与设计**：§3。取单侧分数 V=ŷ(X)−Y，用 Buckingham Π 导出的物理尺度 σ(θ_c) 归一化得 Ṽ=V/σ，取 q̃=Ṽ_(⌈(1−α)(n+1)⌉)，部署时 C(X)={y: s(X,y)≤σ(θ_T)q̃}（p.3）。核心定理：P(Y∈C)≥1−α−2L‖ψ(θ_S)−ψ(θ_T)‖，ψ 是尺度未吸收的相似性偏离，L 由源域 TV 距离对 ‖Δψ‖ 回归得到（p.3、附录 A）。校准按单元而非时间步：同单元三点分数相关 ρ=0.908、设计效应 2.82，故多点监测改用"每单元最大分数"的块校准（p.3）。运行时用 g=median(D|c)/median(D|c′) 的三值判决 holds/violated/indeterminate（p.3–4）。

**实验与结果**：催化剂失活仿真（600/650/700 K，寿命跨 10.2×，400 单元，5 seeds，目标 0.90）。naive 覆盖跌至 0.572，SCC 为 0.891–0.908、平均 gap 0.011（p.4）；随偏离 η 增大 gap 0.011→0.097、back-off 0.283→1.011，可行动边界 η=0.68、退化起点 η=1.97（p.5）。C-MAPSS FD002/FD004（260/249 引擎、30 个有序工况对）：naive 0.590/0.567 → SCC 0.060/0.058（9.8×）；随机森林基线 0.128→0.053（p.6–7）。先验界在 testbed 的 held-out 配置 100% 成立但平均余量 0.339（p.5–6）；C-MAPSS 上两个 ψ 候选的 held-out R² 仅 −0.074~0.022，界不成立（p.7）。

**对本研究的意义**：σ 归一化 + 重标定几乎就是我们 σ_T 方案的物理版，"只传标量分位数"的叙事可直接借用；coverage gap 与 back-off 双指标、actionable/degraded/degenerate 三档值得照搬。差异：其 σ 来自物理 Π 群，我们的 σ_T 来自 PU-Net 后验不确定性；其块校准取每单元最大值以求单元内同时覆盖，我们按引擎/工况分块是为分层诊断；它用 g 检验使相似性前提可证伪，我们用引擎级覆盖诊断。

## 2. Retrieval-Corrected Conformal Prediction（RCCP）

**解决什么问题**：时序残差非平稳，全局分位数在稳定期过保守、波动期不足；局部加权法稀释最相关残差，且检索出的区间本身并不校准（p.1–2）。

**方法与设计**：§3.2–3.3。知识库存一侧残差 e±；KNN 检索 K 个上下文并取加权分位数 R̃±（式 4），得检索区间 [ŷ−R̃⁻, ŷ+R̃⁺]；再以归一化检索误差 B_j=max(e⁺_j/R̃⁺_j, e⁻_j/R̃⁻_j)（式 6）校准，ĉ=Q_{1−α}(B)，最终 [ŷ−ĉR̃⁻, ŷ+ĉR̃⁺]（式 7，p.4）。定理 1 给出 |P−q|≤ρ_n+(2L/m)(e_n+r_n)，把检索失配与校准误差分离（p.5）。

**实验与结果**：Air/Solar/Wind/Electricity，LSTM 与 Transformer 骨干，α=0.1。Air-LSTM：Winkler 92.44 vs SCP 112.55，PI-Width 60.20 vs 62.72（p.6）；Solar-LSTM：26.08 vs 62.87，宽度 18.31 vs 35.24。宽度自适应比（D10/D1）Air 2.30、Solar 20.86，SCP 恒为 1.00（p.7）。K=64 为默认，K∈[32,128] 覆盖稳定（p.8）。

**对本研究的意义**：B_j 的"残差/局部尺度"比值与"用 σ_T 归一化 conformal 分数"同构，且证明归一化后单标量校正即可恢复覆盖，是很有力的写法参照。差异：R̃± 是检索到的经验残差分位数，需邻域支撑；σ_T 是模型先验，在无目标残差时也可给出；RCCP 无分层与引擎级诊断，也不处理跨工况迁移。

## 3. Conformal Prediction for Time Series with Deep Sequence Models

**解决什么问题**：深度序列模型已被大量用于时序 CP，但"如何用、是否有效"缺系统研究；可交换性在时序下失效（p.1–2）。

**方法与设计**：§2。共享编码器 h=Enc(z)，三条接口：DSCP-QR 用多分位头并以非负增量保证单调（p.5）；DSCP-QFE 把头写成 (h,τ) 的部分单调网络，支持任意 τ（p.6）；DSCP-Local 在表征空间做核加权经验 CDF，F̂(u|h)=ΣW_i·1{ε_i≤u} 后反演分位数（p.7）。定理 3.1–3.3 在平稳 α-mixing 下给出渐近条件覆盖（p.8–9）。

**实验与结果**：Air/Solar/Sapflow，LR/LSTM/Chronos，目标 0.9。Air-LSTM：Split CP 的 ΔCov −0.005、PI-W 73.9、WS 137.2；DSCP-QR 为 −0.021/61.1/103.4（p.11）。Solar-LSTM：DSCP-QR −0.006/55.4/84.0，Split CP −0.002/88.1/176.3。Sapflow：DSCP-Local +0.007/632.1/911.4，Split CP +0.022/1318.4/2045.5。DSCP-QFE 系统性欠覆盖（Air-LSTM −0.126），作者归因于部分单调头限制表达力（p.12）。

**对本研究的意义**：把"深度模型当条件分位/局部 CDF 估计器"的三种接口讲清楚了，可作为"模型内生不确定性 vs 后验校准"的对照臂；覆盖/Winkler/宽度三指标组合可直接采用。差异：三者都直接校准残差分布，没有 σ 归一化这一步；理论依赖 mixing，而我们的分块校准正是为绕开该假设。

## 4. Conformal Coverage for Time Series: Validity and Inference

**解决什么问题**：split conformal 只保证边际覆盖，"实测 85% 是否异常"无从判断；时序下实得覆盖率本身是随机变量，长记忆时极限甚至非高斯（p.1–2）。

**方法与设计**：§2–4。分数 V=|Y−μ̂|；以函数依赖测度 θ_k=sup_v‖1{V_k≤v}−1{V*_k≤v}‖₂、Θ=Σθ_k 替代 mixing（式 3–4，p.3）；定理 1 给非渐近界 |P−(1−α)|≤2/n+3(Θ²/4n)^{1/3}（式 5，p.4）；定理 2 为 Bahadur 表示，定理 3 为覆盖率 CLT：√(nm/(n+m))(Cov̂−(1−α))→N(0,σ²_cov)（p.5），并用区组估计 σ̂_cov 构造检验（p.5）；长记忆按 β 分三段极限（定理 6，p.6）。

**实验与结果**：Study 1 用非 mixing 过程，n=2^5 覆盖 88.80%，n=2^12 达 90.19%/95.06%（p.7）。Study 2 的 ARCH/SV 上，5% 拒绝率由 n=2^9 的 10.54%/12.92% 降至 2^19 的 5.49%/5.61%；改用可交换 SE 会低估 1.40/1.97 倍，拒绝率 16.04%/32.10%（p.7–8）。Study 3 在 β=0.6、n=2^20 时区组检验 5.65%，MBB 44.35%、HAC 43.77%（p.8）。真实电力负荷覆盖 91.2%，可交换检验拒绝、区组检验不拒绝（p.9）。

**对本研究的意义**：这是"引擎级覆盖诊断"最直接的方法论来源——先把覆盖率的抽样波动算出来，再判断偏离是否显著，而不是拿点估计下结论。差异：它只诊断、不改进区间，也不涉及 σ 归一化或分层校准；其区组是时间块，我们的块是引擎/工况层。

## 5. Query based learning via conformal uncertainty for RUL prediction

**解决什么问题**：RUL 主动学习中 CP 只当 post-hoc 校准，未用于采样；纯不确定性采样会使样本聚集、探索不足（p.1–2、p.4）。

**方法与设计**：§III。Mondrian conformal regressor 按分箱 κ(x) 分别取残差分位数 q_k，区间 [μ̂−q_k, μ̂+q_k]（式 5–6，p.4）；不确定度 u(x)=Ĉ⁺−Ĉ⁻，多样性 d(x)=到已标注集的最近欧氏距离，采集函数 A=w₁u+(1−w₁)d，w₁ 由贝叶斯优化确定（式 3，p.4），基学习器为 XGBoost。

**实验与结果**：C-MAPSS FD001–FD004，5 seeds、7 轮。FD001（α=0.05）Random 45.53→U-Diversity 41.05；（α=0.1）56.09→52.81。FD003（α=0.1）66.45→59.90；FD004（α=0.1）45.55→41.67（Table II，p.6）。逐引擎 RMSE 为 27.22/23.87/35.72/36.59（p.6）。

**对本研究的意义**：Mondrian 分箱是"分层校准"的一个特例，可作为分层维度的对照基线；"用区间宽度当采集信号"也提示 σ_T 可用于主动采样。差异：它不检验分层是否真换来条件覆盖，无覆盖诊断，也无跨工况尺度归一化；其分层是离散工况标签，我们按引擎/工况块并做诊断。

## 6. Turbofan RUL with Reliable Prediction Intervals via LSTM-QR and Conformal Calibration

**解决什么问题**：点估计无法表征不确定性，分位回归区间在有限样本与工况漂移下覆盖失配（p.1–2）。

**方法与设计**：§3。LSTM 编码 + 三个分位头 τ∈{0.1,0.5,0.9}，一次前向同时给点估计与 80% 区间；加权 pinball 损失（低 RUL 加权、均值归一）加过估计惩罚 L_over=mean max(q̂0.5−y,0)，总损失 L=L_w+λL_over（式 16–18，p.9）。CQR：s_i=max(q̂0.1−y, y−q̂0.9, 0)，δ 取 s 的第 ⌈(n+1)(1−α)⌉ 次序统计量，区间 [q̂0.1−δ, q̂0.9+δ]（式 19，p.10）。

**实验与结果**：C-MAPSS FD001/FD002，3 seeds，RUL 截断 125。同工况 FD001：PICP 0.590→0.800、MPIW 22.822→33.766、RMSE 16.235；FD002：0.722→0.793、MPIW 33.339→37.203、RMSE 18.323（Table 2，p.12）。跨工况 FD001→FD002：0.696→0.806、MPIW 43.108→50.952、RMSE 21.758；FD002→FD001：0.593→0.803、MPIW 25.218→40.888、RMSE 17.562（Table 3，p.14）。基线 MC Dropout-LSTM 的 PICP 仅 0.640，Deep Ensemble 达 0.880 但 MPIW 48.612（Table 4，p.16）。

**对本研究的意义**：最贴近我们数据管线的工程基线（C-MAPSS + 分位回归 + CQR），可作"无 σ 归一化、无分层"的消融端点；PICP/MPIW/RMSE/PHM Score 四件套与 125 截断可直接复用。差异：CQR 只做常数对称扩张 δ，不能随引擎/工况自适应；无覆盖显著性检验；跨工况靠目标域微调而非尺度归一化。

## 综合判断

SCC 与 RCCP 分别在"物理尺度"与"检索尺度"上做了与本方法同构的分数归一化，是最需正面区分的前作；其余四篇分别提供分层校准、覆盖诊断与工程基线的支撑。
