# 04 · 实验协议（预注册，T0+90min 定稿）

> 依据：协议代理的设计 + Codex L2 裁决 + 本轮实测修正。
> 修订点：① 内部验证的"每机末窗口"指标过于容易（RUL≈0），改为**发动机宏平均**为主；
> ② 早停与报告必须用不同发动机（ES/TEST 分层划分）；③ 指标在发动机层聚合，窗口不独立。

## 1. 数据与划分

- 划分：`run_ida.outer_folds(subset, n_outer=5)`，按发动机 5 折，`OUTER_SEED` 固定，全 seed 共用。
- 窗口：`run_ida.prep_fold(window=50, max_rul=125)`；FD002/FD004 用 6 簇工况归一化，FD001/FD003 min-max。
- 验证集再分：`split_es_test(va_u, T, seed=20261110)`，按寿命排序交替分半 → **ES（早停）/ TEST（报告）**，
  两半发动机互斥，早停永不看 TEST 机。
- 训练 seed：{42, 7}（本轮）；划分 seed 与训练 seed 分离。
- 归一化统计只来自训练机；官方测试集**不参与**任何选择。

## 2. 臂

### A2 家族（主）
| 臂 | 机制 |
|---|---|
| `R` | 直接回归（d_T, r_T 置零，头宽相同） |
| `A2` | 完整：非减退化水平 + 工况调制速率 + 瞬态 + 事件条件连续性惩罚 |
| `A2-NE` | 去掉事件连续性惩罚（λ_cont=0） |
| `A2-NR` | 去掉显式速率调制（γ=0） |

### C 家族（对照，收窄为 FD002）
| 臂 | 机制 |
|---|---|
| `M0` | 直接回归 + 辅助事件分类 |
| `M1` | 耦合输出 `125p+(1−p)m` |
| `M2` | M1 + 对 p 停止梯度 |

## 3. 指标

| 指标 | 定义 | 用途 |
|---|---|---|
| **`rmse_macro`** | 每机先算 MSE，再对发动机取均值后开方 | **主指标**（避免末窗口平凡、避免窗口池化） |
| `mae_macro` | 同上，MAE | 辅助 |
| `rmse_at60` | 每机取 `y_true` 最接近 60 的窗口，跨机 RMSE | 固定操作点，跨臂可比 |
| `rmse_last` | 每机末窗口 | 仅参考（内部验证里 RUL≈0，过于容易） |
| `pooled_rmse` | 窗口池化 | 仅与文献口径对照，不作判定 |
| A2 机制 | `switch_ratio` = 切换步 Δd 均值 / 非切换步 Δd 均值；`spearman_dT_rul` | 机制是否发生 |
| C 机制 | `brier` vs `base_brier`（事件概率校准） | 耦合是否可信 |

## 4. 判定门（预注册，来自 Codex D035）

- **A2 效用门（探索）**：FD002 与 FD004 各自、相对 `R` 的 `rmse_macro` 改善 ≥1%，且 2 seed 同向。
- **A2 机制门**：`switch_ratio ≤ 1.25`（且分母高于非塌缩阈值）；`A2` 相对 `A2-NE` 的改善 ≥50% 来自事件约束
  （即去掉后改善至少损失一半）；`A2` 相对 `A2-NR` 同样。
- **A2 防塌缩**：`d_T` 的读出必须对预测有非零作用（置换 d_T 后预测显著变化）。
- **C 升级门**：`M1` 稳定优于 `M0`，且 `M2` 至少损失 `M1` 相对收益的 50%，并排除梯度尺度解释；
  否则 C 只作协议对照。

## 5. 预算与运行矩阵

| 批次 | 运行数 | 预计 | 状态 |
|---|---|---|---|
| C：FD002 × 2 seed × {M0,M1,M2} | 6 | ~1.5 h（4 路） | 4 完成 / 2 运行中 |
| A2：FD002,FD004 × 2 seed × {R,A2,A2-NE,A2-NR} | 16 | ~2 h（4 路） | 排队（等 C 排空） |
| 汇总与消融分析 | — | 0.5 h | — |

**实测**：FD002 单格约 25–35 min（4 路并发时），比历史 14.5 min 慢，原因是并发与更重的评价。

## 6. 失败分支

- A2 未过效用门 → 检查机制门：若机制门过而效用门不过，记为"机制真、效用假"，保留为诊断；
  若机制门也不过，A2 关闭，转 B2。
- C 未过升级门 → 只作协议对照，不进入 TIM 主张。
