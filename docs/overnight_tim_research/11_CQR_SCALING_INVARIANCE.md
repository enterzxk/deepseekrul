# CQR 缩放的校准抵消：精确结论与适用范围

> 修订版（2026-11-10）。上一版把"乘性收缩"与"加性收缩"写成同构，**过强**。
> 本版区分三种不同操作，并写明各自成立的条件。不重做大规模训练。

## 0. 记号

基础区间 $[l_i,u_i]$，中心 $c_i=(l_i+u_i)/2$，半宽度 $w_i=(u_i-l_i)/2\ge0$。
CQR 分数（标准形式）：

$$s_i=\max\{l_i-y_i,\ y_i-u_i\}=|y_i-c_i|-w_i .$$

校准：$\hat q=\mathrm{Quantile}_{1-\alpha}\big(\{s_i\}\cup\{+\infty\}\big)$，
输出 $\hat C(x)=[l(x)-\hat q,\ u(x)+\hat q]$。

## 1. 结论一：统一**加性**收缩被精确抵消（成立）

设 $l_i'=l_i+\delta,\ u_i'=u_i-\delta$（$\delta$ 任意实数）。则

$$s_i'=\max\{l_i+\delta-y_i,\ y_i-u_i+\delta\}=s_i+\delta .$$

这是**对所有 $i$ 相同的常数平移**，分位数平移等变：$\hat q'=\hat q+\delta$。于是

$$
[l_i'-\hat q',\ u_i'+\hat q']
=[l_i+\delta-\hat q-\delta,\ u_i-\delta+\hat q+\delta]
=[l_i-\hat q,\ u_i+\hat q].
$$

**与不收缩完全一致。$\square$**

## 2. 结论二：样本相关半宽下的**乘性**收缩**不**被抵消（修正）

设围绕中心收缩：$l_i'=c_i-\lambda w_i,\ u_i'=c_i+\lambda w_i$（$\lambda\in(0,1)$）。则

$$s_i'=|y_i-c_i|-\lambda w_i=s_i+(1-\lambda)\,w_i .$$

**这是样本相关的平移**：位移量 $(1-\lambda)w_i$ 随 $i$ 变化。
因此：

1. $s'$ **不是** $s$ 的全局严格递增变换（除非所有 $w_i$ 相同）；
2. $s'$ 的**排序可以改变**——半宽度大的样本被抬得更多；
3. $\hat q'=\mathrm{Quantile}\big(s+(1-\lambda)w\big)\neq \hat q+(1-\lambda)\bar w$（一般情形）；
4. 输出区间 $[c-\lambda w-\hat q',\ c+\lambda w+\hat q']$ **一般不等于**原区间。

**只有在 $w_i\equiv w$（共同半宽度）时**，位移才退化为常数 $(1-\lambda)w$，
$\hat q'=\hat q+(1-\lambda)w$，输出 $[c-\lambda w-\hat q-(1-\lambda)w,\ \dots]=[c-w-\hat q,\ \dots]$ 才精确抵消。

> 上一版写成"乘性收缩同样被抵消"，是把"以共同尺度 $\sigma$ 参数化的区间"当成了通例。
> 对 $w_i$ 逐样本变化的情形，该结论**不成立**。

## 3. 结论三：全局分数变换的不变性 ≠ 缩小原始区间

对**分数函数本身**施加严格递增变换 $g$：

$$\hat C_g(x)=\{y:\ g(s(x,y))\le g(\hat q)\}=\{y:\ s(x,y)\le\hat q\}=\hat C(x).$$

**保形集合不变**——这是保形预测的一般性质（分数是任意的非一致性度量）。

但"缩小原始预测区间"改变的是**分数函数在 $x$ 上的依赖方式**（通过 $w(x)$），
不是对分数做全局变换。因此第 3 节的不变性**不能**用来论证缩放无效。

**两件事必须分开**：

| 操作 | 数学对象 | 是否改变保形集合 |
|---|---|---|
| 对分数施加严格递增 $g$ | $g\circ s$ | 否（集合不变） |
| 缩小原始区间（$\lambda$ 或 $\delta$） | $s$ 的定义随 $x$ 改变 | 加性：不变；样本相关乘性：**一般会变** |

## 4. 因此：什么条件下缩放才可能带来真实改变

| 条件 | 说明 | 是否保持 $1-\alpha$ |
|---|---|---|
| 加性统一收缩（常数 $\delta$） | 精确抵消 | 是，但等于没做 |
| 乘性收缩 + 共同半宽度 | 精确抵消 | 同上 |
| **乘性收缩 + 样本相关半宽度** | **不抵消**，排序改变 | 重新校准后仍保持 $1-\alpha$（保形保证来自校准，不来自收缩） |
| 校准后直接缩小区间 | 改变已校准集合 | **否**，覆盖会掉 |
| 条件化（分组/分桶各一个 $\hat q$） | 改变分配 | 边际保持，条件改变 |
| 作用在中心 $c_i$ | 偏差修正 | 是（不是分数变换） |

**关键**：第 3 行说明——对样本相关半宽度做乘性收缩**不是恒等操作**，
它可以改变"哪些样本被覆盖"的分配，同时仍保持边际 $1-\alpha$。
**但它是否改善设备级下尾，必须用实验判定，不能由数学断言。**
（本项目已做的年龄分桶实验是"条件化"一类，结果为负；乘性收缩一类尚未实验。）

## 5. 可检验推论

若有人报告"对 CQR 收缩再校准带来收益"，该收益必然来自：
(a) 收缩是样本相关的乘性（改变排序）；(b) 收缩是条件化的；
(c) 校准集与收缩参数不独立（泄漏）；(d) 指标是宽度类（Winkler）而非纯覆盖率，
且收缩改变了中心或分配。这四条可直接用于审稿质疑。

## 6. 对项目的处置

- **不把"缩放恒等"当作否定整类方法的理由**；只否定"统一加性/共同尺度乘性"这一子类。
- 样本相关乘性收缩 + 设备级下尾评估，是一个**尚未实验**的条目；
  但它属于 C-MAPSS 冻结线，本轮不启动（见主线冻结决定）。
