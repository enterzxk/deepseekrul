# 候选机制规格：前缀一致的失效时间 hazard 模型（PCH）

> 依据 Phase 1 结论：设备级失效**不能提前预测**（前缀 AUROC 0.52–0.61），
> 因此新机制不能建立在"风险可预测"上；它必须改变**训练/更新机制**，而不是加一个输出头。
> 查新状态：**未完成**。已确认离散时间 neural hazard 是标准做法，本规格的差异点尚未核实是否被占。

## 1. 对象

对当前时刻 $t$、预测期限 $h\ge0$，建模

$$S_t(h)=P\big(T_{\text{fail}}>t+h \mid X_{\le t}\big),$$

其中 $T_{\text{fail}}$ 是**绝对失效周期**（不是截断 RUL）。由 $S_t$ 可直接导出：
点预测（$S_t$ 的中位寿命）、90% 区间、$P(T\le t+30)$、$P(T\le t+60)$，
以及随 $t$ 增长的在线更新。

## 2. 机制：前缀一致性约束（训练期，不是输出头）

正确的条件生存函数必须满足**链式法则**：

$$S_t(h)=\mathbb E\big[S_{t+1}(h-1)\mid X_{\le t}\big].$$

训练数据里有**已实现的** $X_{t+1}$，因此可以对该等式做**样本级**约束：

$$\mathcal L_{\text{cons}}=\Big(S_\theta(t+h\mid X_{\le t})-S_\theta(t+h\mid X_{\le t+1})\Big)^2,$$

即：用前缀 $t$ 预测的"活过 $t+h$"，应当与用更长前缀 $t+1$ 预测的同一事件概率一致。
这是一个**跨前缀的自监督约束**，它迫使模型在不同历史长度上给出相容的生存曲线，
而不是各自独立拟合。

**为什么这不是"换个输出头"**：输出头只改变参数化；一致性约束改变的是**训练信号**——
它把"同一失效事件的多个前缀视图"绑在一起，等价于在训练中引入一个 martingale 型不变性。

## 3. 与最近邻的差异（待核）

| 最近邻 | 它做什么 | PCH 的差异 |
|---|---|---|
| DeepHit / neural discrete-time hazard（Lifetime Data Analysis 2021 等） | 用神经网络参数化离散 hazard，最大化似然 | 不加一致性约束；各前缀独立 |
| Deep survival with reporting delays（IEEE 11442049, 2026） | 处理左截断/右删失/报告延迟 | 数据机制不同，不涉及前缀一致性 |
| 时间一致性生存预测 | 约束相邻时刻预测的平滑性 | PCH 约束的是**同一事件在不同前缀下的概率相等**，不是平滑性 |
| CRULP / 2026 RUL 风险区间 | 保形区间 | PCH 不用保形，直接给生存函数 |
| PHME 2026 variable-prefix RUL | 变前缀 RUL 预测 | 无一致性约束 |

**必须核实的点**：是否存在把"前缀一致性/链式法则"作为训练约束的生存模型。
若有，PCH 退化为其特例，应否决。

## 4. 可证伪预测（预注册）

- **P1**：在相同骨干与预算下，PCH 的 90% 区间 PICP 更接近 0.90（|PICP−0.90| 更小），
  且 Winkler 不劣于 CQR 基线。
- **P2**：PCH 的 30/60 周期事件预测 Brier 优于"由点预测+固定宽度导出"的基线。
- **P3**：前缀一致性误差（$\mathcal L_{\text{cons}}$ 在留出引擎上）与设备级覆盖误差正相关；
  去掉该约束后，一致性误差与覆盖同时变差。
- **P4**：设备级覆盖分布的下尾（最差 10% 引擎）改善 ≥5 pp。

## 5. 基线与消融

| 臂 | 内容 |
|---|---|
| A | 直接分位数回归（现有 CQR 头） |
| B | hazard 头，**无**一致性约束（等容量） |
| C | PCH 完整 |
| D | PCH 去掉一致性（=B）+ 去掉绝对时间参数化 |
| E | 标准 CQR 与常数宽度（既有基线） |

**关键判据**：C 必须优于 B，否则"一致性"不是机制。

## 6. 与 Phase 1 的关系

Phase 1 证明"风险不可提前预测"，因此 PCH **不承诺提前识别高风险设备**。
它承诺的是：在**每个前缀**上给出相容的生存曲线，从而让区间与事件概率在
同一引擎的不同观测长度下不自相矛盾。这是一个**内部一致性**主张，可独立检验。
