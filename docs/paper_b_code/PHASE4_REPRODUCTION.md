## 结论：能做什么，不能做什么

### 可以做的

1. **协议对齐的公平对比**：把我们自己的模型跑到与他们相同的窗口长度和测试口径
2. **报告值对比**：在表中明确标注 "as reported by authors"
3. **机制层面的讨论**：基于他们论文描述的结构差异，而非复现结果

### 不能做的

1. ❌ 声称「复现了 SFI-STHGAT」
2. ❌ 用自建近似实现的结果冒充他们的成绩
3. ❌ 在缺少官方代码的情况下断言「我们优于他们」
