## 模型结构

```
输入 100/70 步 × 14 传感器（左填充 + 掩码）
  → 3 通道特征 [raw, raw−基线, 因果 EMA]
  → Linear → **多尺度卷积 k=3/5/7**
  → **时间维 Transformer**（2 层, d=64, 4 头）
  → **传感器维注意力**（跨 14 个传感器, 2 头）
  → 两个池化头（最近 50 步 / 全部有效步）
  → RUL 头 + **HI 头**
```

参数量：77k（旧）→ **117k**（新）

## 损失

```
L = L_RUL(非对称) + 0.5·L_HI(MSE) + 0.1·L_mono(ReLU(hi_t − hi_{t−1}))
```

## 关键发现：循环数依赖

模型原本把**绝对循环数**（`cycle × 250`）作为输入。去掉它：

| 子集 | 基线（旧模型） | +HI | **+HI+MS+SA（新）** |
|---|---:|---:|---:|
| FD001 有 cycle | 8.8610 | 9.0790 | **8.9941** |
| FD001 无 cycle | 15.7403 | 11.3257 | **10.1780** |
| **FD001 依赖度** | **+77.6%** | +24.8% | **+13.2%** |
| FD004 有 cycle | 14.3552 | 14.7860 | 15.9365 |
| FD004 无 cycle | 19.5327 | 18.8045 | **17.6886** |
| **FD004 依赖度** | +36.1% | +27.2% | **+11.0%** |

**含义**：HI 辅助监督 + 多尺度卷积 + 传感器注意力，把模型从「循环数捷径」拉回到「退化建模」。

## 窗口扫描（新模型）

| 子集 | L=30 | L=50 | L=70 | L=100 | 最优 |
|---|---:|---:|---:|---:|---|
| FD001 | — | — | **8.99** | — | 70 |
| FD002 | 11.97 | 11.08 | 10.93 | **9.73** | **100** |
| FD003 | 11.10 | 10.24 | **9.58** | 9.93 | 70 |
| FD004 | **15.19** | 15.33 | 15.94 | 16.38 | 30（跨度仅 7.8%） |

旧模型（有 cycle）的 FD001 曲线：30→10.56, 50→9.30, 70→**8.86**, 100→9.27, 130→9.45, 160→12.72

## 重要限制

1. **全部是单折（f0）、单 seed（101）的验证集 RMSE**，不是官方测试集
2. **L=130 在 FD002/FD004 上 CUDA 报错**（invalid configuration argument），未解决
3. 旧模型的 FD001 窗口扫描**受循环数捷径污染**（无 cycle 时 L=100 优于 L=70）
4. 官方测试集结果（9.64/10.75/10.68/11.19）是**旧模型 + L=100 + 15 模型平均**，与本表不可直接比较
