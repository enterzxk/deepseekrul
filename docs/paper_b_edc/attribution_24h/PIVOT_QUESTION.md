## 1. 问题本体

> **在未见发动机（unseen engines）上，因果个体前缀能否在「连续年龄、合法工况、当前窗口」以及「既有 `_baseline_ref`」之外，提供可复现的预测增益？**

**⚠ 这句话里有一个不可省的限定词：`_baseline_ref` 之外。**

仓库里已有的个体早期基线已经在吃早期个体信息（见 §2.2）。所以下面**是两个不同命题，只有第二个是新的**：

| # | 命题 | 是否已被现有实现覆盖 |
|---|---|---|
| P-a | 个体前缀**有用**（相对于不用前缀） | **已被覆盖**——`_baseline_ref` 就是用它做的 |
| P-b | 个体前缀在 **`_baseline_ref` 之外**还有用 | **未被覆盖**——这才是 PIVOT 问题 |

**上一轮被否的正是这一点没有被分开**：朴素 PrefixCal 只证明了 P-a（甚至没证明），而 P-b 才是可主张的部分。

## 3. 待验证的部分

**唯一待验证命题（P-b）**：

> 在**未见发动机**上，给定**同一段因果前缀**，加入一个**除 `_baseline_ref` 之外的**个体化项，
> 能否带来**留出**的预测增益——且该增益**不能**由同信息的简单替代获得。

**四个必须同时满足的限定**（缺一个就不是这个问题）：

1. **未见发动机**：被评估的发动机在拟合任何个体化参数时**不可见**。
2. **连续年龄**：控制年龄要用**连续 `age`**，不能只放 50 周期箱 dummy——箱内还留着 `ΔRUL = −Δage` 的趋势（`UNRESOLVED_ERRORS` §5.2 已记）。
3. **合法工况**：工况定义必须是物理工况，**不能是 `FD001/3` 上 `KMeans(k=6)` 切出的噪声分区**（`UNRESOLVED_ERRORS` §3 已记）。
4. **`_baseline_ref` 之外**：候选的增量必须是在**已有收缩基线已经给出**的那部分之外，而不是重复它。

## 4. 判据与失败条件（**跑之前冻结**）

### 4.1 主判据（照搬预注册骨架已冻结的那套，`PREREGISTRATION.md` §5）

```
metric = val_engine_mean_rmse，从 val_pred.csv 重算（不读 metrics.json 字段）
d_i    = metric(候选, s, seed_i) − metric(对照, s, seed_i)      i = 1,2,3
Δ      = mean(d_i)
half   = t(0.975, df=2) × sd(d_i) / √3 = 4.3027 × sd / √3
判定     Δ < −half 且 3/3 同号 → better；Δ > +half 且 3/3 同号 → worse；否则 undecidable
```

**四条冻结细节**：`df = n − 1 = 2`（**不是 `n`**）；`t` 用精确分位 `4.3027`（**不用 `1.96`**）；
`half` 由配对差自己的 `sd` 算（**不借注册表现成门槛**）；**`3/3` 同号独立于 `half`**。

### 4.2 失败条件（**任一条成立即判失败，不得解释成「部分成功」**）

| # | 失败条件 | 判法 |
|---|---|---|
| **F1** | 未见发动机上**配对增益不显著** | 全子集 `undecidable` 或 `worse` |
| **F2** | **不优于同信息简单替代** | 见 §4.3 四项对照，**任一对照不劣于候选**即失败 |
| **F3** | **机制探针不通过** | 见 §4.4，任一条不过即失败 |
| **F4** | 增益**只在含被评估发动机的样本内**出现 | 留出后增益消失 |
| **F5** | 增益**可由连续年龄解释** | 把箱内连续 `age` 放进控制后增益消失 |

**⚠ F2 是本轮反复强调的那条**：「不优于同信息简单替代」不能靠「候选自己也涨了」来豁免——
**同信息替代也涨，说明涨的不是机制。**

### 4.3 四项对照（来自 L2，顺序即优先级）

| # | 对照 | 要排除什么 |
|---|---|---|
| **C1** | 现有收缩基线 `_baseline_ref` 原样 | 候选是不是它的等价改写 |
| **C2** | **同一前缀**的普通中心化，或 DAIN 式平移子层 | 增量是不是「随便减个均值」 |
| **C3** | 移植到同一母体的 M2 | 「M2 早就能做到」 |
| **C4** | 等参数量简单替代（参数差 `≤ 1%`） | 「涨参数就涨点」 |

**⚠ C2 的前缀必须与候选拿到的前缀逐点相同**，否则是「多给了信息」，不是「换了算法」。

### 4.4 三个机制探针（缺一条则机制不可主张）

| # | 探针 | 通过条件 |
|---|---|---|
| **P1** | 未来记录改动不影响当前输出 | 替换 `t` 之后记录，`t` 时刻输出**逐位不变** |
| **P2** | 本机前缀换成工况/长度匹配的其他机前缀 | 输出**发生变化** |
| **P3** | 观测恒定偏移干预 | 输出按预期变化 |

**⚠ P2 的边界**：替换前缀会制造分布变化，**只能作压力检查，不能单独当自然因果证据**。

## 5. 与已否定的 PrefixCal 朴素版的区别

| 维度 | 朴素 PrefixCal（已否） | 本 PIVOT 问题 |
|---|---|---|
| 主张的命题 | **P-a**：前缀有用 | **P-b**：前缀在 `_baseline_ref` **之外**还有用 |
| 与现有实现的关系 | 与 `data.py:146` **重合** | 必须**明确说出**改了哪个估计量/假设 |
| 评估方式 | 未区分样本内/留出 | **必须**发动机分组留出 |
| 年龄控制 | 50 周期箱 dummy | **必须**控制箱内连续 `age` |
| 对照 | 无同信息替代 | **四项对照**，任一不劣于候选即失败 |
| 机制证据 | 无 | **三个探针**，缺一不可 |

**一句话**：朴素版问的是「前缀有没有用」（已答：有用，且早就做了）；本问题问的是「**在已经用了前缀的基线上，还剩什么**」。

## 6. 所需数据与实验（**现有资产一条都支撑不了**）

### 6.1 硬缺口：没有任何「未见发动机」留出

