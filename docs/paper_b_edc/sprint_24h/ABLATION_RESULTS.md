## 0. 填写规则（沿用，不修改）

1. 每行必须是**真实落盘终值**（`metrics.json`），不得用 `RUNNING@epN` 中途读数。

## 4. 预算受限标注

**判据**：`budget_limited = (epochs_run == budget)`；`TRUNCATED = (best_ep == epochs_run)`。

**⚠ `budget_limited` 的含义只有一句：早停未触发 ⇒ 不能说「收敛到」，只能说「该协议下的结果」。它不构成剔除理由。**

理由：`CosineAnnealingLR(T_max=epochs, eta_min=1e-5)`（`paper_b/hc/train_d.py:907`）——**第 40 轮 LR 已退到 `eta_min`≈0**，末端每轮几乎不移动权重。所以预算受限的格**不是「还有学习空间时被砍掉」，而是「跑完了整条余弦调度、只是早停判据没触发」**。

**可比性判据是「调度」，不是「早停状态」**：同一 `epochs` → 同一条余弦曲线 → 可比；不同 `epochs` → 不同曲线 → 不可比。**FD001 全部 80ep、FD004 全部 40ep，各自内部全部可比。**

**边界残余（陈述，不是界）**：21 个预算受限格的最后 5 轮改善量（`gain_last5`）**中位数 0.0000、均值 +0.0191、最大 0.1552**；43 个早停格全部精确 0.0000。7 对曾判混状态的配对**两侧全为 0.0000**。
- **`gain_last5 = 0` 不等于「已收敛」**——patience=12 意味着连续 12 轮无改进即早停，所以残余不确定性落在**倒数第 6–12 轮**这个没被 5 轮窗口覆盖的区间。
- **「残余 ≤ 0.1552」这种句式不成立**：观测到的近期增量**不能给未来改善量定界**。只能陈述，不能当界。

## 5. 措辞纪律（写论文时逐条对照）

1. **「无法区分」不写成「等价」**——无法区分 = 有门槛且没过；等价是更强的断言，本轮没有任何模块支持它。
2. **「同协议差」不写成「收敛差」**——40ep 与 80ep 是两条余弦曲线，跨预算的差不可比；同预算内的差有效，但不能叫「收敛水平之差」。
3. **「无法判定 / undecidable」不写成「无法区分」**——前者没门槛，后者有门槛没过。
4. **「未检出」不写成「不存在」**——本轮最好的实测 MDE 是 1.07（M3B），仍是预注册 MME 0.5 的 2.1 倍。**能主张的只有「未检出」。**
5. **不写「显著优于」**——本轮**没有任何一条 promote**。能写的最强正面表述是：「**没有模块在均值上可区分；三条非 RMSE 结论（机制证据、离散度、成本）站得住**」。
6. **方差用 MAD 不用 sd**，且注明跨指纹数（B0 5 个、M2 4 个）。
