## 0. 符号约定（全文唯一）

```
Δ(A→B) = (RMSE_A − RMSE_B) / RMSE_A        正号 = B 优于 A（B 误差更低）
```

- G1 的「均值 ≥ +1.0%」读作「A2 相对 A1 平均改善 ≥ 1.0%」
- G3 的「≤ −10.0%」读作「A0 相对 A1 劣化 ≥ 10%」
- `CYCLE_DEPENDENCE_STUDY.md` §3 曾把 `Δ(A3p→A3a) = +0.4216` 记成正号（正 = 更差），与该约定相反，已按本约定改正为 **−3.87%**（RMSE 差 A3a − A3p = +0.4216）。

## 1. 双口径合取规则（本文件的核心新增）

**主指标不变**：`val_engine_mean_rmse` at best epoch（预注册指标，不得事后更换）。

**强制并列报告**：末 10 个 epoch 的平台均值（及平台 std）。理由见 §2。

**判定改为合取**：一个门只有同时满足以下两条才算通过——

1. 主指标（best-epoch）口径下满足原阈值；
2. 平台口径下 **同号**，且量级相容（不得相差 3 倍以上）。

这是**收紧**，不是放宽：原规则只需口径 1，现规则要求两口径同时成立。因此不构成事后更换指标。

**四子集必须全列**：任何子集在主指标口径下 `Δ > +2.0%`（即劣化），必须单独标注并解释，不得用均值掩盖。

## 2. 为什么必须加平台口径：选择偏差实测

各变体「平台均值 − 最优值」（即 best-of-N 选择偏差）与平台 std：

| 变体 | 平台 std | 选择偏差 |
|---|---|---|
| A0（纯 cycle） | 0.060 | 0.13 |
| A3p（冻结 Fourier） | 0.208 | 0.73 |
| A1（无 cycle） | 0.738 | 1.40 |
| A2（raw cycle） | 0.849 | 1.06 |

跨格选择偏差实测范围 **0.27 – 2.34 RMSE**，与 G1 要检测的效应（0.7–1.6 RMSE）**同量级**，且按变体系统性不同。因此单口径点估计不可解释。

两口径下 G1 的聚合均值稳定（+10.46% / +12.45%），但**子集排序翻转**：单点口径 FD002 最好（+13.52%）、平台口径最差（+3.54%）。**结论：G1 可报「四子集全部正向、均值 +10~12%」，不可报「FD002 效应最大」。** FD003 是唯一在两口径下均列第 2 的子集。

平台口径的局限（必须一并写明）：它只消除 best-of-N 选择偏差，**不消除「曲线高度取决于何时停止训练」**；且 epoch 间高度自相关，`std/√10` 是乐观上界，真实有效独立样本约 2–3 个。

## 3. 触顶格的三分（不得混为一谈）

`epochs_run == best_ep` 只是必要条件，判定需看**尾段线性斜率**（std 不能区分「低方差但仍在下降」与「真收敛」）：

| 类别 | 判据 | 已确认格 |
|---|---|---|
| 干净早停 | `margin = patience = 12` | A0-FD002/004、A1×4、A2-FD002、A3p-FD001 |
| 打满但已平（真收敛） | 尾段斜率≈0 | A0-FD001（尾三 30.1416/30.1350/30.1386）、A0-FD003 |
| 打满且仍在波动（真截断） | 尾段仍有非零斜率 | A2-FD001（margin 6）、A2-FD003（margin 5）、A2-FD004（margin 6） |

**截断格的报值是上界**（真实误差可能更低）。A2 四格中三格截断 → **G1 的效应量被低估，结论偏保守**。A0 两格虽打满但已收敛 → **G3 不存在截断偏置**。

## 4. G2 的噪声底线与分辨率

`NOISE1`（`HC-C-A2-FD001-s101-NOISE1`，只重抽循环投影，骨干 58 键逐位不变）：

```
NOISE1 val = 10.5623371815      A2 val = 10.5924603632
|Δ| = 0.030123 RMSE = 0.28% of A2
```

**σ 的换算（不得直接拿 |Δ| 当 σ）**：

```
σ_Δ(探针) = √2 · σ_p
E|Δ| = 0.798 · √2 · σ_p = 1.128 · σ_p
σ_p = 0.03012 / 1.128 = 0.0267
σ_Δ(G2) = √2 · σ_p = 0.0378
阈值 1.0% ≈ 0.106 RMSE  →  0.106 / 0.0378 = 2.80σ
```

**是 2.80σ，不是 3.5σ。** 若真实效应恰为阈值，单次检出概率约 50%；效应达 1.4 倍阈值时约 88%。

**四子集均值不降低投影噪声**：A3a 四格共用同一份 init 文件，投影抽样跨子集完全相关，`σ/√4` 不成立。有效 σ 接近单子集的 0.0378。

**因此 G2 不得报二元 pass/fail，必须报区间。**

`NOISE1` 的适用范围限定：它测的是 A2 的投影 `Linear(1,64)`（fan_in=1），A3a 是 `Linear(8,64)`（fan_in=8），初始化尺度差 √8。**σ 能否迁移未验证**，需对比两者 `cycle_enc.proj(x)` 在真实 batch 上的输出 std。

### 4.1 W2 实测：FD001 的 seed 带宽（补记，不改预注册阈值）

|---|---|
| 101 | 11.2806 |
| 202 | 11.353972188685571 |
| 303 | 11.442163300493988 |

**极差 = 0.1616 RMSE（1.43%），样本 σ ≈ 0.0809。** 这是**训练 seed 级**的噪声底，和 §4 的投影抽样噪声 σ_Δ = 0.0378 不是同一个量：§4 固定 seed、只重抽投影；这里换的是数据顺序与 dropout。

对 `A2cal` vs `A3bcal`（各 3 seed）的含义：

- 单 seed 的 Δ 小于 **0.162** 时不可辨；
- 两臂各 3 seed 的均值差 SE ≈ σ·√(2/3) ≈ **0.066**，G2 的 1% 阈值（≈0.106 RMSE）只有 **1.60σ**；
- 因此 cal 臂必须报 **3-seed 均值 + 区间**（能配对就报配对差），不能拿单 seed Δ 判 G2。

cal 臂与 FD002–FD004 的 seed 带宽待补；本小节只补 FD001，不改 §4 已预注册的阈值与判定树。

### 4.2 A2cal vs A3bcal 的预注册分析规则（2026-11-12 19:50 +08，批二结果落地前）

**设计定性：同 seed 不是配对设计，seed 只是区组因子。** 理由：

- 两臂共享数据顺序（permutation 用独立 generator、同 seed），但模型构建时抽的参数个数不同（`A2cal` 的 `Linear(1,64)` = 128 参数；`A3bcal` 的 `Linear(8,64)` = 576 参数），初始化抽样不同；
- dropout 的 RNG 流从第一次前向起就分叉，后续 epoch 的随机掩码不再对齐。

所以「同 seed 差」不是零方差配对差，**不得把配对 t 检验当主分析**。

**主分析（预注册，先于结果）**：

1. 每臂 3 seed 的 `val_engine_mean_rmse` 均值；主效应 = `mean(A2cal) − mean(A3bcal)`；
2. 95% CI 用 Welch t（3v3，df≈4），同时报 9 个跨 seed 对的 min–max 作稳健性检查；
3. 判定：
   - CI 不含 0 且 |均值差| ≥ 1% 阈值（≈0.106 RMSE）→ **检出**；
   - CI 不含 0 但 |均值差| < 阈值 → **检出但低于实用阈值**；
   - CI 含 0 → 只能写「**功效不足 / 未检出**」，**不得**写「无差异」或「等价」。

**次要分析**：按 seed 的配对差（同 seed 的 `A2cal − A3bcal`）只作描述，报 3 个差值，不作主检验。

**解释边界**：

- 单 seed Δ < 0.162（FD001 seed 极差）不可解释；
- 1% 阈值只有 1.60σ（σ=0.0809，3v3 均值差 SE≈0.066），CI 跨过阈值时只能写「功效不足」；
- 本规则只适用于 FD001；FD002–FD004 的 seed 带宽补齐后再扩展，**不得先看数再定规则**。

**规则（沿用 §4.2 同一套分析，逐子集独立）**

## 5. G2 三条分支（预注册决策树）

在 A3a 四格落盘前固定。判读用**两口径合取**，阈值以**均值**为准，不以单格为准。

| 分支 | 条件 | 处置 |
|---|---|---|
| **B1** | 四子集均值在两口径下均 **> +5%**（A3a 更好） | Fourier 编码主张成立，A4/A5 按计划跑，补 3 seed 出区间 |
| **B2** | 均值在两口径下均落在 **±5%** 内 | **null（分辨率内未检出）**。主张退为「cycle 通道有效（G1），Fourier 编码在我们的分辨率下未检出额外增益」。**不得写成「Fourier 无用」**，只能写「在 ±3% 区间内未检出增益」。A4/A5 按各自独立价值决定是否跑 |
| **B3** | 均值在两口径下均 **< −5%**（A3a 更差） | Fourier 编码路径不成立。注意 `A3p-FD001 = 10.8951` 已差于 `A2-FD001 = 10.5925`（2.9%），但 A3p 同时差「冻结」与「注入点」两个变量，**不得单独归因** |

**补充约束**：

- 单格 `A3a-FD001` 只能报方向，**不得单独判 G2**；
- 若 A3a 四格落点全部在 `[A2b, A2] = [10.5623, 10.5925]` 的投影噪声带内，按 B2 处理；

2. 运行中的格子报数必须带 `RUNNING@ep<N>` 标签，**不得进入任何结论**。
