## 1. 上界推导（复核，无更正）

```
h_j = σ(β(D̂_j − 1)),  D̂_j ≥ 0（softplus 求和、D_0 = 0）
⇒ β(D̂_j − 1) ≥ −β ⇒ h_j ≥ σ(−β)
⇒ 1 − h_j ≤ 1 − σ(−β) = q
S_0 = 1, S_k = Π_{j≤k}(1−h_j) ≤ q^k
T̂ = Σ_{k=0}^{K−1} S_k ≤ (1 − q^K)/h
```

β=1：h = 0.268941，q = 0.731059，q^200 ≈ 1.6e−27 ⇒ **T̂ ≤ 3.718282 = 1+e**（D≡0 时取等）。

**所需 β**：解 `(1−q^K)/h = 125`（K=200）⇒ **β = 5.2629**。参考：β=2 → 8.389、β=5 → 110.41。

## 2. 两条缺陷（按军师限定重写）

### 2.1 常值平台 `D≡1` 上，`T̂ = 2`，与 β 无关 —— **只对常值轨迹成立**

D≡1 时 `h = σ(0) = 0.5`，任何有限 β 都一样，`T̂ = 1/h = 2`。

**v1 的过强之处（收回）**：我把这条推广成了「阈值处并不到达」的一般结论。**不成立**——轨迹越过 1 后继续增长时 `h_j` 继续变大、`q_j` 变小，`T̂` 会小于 2，不会停在 2。所以这条能证明的只是：

> **在常值平台上，「D=1 ⇒ 失效」的语义不成立**；一般轨迹的阈值语义必须用变速轨迹单独测，不能由这条推出来。

**仍然保留的部分**：`h(D=1)=0.5` 是**单步条件危险率**，不是「到达点」也不是「中位寿命点」（军师原话：不能这样解释）。论文里若写「损伤到 1 即失效」，代入 D≡1 会得到 RUL=2，与叙述冲突——**要么改叙述，要么在规格里把失效点定义写清并让它可测**。

### 2.2 常值族里 T̂ 随 D 递减，最大值在 D=0 —— **这是族内性质，不是损失结论**

常值 D 下（K=200，β=1）：D=0 → 3.718、0.5 → 2.649、1 → 2.000、2 → 1.368、3 → 1.135。

**v1 的过强之处（收回）**：我写成「损失唯一把 D 推向 0」。**未证**——那个分析只看了 T̂ 对常值 D 的依赖，**没有包含终点损失 `L_terminal`、未来速率项，也没有做完整反传**。真实轨迹里 D 由速率网络生成，梯度经累计和传回，方向不能由常值族外推。

**降级后可检验的弱命题**：

- (a) 若只保留 T̂ 项、其余固定，则 D 的下降方向指向 0 —— **可算，是族内结论**；
- (b) 完整损失下是否仍指向 0 —— **需一次完整计算图反传**（tmh 的验收项 6），在此之前不得当结论用。

**保留的反例要求（不变）**：`D≡0` 满足单调、D_0=0、增量≥0、重叠一致、两接口一致，**能过现有六条接口测试**。所以必须有一条**退化解反例**，断言「`D≡0` 不得通过验收」——这是测试要求，不是「损失一定推向 0」的断言。

## 3. 反例清单（按军师四条 + 我的补充）

1. **可表示范围（构造性）**：用**预设轨迹**证明 `T̂` 能覆盖 `[0, 125]`；**不要求随机初始化恰好输出 >125**（那是在测初始化，不是在测算子）。当前 β=1 下这一步必然失败，它就是修复的验收条件。
2. **已失效 = RUL 0**：目标 0 必须可达。**当前 `S_0=1` 使 `T̂ ≥ 1`，0 不可达**——规格需明确 `S_0` 的定义（是否改 `Σ_{k≥1}` 或 `S_0=1−h_0`），这是语义问题不是调参问题。
3. **精确命中（非整数）**：D 在 j 与 j+1 之间横穿阈值时，`T̂` 应落在 `[j, j+1]` 且随横穿位置单调，不得跳变。
4. **平台**：D 达平台后 `h` 恒定，`T̂` 应是几何和 `1/h`（截断到 K），需与 K 截断一致，不得出现随 k 回升。
5. **变速轨迹**：前慢后快、前快后慢两类，`T̂` 必须随真实到达步单调，且与逐步 `ν` 作分母的新写法一致（军师提醒：逐步 `ν` 可能让生存代理随 k 回升，必须专门测）。
6. **完整计算图反传**：`∂L/∂θ` 经累计 D 传回速率网络，非零且方向正确。**不得用局部有限差分代替**（那证明不了梯度穿过了整条轨迹）。
7. **退化解**：`D≡0` 不得通过验收（见 §2.2）。
