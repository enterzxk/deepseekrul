## 2. 两条缺陷（按军师限定重写）

### 2.1 常值平台 `D≡1` 上，`T̂ = 2`，与 β 无关 —— **只对常值轨迹成立**

D≡1 时 `h = σ(0) = 0.5`，任何有限 β 都一样，`T̂ = 1/h = 2`。

**v1 的过强之处（收回）**：我把这条推广成了「阈值处并不到达」的一般结论。**不成立**——轨迹越过 1 后继续增长时 `h_j` 继续变大、`q_j` 变小，`T̂` 会小于 2，不会停在 2。所以这条能证明的只是：

> **在常值平台上，「D=1 ⇒ 失效」的语义不成立**；一般轨迹的阈值语义必须用变速轨迹单独测，不能由这条推出来。

**仍然保留的部分**：`h(D=1)=0.5` 是**单步条件危险率**，不是「到达点」也不是「中位寿命点」（军师原话：不能这样解释）。论文里若写「损伤到 1 即失效」，代入 D≡1 会得到 RUL=2，与叙述冲突——**要么改叙述，要么在规格里把失效点定义写清并让它可测**。

### 2.2 常值族里 T̂ 随 D 递减，最大值在 D=0 —— **这是族内性质，不是损失结论**

常值 D 下（K=200，β=1）：D=0 → 3.718、0.5 → 2.649、1 → 2.000、2 → 1.368、3 → 1.135。

**v1 的过强之处（收回）**：我写成「损失唯一把 D 推向 0」。**未证**——那个分析只看了 T̂ 对常值 D 的依赖，**没有包含终点损失 `L_terminal`、未来速率项，也没有做完整反传**。真实轨迹里 D 由速率网络生成，梯度经累计和传回，方向不能由常值族外推。

**降级后可检验的弱命题**：

- (a) 若只保留 T̂ 项、其余固定，则 D 的下降方向指向 0 —— **可算，是族内结论**；
- (b) 完整损失下是否仍指向 0 —— **需一次完整计算图反传**（tmh 的验收项 6），在此之前不得当结论用。

**保留的反例要求（不变）**：`D≡0` 满足单调、D_0=0、增量≥0、重叠一致、两接口一致，**能过现有六条接口测试**。所以必须有一条**退化解反例**，断言「`D≡0` 不得通过验收」——这是测试要求，不是「损失一定推向 0」的断言。

## 3. 反例清单（按军师四条 + 我的补充）

1. **可表示范围（构造性）**：用**预设轨迹**证明 `T̂` 能覆盖 `[0, 125]`；**不要求随机初始化恰好输出 >125**（那是在测初始化，不是在测算子）。当前 β=1 下这一步必然失败，它就是修复的验收条件。
2. **已失效 = RUL 0**：目标 0 必须可达。**当前 `S_0=1` 使 `T̂ ≥ 1`，0 不可达**——规格需明确 `S_0` 的定义（是否改 `Σ_{k≥1}` 或 `S_0=1−h_0`），这是语义问题不是调参问题。
3. **精确命中（非整数）**：D 在 j 与 j+1 之间横穿阈值时，`T̂` 应落在 `[j, j+1]` 且随横穿位置单调，不得跳变。
4. **平台**：D 达平台后 `h` 恒定，`T̂` 应是几何和 `1/h`（截断到 K），需与 K 截断一致，不得出现随 k 回升。
5. **变速轨迹**：前慢后快、前快后慢两类，`T̂` 必须随真实到达步单调，且与逐步 `ν` 作分母的新写法一致（军师提醒：逐步 `ν` 可能让生存代理随 k 回升，必须专门测）。
6. **完整计算图反传**：`∂L/∂θ` 经累计 D 传回速率网络，非零且方向正确。**不得用局部有限差分代替**（那证明不了梯度穿过了整条轨迹）。
7. **退化解**：`D≡0` 不得通过验收（见 §2.2）。

## 6. 区间求和 vs 首达时长：一致性核查（2026-11-13 04:30 +08，应军师要求）

**待核命题**：设 `D[0]=0`、`D[k+1]=D[k]+ν[k+1]`，`D` 单调不减，`T̂ = Σ_k clip((1−D[k])/(D[k+1]−D[k]), 0, 1)`（零增量单独定义）。问：它是否**恰好等于**分段线性插值下的首达时长。

**结论：相等，且是恒等式，不是近似。**

证明（两行）：单调 ⇒ 存在唯一区间 `j` 使 `D[j] < 1 ≤ D[j+1]`。对 `k<j`，`D[k+1] ≤ D[j] < 1` ⇒ 比值 `≥1` ⇒ clip 取 1；对 `k>j`，`D[k] ≥ D[j+1] ≥ 1` ⇒ 比值 `≤0` ⇒ clip 取 0；只有 `k=j` 落在 `(0,1]`。故 `T̂ = j + (1−D[j])/ν[j+1]`，正是首达点。

**数值验证**（12493 条随机单调轨迹，含加速、减速、平台、精确命中、已越阈值；另有 7507 条未命中）：

```
worst |fpt - sum| = 0.0
```

边界例：已越阈值 `[1.2,1.3,1.4]` → 0；节点精确命中 `[0.5,1.0,1.4]` → 1；平台后跳 `[0,0,0,1]` → 3；未命中 `[0,0.1,0.2]` → 2。

**四条必须钉进规格的细节**

1. **零增量就是极限，不是额外约定**：`ν=0` 且 `D[k]<1` 时比值 `→+∞`，clip 取 1；`D[k]≥1` 时取 0。写成 `1[D[k]<1]` 即可，不需要单独分支。
2. **未命中 = K−1，不是 K**：`K` 个节点只有 `K−1` 个区间。军师写的 `未命中 → K` 与 `D[k+1]=D[k]+ν[k+1]` 的索引口径差 1，规格里要统一。
3. **不需要再减 0.5**：半步修正是旧连乘式的补丁；区间求和给的是精确插值时长，精确命中出整数，非整数命中出插值。
4. **单调性是前提，不是装饰**：若 `D` 可能下降，clip 求和变成「低于阈值的时间」，不等于首达。`D` 由 softplus 累加保证单调，但**测试要断言单调**，不能默认。

**梯度结构（供 tmh 的反传验收）**

`T̂` 对 `ν` 分段可微，**梯度只落在唯一那个横穿区间**：

```
∂T̂/∂ν[j+1] = −(1−D[j])/ν[j+1]² = −f/ν ,  ∂T̂/∂D[j] = −1/ν[j+1]
```

`f=0` 或 `f=1` 处是 clip 的折点（次梯度）。**结构性风险**：若整条轨迹不横穿阈值（`ν` 太小，`D` 在 `K` 步内到不了 1），则 `T̂ ≡ K−1` 且**梯度恒等于 0**——模型卡在 `K−1` 再也回不来。当前 `ν=softplus(0)=0.693` 起步，横穿约在 `k≈1.4`，在「太快」一侧，梯度非零，暂时安全；但 `ν` 初始化必须保证 `ν·K > 1`，并且要有一条**零梯度陷阱**的反例测试。

**军师那条减速反例我复算过**：`D₀=0.90, ν₀=0.5` 时 `S=0.690`；下一步 `ν₁=0.01, D₁=0.91` 时 `S=1.000`。**生存概率回升，确实不是生存函数**，与他的判断一致。区间求和在这个例子里给 `0 + (1−0.90)/0.01 = 10` 被 clip 到 1，即 `T̂=1`——首达确实发生在第 1 步内，语义正确。

## 7. 两句待撤回的规格声明：按区间求和口径的精确定位（2026-11-13 04:45 +08）

经理提到规格里有两句此前要求撤回：「K 不影响任何损失」「截断预测是真值下界」。§6 的恒等式正好能把它们钉成精确形式。

**先把值域钉死**：区间求和给出 `T̂ ∈ [0, K−1]`（未命中时取到 K−1，已失效时取 0）。这不是近似，是恒等式的直接推论。

**第一句「K 不影响任何损失」——不是算子性质，是损失形式的性质。**
- 若损失仍是**删失 hinge**（`r > 125` 的样本对 `T̂ ≥ 125` 零损失），且 `K ≥ 126`，则该句在**该损失下**成立；
- 若换成对 `y = min(r,125)` 的平方误差，`T̂ = 130` 会有非零损失，K 一旦小到 `K−1 < 125` 就直接改变损失；
- 所以正确写法是：「**在删失 hinge + K ≥ rul_cap+1 的前提下**，K 不影响损失」。脱掉这个前提，这句话是错的，不能当算子的性质引用。

**第二句「截断预测是真值下界」——只在删失样本上、且只因为 clamp 成立。**
- `r > K−1` 的样本：`T̂ ≤ K−1 < r`，确实是下界，但这是**截断造成的**，不是模型校准给出的保证；
- `r < K−1` 的样本：没有任何东西把 `T̂` 压在 `r` 下面，预测可以高于真值；
- 所以不能写成「截断预测是真值下界」这种一般陈述，只能写「对 `r > K−1` 的删失样本，`T̂` 因截断而不超过真值」。

**给规格的建议**：这两句改成带前提的版本，前提写进同一行；否则以后有人拿「下界」去支持保形区间的最坏情况论证，会站不住。
