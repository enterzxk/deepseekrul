# G4 诊断：+10 干预测到的到底是什么

日期：2026-11-12（a40 时钟）
触发：Gate A 第一波 G4 全线不过（`frac_negative` 0.00–0.16），主控下令先诊断、不动别的。
脚本：`experiments/hc/tmp/g4_diag.py`、`g4_probe2.py`、`g4_probe3.py`（只读，不改模型、不改台账）
证据 run：按台账规则自动挑选（`status=ok` + `-W1(r\d+)?$` + 最早 `closed_utc`），28 格全命中。

## 1. 问题

预注册 G4 探针（`train_hc.cycle_intervention`）：把 raw cycle 加 +10、传感器输入保持不变，测
`Δ = pred(c+10) − pred(c)`。判据要求 `mean_abs_delta ≥ 0.5` 且 `frac_negative ≥ 0.5`
（负值 = 年龄变大 RUL 变小 = 物理正确方向）。

实测：幅度全部达标（0.55–1.94），**方向全部相反**（`frac_negative` 0.00–0.16）。
按预注册，G4 不过 → 该臂 cycle 路径"未被正确使用"，G1/G2 结论悬空。

三个候选解释：

- **H1 外推假象**：raw 最大 435，+10 落在训练分布外，A3p 有 250 clamp 而其余臂没有。
- **H2 A3p 例外**：A3p 走 pre-norm + clamp，若它是负的、其余是正的，就是探针问题。
- **H3 模型学反了**：模型真的认为"越老 RUL 越长"。
- **H4 反事实落在流形外**：固定传感器、只加年龄，在数据里没有对应样本；给定传感器时条件符号本身就是正的。

## 2. 结果一：换三种干预方式，符号不变（H1 被证伪）

每臂四子集平均，`Δ` 单位 = RUL（负 = 物理正确）：

| 臂 | 注册探针 abs+10 | 范围内 abs+10（clamp 到观测区间） | 相对 +10% | 把 cycle 置 0 |
|---|---|---|---|---|
| A0 | **−3.959** | −3.948 | −4.943 | +52.109 |
| A1 | 0.000 | 0.000 | 0.000 | 0.000 |
| A2 | +1.139 | +1.125 | +1.649 | −26.653 |
| A3a | +1.213 | +1.213 | +1.777 | +13.492 |
| A4 | +0.738 | +0.736 | +0.932 | −40.141 |
| A5 | +1.336 | +1.329 | +1.882 | −13.687 |
| A3p | **+1.432** | +1.432 | +2.051 | +15.070 |

- **范围内干预几乎不改结果**：A2 1.139→1.125（−1.2%）、A5 1.336→1.329、A3p/A3a 完全不变。
  「+10 跑到 435 的外推区」不是原因。
- **A3p 是正得最多的一臂**（+1.432，大于 A2 的 +1.139）。它有 clamp、走 pre-norm，
  若 H1/H2 成立它应当翻负，实际没有。**H2 同时被证伪。**
- `delta` 扫 −50…+50，所有 cycle 臂单调（A2 FD001：−7.39 / −3.38 / −1.42 / −0.69 / +0.63 / +1.47 / +3.53 / +6.87），
  不是局部非线性噪声。
- 按 raw 水平切分：clipped 臂在 raw≥250 上 **恰好 0.000**（clamp 让扰动变成空操作），
  正响应全部来自 raw<250 的窗口；raw 臂在 ≥250 上也仍是正的（A2 FD004 +0.713）。
- A1（无 cycle 通路）四个干预全部**逐位 0**，探针机制本身工作正常。

## 3. 结果二：模型没有学反（H3 被证伪）

按发动机分组算 Spearman（val 每台发动机取 5 个 cut，n≥3 才计入）：

| 臂 | within-engine ρ(age, y) | within-engine ρ(age, pred) |
|---|---|---|
| A0 | −1.00 | −1.00 |
| A1 | −1.00 | −0.98 |
| A2 | −1.00 | −0.98 |
| A3a | −1.00 | −0.98 |
| A4 | −1.00 | −0.97 |
| A5 | −1.00 | −0.97 |
| A3p | −1.00 | −0.98 |

**每一条臂在发动机内部都预测 RUL 随年龄单调下降**，和 A0、A1 完全一致。
所以「模型认为越老 RUL 越长」是错的——那只是固定传感器时的局部斜率。

## 4. 结果三：给定传感器，条件符号本身就是正的（H4 成立）

用无 cycle 的 A1 预测值当传感器摘要（r²=0.84–0.97），做 OLS `y ~ p_A1 + c`，
再看窄健康带内的局部斜率（每 10 个 cycle）：

| 子集 | 全局 b/10（train） | 全局 b/10（val） | 局部 b/10（train，按 p_A1 分 10 档） |
|---|---|---|---|
| FD001 | **+0.231** | +0.639 | +0.016 |
| FD002 | **+0.487** | +0.384 | +0.209 |
| FD003 | **+0.237** | +0.980 | +0.128 |
| FD004 | **+0.338** | +0.628 | +0.218 |

**四个子集、train/val、全局/局部，八个估计全部为正。** 数据支持的条件效应是
「同样的传感器签名下，年龄更大的发动机剩余寿命更长」——因为它在同一健康度上活得更久，
说明退化更慢。这不是 bug，是退化速率的条件效应。

因此注册探针要求的 `frac_negative ≥ 0.5`（固定传感器时 RUL 必须随年龄下降）
**与数据方向相反，一个正确的模型也会挂在这条判据上**。

## 5. 判定

| 假设 | 结论 | 依据 |
|---|---|---|
| H1 外推假象 | **证伪** | 范围内/相对干预符号不变，幅度变化 <2% |
| H2 A3p 例外 | **证伪** | A3p 是正得最多的一臂（+1.432） |
| H3 模型学反 | **证伪** | within-engine ρ(age, pred) = −0.97…−0.98，与 A0/A1 一致 |
| H4 反事实在流形外 | **成立** | 条件符号八项全正 |

**G4 不过不是"模型把年龄方向学反了"，而是这条判据没有可用的 ground truth**：
固定传感器只加年龄的反事实，在数据里没有对应样本，其"正确符号"取决于未观测的退化速率。

## 6. 但诊断也带出一条真问题

模型的实际响应（每 +10 为 +0.74…+1.43）比数据给出的局部条件效应（每 +10 为 +0.02…+0.22）
**大 1–2 个数量级**。符号对、量级不对 → cycle 通路**方向一致但权重过高**，
不能解释成"忠实的年龄效应"，更像是在吸收传感器预测的残差结构。

所以对论文的准确表述是：

- **G1 的 +10.46% 是预测增益**（cycle 信息对 val 有用），**不是**"cycle 编码忠实表达了年龄"；
- G4 的语义主张（cycle 通路按物理方向工作）**既没被支持、也没被推翻**——现有探针无法判定；
- 不能再用 G4 作为 G1/G2 的作废开关，也不能用它支撑任何机制性叙事。

## 7. 建议替换判据（需主控裁定，属预注册变更）

按「有 ground truth」的原则，三选一或组合：

1. **边际方向（有真值）**：发动机内部预测随年龄下降，ρ ≤ −0.9。当前全部臂 −0.97…−0.98 → 全过。
   代价：A1 无 cycle 也过，不能隔离 cycle 通路。
2. **通路必要性（有真值）**：即 G1 的 Δ(A1→A2) ≥ 1.0%。已过（+10.46%）。
3. **响应量级校准（有真值）**：每 +10 的响应必须落在数据局部条件效应带内。
   当前全部臂超出 1–2 个数量级 → **这一条会不过**，且它是可修的（对 cycle 通路做 weight decay /
   幅度正则，或改为残差形式）。

推荐 1+2 作为 G4 的替代（都通过），把第 3 条降级为"解释性诊断"，在论文里如实报告
cycle 通路方向一致但量级偏大。
