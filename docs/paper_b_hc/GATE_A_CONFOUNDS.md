## 1. 三个已确认的混杂

### C1：注入尺度差 158 倍（跨全部子集）

```
A2   cycle_enc.proj  输入 std 70.107  →  输出 std 69.665
A3a  cycle_enc.proj  输入 std  0.707  →  输出 std  0.440
```

- 根因：`ScalarCycle` 喂原始 cycle（1–362），`FourierCycle` 喂有界的 `sin/cos`。同一个 `Linear` 初值下，输出尺度随输入尺度走。
- 训练没有把它养起来：A3a 的 `w_std` 0.1986 → 0.1993（几乎不动）。
- **度量口径提醒**：`proj(x).std()` 在 batch × 64 通道上一起算，混了 per-channel 偏置（`Var(w)·E[x]²`）与时间维变化。判断「通道是否携带信号」应用 **`proj(x).std(dim=batch).mean()`**。按此口径估算：A2 ≈ 37.5、A3a ≈ 0.40、A4 ≈ 0.34（A5 预计更小）。

### C2：`cycle_source` 不同（只影响 A3a / A3p）

字段级 diff（`hc_config`，非从键名推断）：

```
A2 vs A4   只有 cycle_mode: 'raw' -> 'log'                干净
A2 vs A5   只有 cycle_mode: 'raw' -> 'spline'             干净
A2 vs A3a  cycle_mode:   'raw' -> 'fourier'
           cycle_source: 'raw' -> 'clipped'               第二个变量
A2 vs A1   cycle_mode: 'raw' -> 'none'
           injection:  'post_norm' -> 'none'
```

- **所有 Fourier 臂（A3a、A3p）都用 `clipped`（clipped at 250），所有线性/样条臂都用 `raw`。** 这是系统性差异，不是个别配置。
- 因此 **`Δ(A2→A3a) = −6.84%` 混着「编码形式」与「cycle 是否在 250 处截断」两个变量，不能归因给 Fourier 编码。**
- 截断发生在 cycle > 250 区间，而该区间正是 RUL 最小的区域——它是信息内容的变化，不只是表示形式的变化。

### C3：冻结 + 注入点（只影响 A3p）

```
A3p = DSPT_HC_Frozen：frozen_injection=True，pre-norm，循环模块冻结
A3a = DSPT_HC      ：frozen_injection=False，post-norm，循环模块可训练
```

- `Δ(A3a→A3p) = +3.73%`、`Δ(A2→A3p) = +2.78%` 都同时差两个变量，**只能报数，不能归因**。
- 若要单独测注入点，需第四个臂：可训练 + pre-norm。**已决定不建**（两个 Fourier 臂都输给 A2，细分两个输家之间的差距对主张无贡献）。

## 2. 混杂对「干净比较」的影响

**配置层面单变量 ≠ 效应可归因。**

| 比较 | 配置单变量 | 尺度匹配 | 可归因性 |
|---|---|---|---|
| A2 vs A4（log1p） | ✅ | ❌（输出尺度 ~110×） | **不可归因** |
| A2 vs A5（样条基） | ✅ | ❌（预计更小） | **不可归因** |
| A2 vs A3a（Fourier） | ❌（C2） | ❌（C1） | **不可归因** |
| A3a vs A3p / A2 vs A3p | ❌（C3） | ❌ | 只能报数 |

**结构性原因**：任何输入表示的改变都会改变输出尺度，除非显式归一化。**换基就换尺度。** 所以在这个架构下，「编码形式」这个比较天然与尺度纠缠。

## 3. 唯一干净的修法

不是「乘一个因子」（只对齐一个点，且对齐到谁不明确），而是**在 `proj` 之后加归一化**，让所有臂的输出尺度一致：

```
proj(x) → LayerNorm(proj(x))      或    输入标准化后再投影
```

成本：4 臂（A2 / A4 / A5 / A3a）× 4 子集 = 16 格，约 4–6 小时。

**这是唯一能得到干净编码结论的设计。** 其余方案（只补 A3a′、只换 cycle_source）都只是把一个混杂换成另一个混杂。

## 5. 平台口径的定义缺陷（独立于上述混杂）

预注册的「末 10 epoch 平台均值」在**早停格**上测的不是性能，是**过最优之后的退化速度**：

```
A2-FD002    ep=26  best_ep=14  → 末 10 轮 ep17–26，全部在最优之后
A3a-FD002   ep=22  best_ep=10  → 末 10 轮 ep13–22，全部在最优之后
A2  10.2074 → 12.5499（退化 2.34）
A3a 10.6051 → 12.0430（退化 1.43）
```

因此 FD002 上 G2 的两口径反号（−3.90% vs +4.04%）**不是「效应不稳健」，是 A2 过拟合更快被平台口径奖励**。

**建议补充第三口径（post-hoc，不改主判定）**：以 `best_ep` 结尾的 10 轮窗口（`ep(best−9)`…`ep(best)`），测最优附近的平台高度，不测最优之后的退化。三口径同号才报方向。
