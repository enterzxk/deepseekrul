### 10.7 分辨率表的系数更正（连带更正）

- **CI 半宽** = 2.876 × √(2/3) = **2.348×sd**；**80% 功效 MDE** = (2.876 + 0.9416) × √(2/3) = **3.117×sd**。
- 但 `3.117` 是 **n=3 且 df=3.675** 的 MDE，里面同时含 √(2/3) 的小样本膨胀与**实测不等方差 df**，**不能拿 `√(3/n)` 外推**。正确做法是迭代解 `n = 2·((t₀.₉₇₅,₂ₙ₋₂ + t₀.₈₀,₂ₙ₋₂)·sd/δ)²`，让 C(n) 随 n 变。
- 解出判 **1%** 所需 seed/臂：**9 / 21 / 929 / 4**（FD001–FD004）。
- **作废**：`3×(3.117σ/δ)²` → 14.8 / 36.8 / 1722 / 5.2（前导 3 重复计数）；`2×(3.117σ/δ)²` → 10 / 25 / 1147 / 4（小样本膨胀没去掉）。
- **限制**：表里的 sd 用 **A1 代理**，cal 两臂实测 sd 更大（FD002 0.20 / 0.19），**实际所需 seed 比表里还多**。
