# Paper B 相关工作与真实 gap

> 交付物 #1（任务书 §4）。作者：燕子。日期：2026-11-12。
> 目的：回答**我们的 gap 到底是什么**，不是罗列模块。
> 一句话结论先放这里：**HI 参与 RUL、FHT、Wiener、工况感知，这四件事都已经被做过。
> 我们不能声称它们是创新。真正还没被回答的，是"年龄与退化测量该怎样分工"这个问题——而它目前
> 只在 6 篇范围内未被触及，不能据此宣称新颖。**

## 4. 我们的 gap 到底是什么

把 §3 的结论压成三个**可证伪**的科学问题。这不是模块清单，每个问题都有明确的否证方式。

### Q1（核心）：当年龄与真实退化测量同时可得时，年龄应当只进入"未来退化速度"，还是也进入"当前退化状态"？

- **为什么值得问**：旧模型的绝对周期 Fourier 编码是逐时刻相同的加性偏置，它不携带任何时间信息
  （`DSPT_BASE_FUNCTIONAL_AUDIT.md` §2.3 已实测：`pe_proj` 的注入位置在每个时刻相同，携带
  **零时间信息**，效果是读数前的逐发动机加性偏置）。这等于让年龄直接参与当前状态估计——
  是捷径，不是先验。
- **否证方式**：把 cycle 从状态路径移除、只接到速度路径，若 RUL 精度不变甚至变好，则"年龄进状态"
  是冗余甚至有害；若显著变差，则年龄确实携带状态信息，Q1 的前提被推翻。
- **为什么它还没被回答**：六篇里两篇根本不喂 cycle，所以没有一篇需要回答"喂了之后该接在哪"。

### Q2：结构化 HI 若真的参与 RUL 计算，它的收益是否只出现在长引擎的早窗？

- **为什么值得问**：cap 125 的标签定义会把长引擎早段压成常数（FD004 有 67/248 台真值 >125）。
  在这些窗口上任何模型都"没得可学"，HI 结构若真有作用，应当体现为**早窗误差下降**，
  而不是全窗平均下降——全窗平均会被后期窗口主导。
- **否证方式**：按 `lifetime_tertiles` 与 `rul_bins` 分层报 RMSE。若 HI 参与前后各层差值与
  总体差值同号同幅，则"只在早窗有效"不成立，收益来自别处。

### Q3：在相同信息集下，HI 结构还剩多少增益？

- **为什么值得问**：§5 会说明，我们对不喂 cycle 的两篇论文**不能声称架构级优势**——多一个通道
  的收益属于信息。所以必须有一个"信息对齐"的内部对照，否则 Paper B 的核心主张无法与"我们多给了
  一个输入"区分开。
- **否证方式**：只在"都给 cycle 编码"的臂之间比较（A1 无 cycle / A2 原始标量 / A3a Fourier /
  A4 log / A5 spline，同骨干同 seed）。若这些臂之间的差异都在初始化噪声内，则 HI 结构在信息对齐
  条件下无增益。

## 6. 跨论文比较的三条脚注（引用时必须带）

这一节是**方法学**而非文献内容，但直接决定 gap 能否被证实。

- **F1 输入信息不对等**：SFI-STHGAT、ST-KDFormer 不喂 cycle，STGATN 把 cycle 当标签。
  我们的 cycle 臂多一个通道。公平的架构比较只有我们自己的 Vanilla 2×2（只加 cycle 编码：
  12.803 → 11.758）。
- **F2 测试标签口径未核实**：五篇全未声明测试标签是否裁剪、预测是否裁剪。主表用 capped 是
  **本工作冻结口径**，不是"与文献同口径"。
- **F3 评估单位不一致**：只有 DCCG-Mamba 写明"number of test engines"，其余四篇写"number of
  samples"，无法判定是末窗还是全窗。
- **F4 调参预算不对等**：ST-KDFormer 100 epoch（AdamW, lr 1e-3, MultiStepLR 10/20/30/40 ×0.5,
  batch 128）；DCCG-Mamba 120 epoch 且**逐子集用 DA-MT-MFBO 元启发式调参**；我们 40 epoch /
  patience 12。对性能结论偏保守，**但对消融是混杂变量**。

消融的正确表述（已由主控裁定）：
> **在 40 epoch 预算下未检出独立增益，且该预算小于可核实的对比论文，不能排除预算不足。**
> 结论等级仍是「未检出」，不升格成「无效」。
