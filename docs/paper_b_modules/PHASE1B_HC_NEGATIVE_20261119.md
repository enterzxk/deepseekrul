# Phase 1b：多工况 H_c 负结果与 Gate 1 判定

> 日期：2026-11-19。代码：`paper_b/modules/rhse_hc.py`。
> 结论：**H_c 没有改善重构；FD002/FD004 的失败不是“单矩阵 H 在多工况下失配”，
> 而是检测/重构在 stuck/noise 上本身不够。Gate 1 按原计划不通过；不建议据此进入 Phase 2。**

## 1. H_c 诊断

对每个离散工况 c 单独拟合 `H_c ∈ R^{14×3}`（training late-life dy，按窗口末周期 cond 分组），
用 oracle 已知故障传感器、Hθ 重构故障传感器，比较重构 MSE（越小越好）：

| 子集 | global H MSE | H_c MSE | H_c/global |
|---|---:|---:|---:|
| FD002 | 0.6106 | 0.6166 | **1.010** |
| FD004 | 0.4686 | 0.4776 | **1.019** |

**H_c 没有帮助，反而略差。** 每个工况样本充足（FD002 5880–12040 行/工况；
FD004 5600–10850），不是样本不足。说明单矩阵 H 已经足够表达测量关系；
多工况失败的原因不在 H 失配。

## 2. 失败原因（从 R0/R1/R2 看）

FD002（s101，mag=3，sensors 0/5/10）：

| 故障 | R0 | R1 | R2 oracle | 读法 |
|---|---:|---:|---:|---|
| stuck | 12.732 | 13.477 | 13.050 | R2 只恢复 0.573；Hθ 重构本身不够 |
| noise | 12.732 | 12.966 | 13.050 | R2 **比 R1 更差**；Hθ 不是 noise 的正确修复方式 |

- **stuck**：R2（oracle 已知故障传感器）只有 0.573，说明即使知道哪个传感器坏了，
  Hθ 重构也救不回 0.65；H_c 不改变这一点。
- **noise**：R1−R0 只有 0.234，fault 本身伤害很小；R2 比 R1 更差，说明“用 Hθ 平滑”
  对随机噪声不适用。噪声需要的是滤波/去噪，不是测量模型重构。
- FD004 的 drift/noise 同理：R3 0.518/0.338，H_c 不会改变重构质量。

## 3. Gate 1 判定

| 条件 | 结果 |
|---|---|
| clean 代价 ≤0.15 | FD001 +0.024 通过；FD002 +0.227 不通过 |
| EOL FPR ≤2% | TSH 未测；simple RHSE 1.8% |
| 平均 recovery ≥0.65（≥3/4 子集） | **不通过**（FD002/FD004 明显低于 0.65） |
| R4 在 stuck 上领先 R5 ≥0.10 | FD001/FD003/FD004 通过；FD002 两者都负 |
| R4 在 drift 上领先 R5 ≥0.10 | 只有 FD004 达到；FD001 晚漂移 R5 更好 |
| onset=0.20 领先 R5 ≥0.10 | FD001 drift +0.079（接近）；stuck 大幅通过 |

**Gate 1 不通过，且 H_c 不是修复路径。** 按计划 §4.3 的决策树：
- “R2 好、R4 差” → 问题在检测；但 FD002 stuck 的 R2 只有 0.573，**R2 也不好**；
- “R2 也差” → 问题在重构/骨干敏感性，需要端到端训练；
- 但 noise 的 R2 < R1 说明 Hθ 重构对 noise 是错误归纳偏置，端到端也未必能救。

## 4. 建议（PENDING-L2）

**不要进入 Phase 2 端到端。** 目前证据支持的最强叙事是：

1. **LTAG 主线**：test 15/15，+0.398；这是唯一 test 级验证的模块。
2. **RHSE-TSH 单工况条件性结果**：FD001/FD003 的 bias/stuck/drift 恢复 0.59–0.97，
   clean 代价 +0.024；作为“传感器故障下的可解释前端”写，明确多工况限制。
3. **多工况负结果**：FD002/FD004 的 stuck/noise 不适合 Hθ 重构；noise 需要滤波，
   stuck 需要更好的重构或直接 last-value；这是边界/讨论，不是主贡献。
4. **Phase 2 端到端暂缓**：Gate 1 未过；除非先解决 noise 的重构归纳偏置和 FD002
   stuck 的 R2，否则端到端只是把失败放大。

**下一步（可逆）**：
