# 传感器侧创新 + 结构化 HI：最新文献 gap 与候选模块

> 日期：2026-11-18。目的：回答“最新航天发动机在传感器侧做了什么、我们还能做什么、
> 怎样和结构化 HI 结合”。只列已核实 URL 的工作；未读全文的标 `[摘要级]`。
> 本地前置：`docs/paper_b_hc/RELATED_WORK_GAP.md`、`docs/DSPT_SENSOR_MODULE_DESIGN_20261114.md`、
> `docs/paper_b_sensor_study_20261114/RESULTS.md`（传感器替换/关系残差/分组实验的终值）。

## 0. 一句话结论

传感器侧最新工作集中在**图/注意力融合、传感器耦合不确定性、传感器选择、传感器掩码增强**；
**“逐传感器单调 HI + 动态可靠性 + 结构化累积 HI”这个组合还没有被直接占住**。
但“多指标融合 HI”“复合 HI”“传感器选择”都已有工作，不能把 HI 本身当新意；
可写的新意只能是**逐传感器单调状态 + 动态可靠性权重**，以及它与冻结 RUL 骨干的零初始化结合。

## 2. 真实 gap

**没有被直接占住的组合**：

> 逐传感器维护一个**单调健康状态** `H_tj`（不是特征，也不是单一复合 HI），
> 用**动态可靠性** `r_tj`（时序一致性 + 跨传感器共识 + 工况稳定性）加权融合成结构化 HI `H_t`，
> 再把 `H_t` 以**零初始化残差**接回冻结 RUL 骨干。

与最近邻的差异：
- vs UCD-OCMN：它在图边权上建模耦合不确定性；我们在 **HI 状态**上做逐传感器单调 + 可靠性融合。
- vs EAAI CHI：它是**单一**复合 HI；我们是**逐传感器 HI bank** + 可靠性，能定位“哪个传感器在退化”。
- vs 多指标动态 HI：它融合多个指标成系统 HI；我们保留逐传感器状态并显式估计可靠性。
- vs 熵权选择：它是静态选通道；我们是**逐样本/逐时刻**可靠性，能处理传感器漂移/失效。
- vs sensor-aug / 关系残差：那些在特征/重建层；我们在 **HI 层**，且零初始化保证不劣于 B0。

**不能声称**：
- “首次用 HI 做 RUL 状态”（EAAI 2025 已做）；
- “首次多传感器融合 HI”（多指标融合/CHI 已有）；
- “首次传感器选择”（熵权 2026 已有）；
- “传感器图/注意力融合”（UCD-OCMN、ADFG、STGATN 等已有）。

## 3. 候选模块

### M1（首选）SMHI-RF：Sensor-wise Monotone HI with Reliability Fusion

- 输入：冻结 B0 的逐传感器 token `h_tj`（来自 `sensor_attn` 的 hook，B×L×N×D）。
- 逐传感器增量：`δ_tj = softplus(MLP(h_tj)) ≥ 0`；`H_tj = cumsum_t δ_tj`（窗口内单调）。
- 可靠性：`r_tj = softmax_j( MLP([h_tj, mean_j h_tj, 时序一致性]) )`。
- 融合：`H_t = Σ_j r_tj H_tj / Σ_j r_tj`；取窗口末端 `H_last`。
- 接回：`pred = reg_head(z) + res_head([z, H_last])`，`res_head` 末层零初始化 → step 0 = B0。
- 训练：冻结 B0，只训 HI bank + res_head；censored hinge；training engines；validation 只评价。
- 消融：HI bank 开/关；可靠性 vs 均匀；逐传感器 vs 单池化 HI；单调 vs 无约束；
  传感器噪声/缺失压力测试；与 LTAG（K=3）组合。

**假设**：逐传感器单调 HI + 可靠性融合能在 FD002/FD004（多工况、传感器耦合复杂）上
降低 RUL RMSE，并在传感器噪声/缺失下比 B0 更稳；FD001 至少不劣。

**否证**：若 validation 上四子集均无正增益，或增益在传感器压力测试下消失，则撤下。

### M2：传感器耦合可靠性门控 HI

- 用简单的跨传感器耦合一致性（滑动窗口相关矩阵的稳定性 / 残差）估计 `r_tj`，
  替代 M1 的学习可靠性；其余同 M1。
- 更接近 UCD-OCMN 的“耦合不确定性”，但落在 HI 层；作为 M1 的机制对照。

### M3：传感器退化感知 HI

- 为每个传感器维护一个偏置/噪声状态 `b_tj, σ_tj`，从早期基线漂移估计；
  用 `1/σ_tj` 作为可靠性；HI 融合时降权退化传感器。
- 主要用于噪声/缺失鲁棒性；clean 上可能无增益。

## 4. 最小实验（先做 M1）

- 数据/协议：Stage D B0 冻结 checkpoint；4 子集；seeds 101/202/303（FD001 可 6）；
  training engines 训练 HI bank，validation cuts 评价；test 封存。
- 规模：每子集 3 seed × 2 臂（B0 / B0+SMHI）× 5 cuts；只训小头，GPU 成本低。
- 判定门（预注册）：
  1. 四子集 validation engine-mean RMSE 相对 B0 的平均增益 ≥ 0.20，且 ≥3/4 子集点估计为正；
  2. 至少一个多工况子集（FD002/FD004）增益 ≥ 0.20 且 3/3 seed 同号；
  3. 传感器噪声/缺失压力测试下，SMHI 的退化小于 B0（预注册噪声水平）；
  4. 消融：可靠性融合 ≥ 均匀融合；逐传感器 ≥ 单池化 HI；单调 ≥ 无约束。
- 若 M1 过门，再与 LTAG 组合（LTAG 的 gate 特征加入 `H_last`），看是否叠加。

## 5. 风险

- Stage D 的单 HI/首达模型曾显著差于 B0；M1 必须用**零初始化残差**，不能替换 RUL 头。
- 逐传感器 HI 可能学到“传感器身份/工况”而不是退化；需传感器替换/打乱对照。
- 可靠性权重可能塌缩到少数传感器；需熵/稀疏正则与消融。
- clean 上可能无增益（sensor-aug 的先例）；噪声/缺失下的鲁棒性必须预注册，不能事后挑。
- 最近邻（UCD-OCMN、EAAI CHI、多指标 HI）已占住“传感器图/复合 HI”；论文只能写
  “逐传感器单调 HI + 动态可靠性”的窄差异，不能写“首次”。
