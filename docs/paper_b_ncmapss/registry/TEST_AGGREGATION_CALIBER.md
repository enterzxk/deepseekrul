# 测试批 20 个聚合列的「可断言性」标定

**回答一个问题**：测试行上那 20 个按机聚合的列，哪些格子的值与池化值**在代数上必然相等**，
因此那一格不携带「聚合口径」的信息？

答案不能靠比数值，但**也不能用一条统一判据**——聚合函数不同，「必然相等」的条件就不同。

## 判据按族分（这是关键）

| 族 | 列 | 必然相等当且仅当 | 为什么 |
|---|---|---|---|
| **RMSE 族**（14 列） | `rmse_raw_unit`、`rmse_cap125_unit`、12 个 `seg_*` | **恰好一台机贡献数据** | `sqrt(mean)` 非线性 |
| **线性族**（4 列） | `mae_*_unit`、`bias_*_unit` | 恰好一台机，**或各机样本数相同** | 池化就是按样本数加权 |
| **NASA 族**（2 列） | `nasa_*_unit` | **恰好一台机** | 它是求和 |

**RMSE 族为什么不能沿用线性族的判据**（两台机各一个误差 `0` 和 `2`）：

```
逐机等权 = (0 + 2) / 2          = 1.000
池化     = sqrt((0² + 2²)/2)    = 1.414
```

样本数相同（各 1 个），两种聚合却不等。一般地，逐机是 `(1/E)Σ_i sqrt(S_i/k_i)`，
池化是 `sqrt(Σ_i S_i / Σ_i k_i)`——只有 `S_i/k_i` 全部相等时才碰巧相等，那是巧合，不是结构。
NASA 更直接：它是求和，池化永远比逐机等权大 `E` 倍，除单机外永不相等。

## 实测（80 行 × 20 列 = 1600 格）

```
rmse 族   degenerate 40   / ok 1080
线性族    degenerate  0   / ok  320
NASA 族   degenerate  0   / ok  160
合计      pass 1560       degenerate 40    pass_coincident 0
```

那 40 格全部是 **DS02 的 `seg_early_absolute_capped` / `_raw` × 20 行**——
该段只统计 RUL ≥ 75 的飞行，DS02 只有 unit 14 够到（11、15 的寿命是 58/66），`counts=[1]`。

`pass_coincident` 至今**一次都没出现**。经理举的那个 1.261「碰巧相等」是
`DS02_N0_TEST_f200` 的 `seg_early_absolute_raw`、`counts=[1]`，属于结构性退化，不是巧合。

## 一条更正（我自己写错过，留在这里）

本文件初版写「各机样本数相同 ⇒ 退化」，并据此报出 **240 格**退化，其中包含
`seg_late_absolute_*`（四台机各 25 个飞行）与 DS07 的 `seg_mid_absolute_*`（各 50 个）。
**那是错的**：这条判据只对线性聚合成立，被套到了 RMSE 上。
`seg_late_absolute_*` 在四个子集上**不退化**——各机 25 个飞行看着整齐，但 `sqrt` 非线性，
逐机与池化只在各机误差平方和相等时才碰巧相同。**正确数是 40，不是 240。**

教训写在这里而不只是改数：**判据要先问「聚合是什么函数」，再问「样本数」，不能反过来。**
