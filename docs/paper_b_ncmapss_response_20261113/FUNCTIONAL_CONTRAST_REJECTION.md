# 未立项：函数范数白化／解码响应差

2026-11-14，仅理论与文献审查，未实现、未启动任何该候选GPU。两位新上下文Codex独立方法与新颖性代理分别审查，顶层采纳“数学诊断、不立项”决定；不复活失败的common。

候选为G0=E_q0[A(W)^T A(W)]、拟合h时以λh^T G0h正则，再向时序头输入解码差Δf(W)=A(W)(hf−hr)的均值/能量或固定节点值。q0拟仅来自训练机。对G0正定，z=G0^(1/2)h及B=A G0^(−1/2)把它精确化为普通ridge；等价有限秩向量KRR的核为K(W,V)=A(W)G0^(−1)A(V)^T。因此修正换基缺陷本身是已有函数空间几何，不是新sensor机制。

G0奇异时，目标只定义半范数；直接删null空间不必等价于原优化。例q0仅见A=[1,0]、观测A=[1,1]，目标(h1+h2−1)^2+λh1^2最优可令h1=0/h2=1；先截断第二维则得到h1=1/(1+λ)。系数坐标中的εI及谱阈值还会破坏一般非正交换基不变性。

更大的background平移歧义仍存在：b→b+A c，h→h−c。每航班收缩S_i=(Q_i+λG0)^−1Q_i不同，则估计差额外改变−(Sf−Sr)c。无噪声标量例G0=λ=1，真实两h均1而Qf=1/Qr=4，估计.5/.8给假差−.3A；把b移为b+A则两残差/估计差均0。换基修正不识别退化变化。

能量也含估计噪声；无独立噪声假设时PSD能量不是健康强度，正负变化被平方消去。固定节点若满列秩只是同k维系数的可逆重编码；继续输入原full_h的level支路还会令整个模型保持坐标依赖。共同W覆盖不保证局部激励、未观测历史消除或q0外推有效，任何未来主张均需明确假设与误差/拒绝保证。

若未来只做数值诊断，必须对照精确白化FE/KRR、非正交换基、零真变化但不等采样、background平移、奇异support以及最强经典残差同头对照。通过不变性只说明实现正确，不说明新颖性；无独特机制能越过精确等价对照，当前不值得新GPU矩阵。保留此拒绝证据，后续不重新包装同一想法。
