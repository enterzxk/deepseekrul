在本套配置中，使用传感器的raw管线在前三子集优于W-only，在DS07却更差；DS07的确定性年龄先验也明显更好。不能把“传感器影响大”解释为跨子集必然收益，或由任何单独新结构造成。

W-only保留同70航班头、W/coverage/age，但Xs置零且禁用sensor辅助监督；raw有sensor训练信息和辅助context路径。此表是信息参考比较，不是只遮一列而其它训练路径完全相同的孤立因果效应。三seed先算各engine误差再等权，seed不是新增engine。

D1说明工况解释的变化占据大部分raw尺度，剩余残差的年龄关联较强；这仍可能包含模型误差、动态与初始条件。D2的末态梯度没有支持重建梯度支配。D3因此只检查固定残差预条件是否已经足够，须对照aux开关与严格配对；在D3完成前不把尺度诊断写成RUL收益。

旧DSPT的原始传感器/相对早期基准/平滑等输入设计仍需在其原协议中分别判断。当前新数据的raw512同步点实验不能冒称冻结DSPT改动或旧周期编码结论复现。
