## 1. Q1：Cycle 能否作为架构无关插件稳定改善公开方法

**两半是两个不同的问题，不得合并成一张「Cycle 效应」表。**
第一半问「在 DSPT 上把 Cycle 注入哪里」；第二半问「把那个位置套到别人的方法上，还有没有增量」。
第一半的绝对数与第二半的绝对数**不可比**（选轮口径不同，见 §1.2 引用），只能比 within-method Δ。

### 1.1 第一半：DSPT 上的注入位置

**判据原文（`S1A_POSITION_PREREG.md` §3，冻结，按顺序执行）：**

> 1. **合格集** `Q = {p : CI_p 上限 < 0 且 n_neg(p) ≥ 3}`。
> 2. `|Q| = 0` → **无胜出**。用 `pre_norm` 作实现默认值，文档写
>    「位置未由证据识别，沿用默认」。若同时 `none` 对每个 Cycle 位置的合并 CI 上限 < 0
>    （即 Cycle 显著更差），另记一条「DSPT 上 Cycle 为负效应」。
> 3. `|Q| = 1` → 该位置为**唯一胜出**。
> 4. `|Q| ≥ 2` → 取 `Δ_p` 最负者；它必须对 `Q` 中**每一个**其他位置都有
>    「成对合并 CI 上限 < 0」。满足 → 唯一胜出；不满足 → **无唯一胜出**，
>    用 `pre_norm`，文档写「多个位置优于 none，但彼此不可区分，沿用默认」。
> 5. 若两个位置 `Δ_p` 浮点完全相同，优先 `pre_norm`（只为确定性，不是科学理由）。
>
> **`none` 不能「胜出」**——它是参照臂。若 `none` 最好，结论是「无 Cycle 位置通过」，
> 不是「none 是胜出位置」。

**报告要求（§4，缺一不可）：** 4×4 绝对表（含 seed sd、机数、seed 列表）；每个 Cycle 位置对
`none` 的合并差与 95% CI、方向计数、5 个 seed 级差；**所有位置两两**的成对合并 CI；参数量
（总参数与有效可训练参数）；**多重比较**须同时报 98.33% CI（Bonferroni，α = 0.05/3），若跨 0
必须写「方向一致但未过校正门槛」，不得称「显著胜出」；按机数加权作敏感性单列，若与等权符号
相反须写「结论对聚合权重不稳健」。

**本节的结论：**

**判定走 §3 第 4 条（`|Q| ≥ 2`）。** 三个 Cycle 位置**全部合格**（95% CI 上限 < 0 且
`n_neg ≥ 3`，Bonferroni 98.33% CI 也全部不含 0）：

| 位置对 `none` | 合并 Δ | 95% CI | 98.33% CI | 方向 |
|---|---:|---|---|---:|
| `pre_norm` | **−1.3122** | [−1.8898, −0.7583] | [−2.0230, −0.6441] | 4/4 |
| `post_norm` | −1.0127 | [−1.4042, −0.6244] | [−1.4878, −0.5426] | 4/4 |
| `head_concat` | −0.7508 | [−1.1284, −0.4012] | [−1.2058, −0.3265] | 3/4 |

取 Δ 最负者 `pre_norm`，要求它对 `Q` 中**每一个**其他位置都成对 CI 上限 < 0。对 `post_norm`：

> `post_norm − pre_norm` = **+0.2994**，95% CI **[−0.1409, +0.7303]**，方向 4/4

**CI 跨 0 → 不满足支配 → 无唯一胜出。** 于是按 §3 第 4 条回落到 `pre_norm` 作实现默认值。
注意方向是 4/4 一致的（四个子集上 `post_norm` 都比 `pre_norm` 差，点估计 +0.03 到 +0.64），
跨不过 0 是**精度不够**，不是方向相反——这一点必须和「无差异」区分开写。

`head_concat` 则明确被排除：`head_concat − pre_norm` = +0.5614，95% CI [+0.1420, +0.9817]，
方向 0/4，两个区间都不含 0。但它是否被支配**不影响**上面的结论，因为支配要求对所有合格位置成立。

**默认位置是否启用：是。** 但按 §6 与组内规则，正文只能写「**默认位置**」，
**不得写成「最优位置」或「胜出位置」**——它是规则在无支配者时的回落值，不是证据选出来的。

**多重比较：过门槛，但不是胜出。** 三个位置的 98.33% CI 全部不含 0，说明「Cycle 比 `none` 好」
这件事扛得住 Bonferroni；而「哪个位置最好」扛不住——那是成对支配的问题，不是多重比较的问题。

（出处：`S1A_CYCLE_MATCHED.md` §7.1–§7.3。）

#### 1.2.1 主张 R（重编码增量）

**范围与主比较（§5.1）：** 范围为 `aidgn` / `two_phase` / `ffve` / `fcstgnn` 四个方法；它们已吃
归一化 `age`，测的是**Fourier 重编码在已有 cycle 输入之上的增量**，不是「cycle 信息有没有用」。
主比较逐方法不同：`aidgn`、`two_phase`（有 sham 臂）为 **V1 − sham**；`ffve`、`fcstgnn`
（无 sham 臂）为 **V1 − V0**。

**单方法「通过」的定义（三个条件同时满足，缺一不算）：**

> 1. 该方法的合并点估计为负；
> 2. 该方法的 ≥3/4 子集点估计为负；
> 3. 该方法的合并 95% CI 不含 0。

**三档判定（互斥且穷尽，开跑前写死，不得按结果改）：**

> 记 `p` = 通过的方法数，`m` = 方向一致的方法数（该方法 ≥3/4 子集点估计为负）。
> 「通过」本身要求 ≥3/4 子集为负，所以恒有 `m ≥ p`。
>
> - **强结论**：`p ≥ 3`；
> - **弱结论**：`p < 3` 且 `m ≥ 3`；
> - **不成立**：`m < 3`。
>
> 「合并 CI 跨 0」只用于**描述未通过的方法**，不作档位条件。
> 「≥3/4 方法」是**逐方法过门槛的计数**，不是把四个 Δ 跨方法平均。

**「不成立」的后果（§5.1，预先写定）：** 主张 R 不成立，如实记录为负面结果；按预登记判据，
主线改为**协议审计、强基线与机制归因**，不得事后改判据或换口径重算。

**本节的结论：**

档位 **weak**（`p = 2`、`m = 4`）。五方法主比较（engine-level，四子集等权，seed 先平均再合并，
10,000 次重采样）：

| 方法 | 主比较 | Δ | 95% CI | 子集同号 | 判定 |
|---|---|---:|---|---:|---|
| `aidgn` | V1−sham | −11.7130 | [−12.8280, −10.5461] | 3/4 | 机械过线，**控制失效**（`S1A2_PUBLIC.md` §1.9），不提供肯定支持 |
| `two_phase` | V1−sham | **−0.7129** | [−1.0542, −0.3729] | **4/4** | **通过；唯一干净的正结果** |
| `dual_mixer` | V1−sham | −0.1615 | [−0.4745, +0.1516] | 3/4 | 不通过（主张 I，见 §1.2.2） |
| `ffve` | V1−V0 | −0.2371 | [−0.5745, +0.1099] | 3/4 | 不通过（CI 跨 0） |
| `fcstgnn` | V1−V0 | −0.3091 | [−0.6887, +0.0811] | 3/4 | 不通过（CI 跨 0） |

**强档不成立，而且不是「差一点」。** 可解释的四个方法里只有 `two_phase` 同时满足三条件，即
`s = 1`；**即使把控制失效的 `aidgn` 也算作通过，`s + 1 = 2 < 3`**，强档要求的「≥3 个方法通过」
无法满足。去掉 `aidgn` 后 `m = 3`（`two_phase`、`ffve`、`fcstgnn` 均 ≥3/4 子集为负），
弱档在可解释口径下仍然成立。

**`two_phase` 的干净形态**：V1−V0 = −0.5453（CI [−0.9634, −0.1363]），sham−V0 = +0.1676
（CI [−0.1776, +0.5183]，跨 0，说明 sham 没被弄坏）。逐子集 −0.496 / −0.443 / −1.107 / −0.806，
去掉任一子集后仍在 −0.58 到 −0.68 之间，**不靠单格**。

**`aidgn` 单列，不进档位**：它的负值全部来自 sham 损伤（sham−V0 = +12.8597），5/12 格 sham
没训练起来（`rel` = 0.92 / 0.87 / 0.81 / 0.75 / 0.50），是控制失效不是效应。事后尺度匹配的
24 格给出 V1−V0 = −0.4035（CI [−0.7489, −0.0723]，4/4），但那是 **post hoc**，只作解释性证据；
主分析那一行 −11.7130 保持原样、继续标 CONTROL-COMPROMISED。

**正文措辞（写死，不得改写）：** 不得写「重编码带来稳定增量」（强档不成立），也不得写
「Cycle 无效」（落在弱档而非「不成立」档）。准确说法是：**三个可解释方法方向一致，
其中只有一个达到统计显著。**

#### 1.2.2 主张 I（信息效应）

**判据原文（§5.2）：**

> 只在 `dual_mixer` 上单方法报告 **V1 − sham**（n = 1），不做跨方法合并。
> `dual_mixer` 是唯一没有 `age` 输入的方法，V1 与 sham 同容量、同全量训练、只差编码置换，
> 所以这是一个干净的单方法信息对照。
>
> **多方法合并的信息效应不在本套件内**，归第一半 DSPT（`none` 臂没有任何 cycle 通道）。

**标签（§5.3）：** 有 sham 臂的三方法，**V1 − sham = 等容量信息对照（主）**，
**V1 − V0 = 容量 + 信息（次要，不得当信息效应读）**；无 sham 臂的两方法 V1 − V0 即主比较。
**五个方法不得平权平均成一个「Cycle 效应」**：`dual_mixer` 单独一列，另外四个一列。

**本节的结论：**

`dual_mixer` 的 V1−sham = **−0.1615**（95% CI [−0.4745, +0.1516]，3/4 子集同号），CI 跨 0，
**主张 I 不成立**。拆开看两项都跨 0：sham−V0 = +0.1830（[−0.1368, +0.5155]）、
V1−V0 = +0.0215（[−0.3126, +0.3540]）——**既没有「插件有害」也没有「插件有益」的证据**。

按 §5.2 的冻结口径，这是 **n = 1 的单方法报告，不做跨方法合并**；多方法合并的信息效应归第一半
DSPT（`none` 臂没有任何 cycle 通道）。所以本节**不得**与 §1.2.1 的四个方法放在一张表里排序。

> 选择规则的实验。

**为什么不用「条件性命中」这种写法：** 那个条件句听起来更温和，但它仍然预设「有一个判据、
只是没预注册」。阈值和规则都不可核验时，「在某个规则下命中」也不成立——「条件」是事后挑的，
写成条件性命中等于给审稿人一个现成的攻击面。Q1 与 Q3 有预登记判据，Q2 没有，这是事实，
照实写比修饰更稳。

## 3. Q3：寿命辅助信息要多高精度才让当前模型明显变好

**主口径（`S2_BREAKEVEN.md` §5，定义已于 2026-11-14 冻结）：**

> **σ\* 逐子集定义。** 每个子集单独取「ΔRMSE 相对无辅助对照仍降 ≥ 0.3 的最大 σ」，**报四个数**。
>
> **分档也逐子集套**：σ\* < 0.10 无空间；0.10 ≤ σ\* < 0.20 弱空间；σ\* ≥ 0.20 有空间。
> 四个子集若落在不同档，**如实写成不一致**，不取中位数、不按多数票。
>
> **次口径（辅助，不替代上面的四个数）**：若要给一个汇总数，写「≥3/4 子集同时达到 −0.3 的
> 最大 σ」，并明确标注为辅助汇总。

**两条必须写进结果的边界（§5）：**

> - 若最大测试值 σ=0.30 仍达到 −0.3，则 σ\* 是**下界**而不是上限——没有测更大的 σ，
>   不能声称曲线在此处转折。
> - 判据只回答「需要多准」，不回答「能不能估到这么准」。后者不在 S2 范围内。

**用途边界（§5.4）：** S2 只用于决策，**不进主结果表、不写成方法**；辅助量是「真实总寿命 +
噪声」，现实中不可得，是诊断工具不是贡献。

**本节的结论：**

四个子集 σ\* = **0.30 / 0.30 / 0.10 / 0.30**（FD001 / FD002 / FD003 / FD004），逐子集分档为
**有空间 / 有空间 / 弱空间 / 有空间**。

**分档在子集间不一致，如实写不一致**——不取中位数、不按多数票。这不是「S2 没做好」：
判据本来就是逐子集定义的，逐子集套出不同档是它该有的行为。

**其中三个 0.30 是网格上界造成的下界。** σ 网格到 0.30 封顶，那三个子集在 0.30 处仍然达标，
所以只能说 σ\* ≥ 0.30，**不能声称曲线在 0.30 之后转折**——我们没有测更大的 σ。

**尾部很薄，σ\* 应读作「至少」而不是「大约」**：在 σ=0.30 处收益只剩 0.37–0.48 周期，
离 −0.3 的阈值只有 0.14–0.42 个 seed-sd。留一 seed 检验（事后）显示每个子集都至少有一个尾点
会翻到阈值之上（去掉一个 seed 后分别落到 −0.164 / −0.243 / −0.114 / −0.297）。判定仍按预登记的
5-seed 均值执行，这条只说明边际很薄。

**FD003 的档位贴着边界**：它的连续穿越点按 0.10→0.20 线性插值约在 σ≈0.19，仍落在「弱空间」档内，
但离 0.20 的档边界很近。**这是插值、不是实测**，换一套更密的 σ 网格可能改变它的档位；本次按冻结
规则给「弱空间」，不因插值改判。

**用途边界（不得违反）：** S2 只用于决策，**不进主结果表、不写成方法**。这里的辅助量是
「真实总寿命 + 噪声」，现实中不可得，它是诊断工具，不是贡献，也不是可部署的模块。

## 5. 已知缺口

分两类，**不得混在一起写**：5.A 是我们流程造成的（没做好），5.B 是数据本身就是这样（做到了但不一致）。
混在一节会让人把「数据不一致」读成「我们没做好」。

补齐了就把对应条目标 `已补`，**不删除**。

### 5.A 过程缺陷（我们没做好的）

1. **7 个作废格（DataLoader `generator=` 协议差异）。** 逐格名称、原因与可比性见
   `S1A2_PUBLIC.md` §1.4。其中「作废版与重跑版的差值」只在已重跑的格上可比，未重跑的格没有
   差值——该节须写清哪几格可比，不得让读者以为七格都有差值。
2. **`two_phase` 的预训练是确定性重放，不是原生重训。** 重放规则见 `S1A2_PUBLIC.md` §1.6；
   它和其余四方法的训练起点不同，这一点必须在正文出现，不得只写在附录。
3. **`dual_mixer` 的容量差。** V1 相对 V0 参数量增加 13.47%（64,123 → 72,763），
   V1 全量训练、不冻结基座；因此 **V1 − V0 只能读作「容量 + 信息」**，等容量主判据是
   **V1 − sham**。「冻结基座只训头」的妥协已撤回，撤回理由见预登记 §6。
4. **S1-B 的阈值与选择规则没有预注册。** 两者最早都出现在 `S1B_READOUT.md` 的创建提交，
   之前零命中（见 §2 的五条检索命令与结果）。唯一先于报告写下的约束是 `18a77f13` 要求的
   「用 engine-level 选轮」，早 12 分钟，不构成开跑前冻结。因此 Q2 无可核验判据；
   要强结论须在未看过 TEST 的新种子或新子集上重做一次带冻结阈值与冻结选择规则的实验。
5. **S1-B 的第二条判据在 RMSE 改善时是空条件。** 「RMSE 变化不超过种子标准差」只在 RMSE
   **变差**时起约束作用；选中变体的 RMSE 下降时它自动满足。判据的实际强度比字面弱，须与结论同报。
6. **S2 的三个 σ\* 是下界，不是上限。** σ 网格到 0.30 封顶，其中三个子集在 0.30 处仍达标，
   所以那三个是**下界**；不能声称曲线在 0.30 之后转折。这是我们没测更大的 σ，不是数据说停在那里。
7. **第二半的绝对数与第一半不可比。** V0 用 pooled 选轮、第一半用 engine-mean 选轮，
   只能比 within-method Δ；`S1A2_PUBLIC.md` §1.5 的噪声底同样限制解读，填写时一并引用。

### 5.B 结果限制（数据本身如此，不是流程缺陷）

1. **S2 分档在子集间不一致。** 按冻结规则如实写不一致，**不取中位数、不按多数票**。
   这不是「S2 没做好」——判据本来就是逐子集定义的，逐子集套出不同档是它该有的行为。
2. **（预留）主张 R 若出现逐方法方向相反**：那是数据，不是缺陷。按 §1.2.1 的三档判定归类，
   不得因为方向不一致去调整口径或剔除方法。

**填写规则：** 凡是我们流程造成的，一律进 5.A；凡是我们按冻结规则算出来、只是不合预期的，
一律进 5.B。**不许把 5.B 的条目挪进 5.A 来免责，也不许把 5.A 的条目写进 5.B 来淡化。**

**这两个小节只记录事实，不含判定。** 判定只写在 Q1 / Q2 / Q3 各节里。
将来任何人**不得从 5.A / 5.B 反推结论**——例如「5.A 第 4 条说判据没预注册，所以 Q2 不成立」
这种推理不允许；Q2 的定性由 §2 自己的文字给出，不由缺陷清单推出。
