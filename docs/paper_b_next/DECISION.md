## 1. Q1：Cycle 能否作为架构无关插件稳定改善公开方法

**两半是两个不同的问题，不得合并成一张「Cycle 效应」表。**
第一半问「在 DSPT 上把 Cycle 注入哪里」；第二半问「把那个位置套到别人的方法上，还有没有增量」。
第一半的绝对数与第二半的绝对数**不可比**（选轮口径不同，见 §1.2 引用），只能比 within-method Δ。

### 1.1 第一半：DSPT 上的注入位置

**判据原文（`S1A_POSITION_PREREG.md` §3，冻结，按顺序执行）：**

> 1. **合格集** `Q = {p : CI_p 上限 < 0 且 n_neg(p) ≥ 3}`。
> 2. `|Q| = 0` → **无胜出**。用 `pre_norm` 作实现默认值，文档写
>    「位置未由证据识别，沿用默认」。若同时 `none` 对每个 Cycle 位置的合并 CI 上限 < 0
>    （即 Cycle 显著更差），另记一条「DSPT 上 Cycle 为负效应」。
> 3. `|Q| = 1` → 该位置为**唯一胜出**。
> 4. `|Q| ≥ 2` → 取 `Δ_p` 最负者；它必须对 `Q` 中**每一个**其他位置都有
>    「成对合并 CI 上限 < 0」。满足 → 唯一胜出；不满足 → **无唯一胜出**，
>    用 `pre_norm`，文档写「多个位置优于 none，但彼此不可区分，沿用默认」。
> 5. 若两个位置 `Δ_p` 浮点完全相同，优先 `pre_norm`（只为确定性，不是科学理由）。
>
> **`none` 不能「胜出」**——它是参照臂。若 `none` 最好，结论是「无 Cycle 位置通过」，
> 不是「none 是胜出位置」。

**报告要求（§4，缺一不可）：** 4×4 绝对表（含 seed sd、机数、seed 列表）；每个 Cycle 位置对
`none` 的合并差与 95% CI、方向计数、5 个 seed 级差；**所有位置两两**的成对合并 CI；参数量
（总参数与有效可训练参数）；**多重比较**须同时报 98.33% CI（Bonferroni，α = 0.05/3），若跨 0
必须写「方向一致但未过校正门槛」，不得称「显著胜出」；按机数加权作敏感性单列，若与等权符号
相反须写「结论对聚合权重不稳健」。

### 1.2 第二半：把默认位置套到公开方法

**指标定义（`S1A2_PUBLIC_PREREG.md` §5）：**

> **指标**：engine-level RMSE，从每格 `validation_predictions.csv` 重算——先对每台发动机的 5 个
> 截点算 RMSE，再对发动机等权平均。`metrics.json::val_engine_rmse` 是 **pooled**，禁用。
>
> **配对**：同方法、同子集、同 seed、同发动机的逐机差；四子集**等权**合并；95% CI 用
> 分层 bootstrap（子集内对发动机有放回，10,000 次，RNG `20261114`），点估计用观测值。
> 另报 Bonferroni 98.33% CI、方向一致计数、按机数加权敏感性。

#### 1.2.1 主张 R（重编码增量）

**范围与主比较（§5.1）：** 范围为 `aidgn` / `two_phase` / `ffve` / `fcstgnn` 四个方法；它们已吃
归一化 `age`，测的是**Fourier 重编码在已有 cycle 输入之上的增量**，不是「cycle 信息有没有用」。
主比较逐方法不同：`aidgn`、`two_phase`（有 sham 臂）为 **V1 − sham**；`ffve`、`fcstgnn`
（无 sham 臂）为 **V1 − V0**。

**单方法「通过」的定义（三个条件同时满足，缺一不算）：**

> 1. 该方法的合并点估计为负；
> 2. 该方法的 ≥3/4 子集点估计为负；
> 3. 该方法的合并 95% CI 不含 0。

**三档判定（互斥且穷尽，开跑前写死，不得按结果改）：**

> 记 `p` = 通过的方法数，`m` = 方向一致的方法数（该方法 ≥3/4 子集点估计为负）。
> 「通过」本身要求 ≥3/4 子集为负，所以恒有 `m ≥ p`。
>
> - **强结论**：`p ≥ 3`；
> - **弱结论**：`p < 3` 且 `m ≥ 3`；
> - **不成立**：`m < 3`。
>
> 「合并 CI 跨 0」只用于**描述未通过的方法**，不作档位条件。
> 「≥3/4 方法」是**逐方法过门槛的计数**，不是把四个 Δ 跨方法平均。

**「不成立」的后果（§5.1，预先写定）：** 主张 R 不成立，如实记录为负面结果；按预登记判据，
主线改为**协议审计、强基线与机制归因**，不得事后改判据或换口径重算。

**本节的结论：**

#### 1.2.2 主张 I（信息效应）

**判据原文（§5.2）：**

> 只在 `dual_mixer` 上单方法报告 **V1 − sham**（n = 1），不做跨方法合并。
