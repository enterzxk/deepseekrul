# S1-A 第二半：`aidgn` 注入尺度匹配敏感性（预登记，v1）

状态：**冻结件**。commit 之后不得修改；任何改动都必须另立 v2 并说明动机，不得覆盖本文。
上位判定：`research_decision` revision 93（L2，Codex，`branch`）——保留 96 格主分析与它的
机械评分，`aidgn` 在科学解读上标 CONTROL-COMPROMISED / UNRESOLVED，另立本敏感性。

## 1. 为什么要有这一份

主分析里 `aidgn` 的 V1−sham = −11.7130（95% CI [−12.8280, −10.5461]），按冻结规则是「通过」。
但逐格看训练曲线，12 个 sham 格里有 5 格训练损失几乎不降（`last/first` = 0.92、0.87、0.81、
0.75、0.50），验证 engine RMSE 36.9–49.1，而同格 V0 是 10.3–13.8——它们停在均值预测噪声底。
分解给出同样的结论：`sham−V0 = +12.8597`（CI [+11.8147, +13.8646]），`V1−V0 = +1.1467`，
所以那个 −11.71 全部来自 sham 臂的**损伤**，不是 V1 的改善。

实测注入项与头输入的逐样本范数比：`aidgn` 4.17（|h|=0.786 vs |inj|=3.277）、`fcstgnn` 3.15、
`ffve` 0.90、`dual_mixer` 0.46。`aidgn` 的头输入只有 0.79，注入项比它大四倍。V1 能活是因为
这一项携带真周期、头可以拿它做预测；sham 把它换成同分布排列值后，同一量级就是主导噪声。

**这个解释是事后的**，单批次测量不足以证明因果（`fcstgnn` 比值 3.15 却训练正常）。本敏感性
就是去检验它：如果失配是原因，把量级对上之后 sham 应该能训练，V1−sham 的大幅优势应该消失。

## 2. 假设与证伪

- **H-scale**：`aidgn` 的 sham 失效主要来自注入量级失配（注入 ≈ 4.2× 头输入），不是「无信息
  输入必然有害」。
- **预测**：尺度匹配后，(a) sham 格的可训练性恢复（DEAD 格数 < 3/12）；(b) `sham−V0` 的合并
  估计向 0 收缩；(c) `V1−sham` 的绝对值显著小于 11.71。
- **证伪**：若匹配后 sham 仍有 ≥3 格 DEAD，或 `sham−V0` 仍在 +10 量级，则量级不是充分解释，
  停止这条解释，不再调参重跑（见 §6）。

## 3. 干预：只改一条公共尺度规则

唯一改动是一个标量 α，**两臂使用同一个 α**：

1. 在网络构建、任何训练之前，取训练集**第一个 batch**（batch_size 同该方法配置，不洗牌、
   不做数据增强、不看验证集），以 `torch.no_grad()` 跑一次前向；
2. 用临时 forward pre-hook 记录该 head 输入的逐样本 L2 范数均值 `mean_h`；
3. 记录同一 batch 上 `pe_proj(pe(cycle))` 的逐样本 L2 范数均值 `mean_inj`；
4. `α = mean_h / mean_inj`，写进 `config.json`（`scale_mode: "matched"`、`scale_alpha`、
   `scale_mean_h`、`scale_mean_inj`、`scale_batch_size`），并作为 buffer 乘在 `pe_proj` 输出上。

不改变的东西：`pe_proj` 的初始化方式（仍是默认 `nn.Linear` 初始化）、注入位置（回归头
forward pre-hook）、`h ← h + α·pe_proj(pe)` 的相加形式、损失函数、优化器、学习率、轮数、
早停、选轮规则、种子、数据划分、五个方法的其它任何代码。

α 只用训练输入标定，**不使用验证集、不使用官方 TEST、不使用任何训练结果**。两臂 α 相同，
所以 V1−sham 仍是等容量、等尺度的对比。

## 4. 网格与预算

`aidgn` × {V1, sham} × {FD001, FD002, FD003, FD004} × {101, 202, 303} = **24 格**。
输出根目录独立（`cycle_runs_scale/`），不覆盖主分析任何格子。预计单卡 60–90 分钟。

## 5. 判据（事先写定）

- **可训练性**：某格 `train_loss` 末轮 / 首轮 > 0.8 判 `DEAD`（与主分析 §1.9 同一阈值）。
  DEAD 格**保留在数据里**并逐格列出，不剔除、不重跑。
- **主分析**：V1−sham，四子集等权，3 seed 先平均再合并，engine-level bootstrap 10000 次、
  RNG 20261114，报 95% CI 与 Bonferroni 98.33%；同时报 V1−V0 与 sham−V0。
- **实质收益**：合并 Δ ≤ −0.5 周期且 95% CI 上限 < 0 记为「有实质收益」；−0.5 < Δ < 0 且
  CI 跨 0 记为「无法区分」；Δ ≥ 0 记为「无收益」。0.5 周期取自单格约 0.25 周期的噪声底
  两倍，写在这里是为了防止事后挑阈值。
- **功效说明**：24 格只能回答「尺度是不是主要解释」，不能用来宣称 `aidgn` 上有无增量的
  最终结论。

## 6. 停止条件

- 若匹配后 sham 仍有 ≥3/12 格 `DEAD`：判「量级不是充分解释」，本敏感性到此为止，
  不再调整 α 目标、不再加尺度档位重跑；结论写进 `S1A2_PUBLIC.md`。
- 若 24 格全部终态且 `pgrep -f run_grid_cycle` 为 0：出一次性报告，不追加格子。
- 任何情况下不改主分析、不改 96 格、不把本敏感性的数写进主结果表。
