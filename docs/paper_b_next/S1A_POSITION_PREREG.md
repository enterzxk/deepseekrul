适用：`docs/paper_b_next/S1A_CYCLE_MATCHED.md` 前半部分；决策对象是四个 Cycle 注入位置里
选哪一个，供 S1-A 第二半的五个公开方法复用。

**冻结时已落地 5 格，全部是 FD001**（`S1A_head/FD001/s101,s303,s43,s42`、`S1A_none/FD001/s42`）。
本规则不参考这些数字，任何阈值都不来自已落地结果。

> 经理提的三条全部保留，只补四处歧义：①「合并」定义为四子集**等权**，不是按机数加权；
> ②「唯一胜出」需要**成对支配**，不只是各自优于 `none`；③选不出时除默认 `pre_norm` 外，

## 0. 一句话

跨四子集等权的 engine-level 配对差是主判据；只有「合并 95% CI 不含 0 + ≥3/4 子集同向 +
（若有多个合格者）成对支配」才算唯一胜出；选不出就用 `pre_norm` 默认值，文档写明
**「默认，不是证据」**，且第三阶段不停摆。

## 1. 决策对象与数据

- 位置：`none` / `pre_norm` / `post_norm` / `head_concat`。
- 规模：4 子集 × 4 位置 × 5 seed（101/202/303/42/43）= **80 格**。
- 验证机：FD001 20、FD002 52、FD003 20、FD004 50，共 142 台；每台 5 个固定截点
  `round(f·n)`，f = 0.40/0.55/0.70/0.85/0.95。不得换成随机截点。
- 指标：**engine-level val RMSE**——先逐机算 5 截点的 RMSE，再对机等权平均；
  从每格 `val_pred.csv` 重算。**禁用** `metrics.json::val_engine_rmse`（S1-C 已实测为 pooled）。
- 数据完整性：每格必须是 **best epoch** 的预测；`config.json` 的
  `cycle_pos / fp32 / subset / seed` 必须与路径一致，且 `fp32` 必须为 `true`。
  任一不符 → 该格作废、不插补、不参与判定。

---

## 2. 统计量（冻结）

- **逐机配对差**：`d_{p,s,k,e} = RMSE_{p,s,k,e} − RMSE_{none,s,k,e}`，同子集、同 seed、同机、同截点。
  同一 (subset, seed) 下四个位置看到的是同一批验证机，配对成立。
- **子集效应**：`Δ_{p,s}` = 先对 5 个 seed 平均，再对机等权平均。
- **合并效应**：`Δ_p` = 四个子集 `Δ_{p,s}` 的**等权平均**（不是按机数加权）。
  理由：机数 20/52/20/50 差 2.6 倍，按机加权会让 FD002/FD004 主导；等权与
  「不按单个子集宣称显著」和 A8 台账的既有做法一致。
- **95% CI**：分层 bootstrap——子集内对机有放回重采样（10,000 次），seed 先平均，
  四子集样本等权平均，取 2.5/97.5 分位；RNG 固定 `20261114`。点估计用观测值，
  不用 bootstrap 均值。
- **方向一致计数**：`n_neg(p) = #{s : Δ_{p,s} < 0}`（点估计为负即算，不要求子集 CI 显著）。
- **种子离散**：5 个 seed 级合并差（每个 seed 先对子集等权平均），报均值 ± sd；
  只作稳健性描述，**不进判定门**。

---

## 3. 选择规则（冻结，按顺序执行）

1. **合格集** `Q = {p : CI_p 上限 < 0 且 n_neg(p) ≥ 3}`。
2. `|Q| = 0` → **无胜出**。用 `pre_norm` 作实现默认值，文档写
   「位置未由证据识别，沿用默认」。若同时 `none` 对每个 Cycle 位置的合并 CI 上限 < 0
   （即 Cycle 显著更差），另记一条「DSPT 上 Cycle 为负效应」。
3. `|Q| = 1` → 该位置为**唯一胜出**。
4. `|Q| ≥ 2` → 取 `Δ_p` 最负者；它必须对 `Q` 中**每一个**其他位置都有
   「成对合并 CI 上限 < 0」。满足 → 唯一胜出；不满足 → **无唯一胜出**，
   用 `pre_norm`，文档写「多个位置优于 none，但彼此不可区分，沿用默认」。
5. 若两个位置 `Δ_p` 浮点完全相同，优先 `pre_norm`（只为确定性，不是科学理由）。

**`none` 不能「胜出」**——它是参照臂。若 `none` 最好，结论是「无 Cycle 位置通过」，
不是「none 是胜出位置」。

---

## 4. 报告要求（缺一不可）

- 4×4 绝对表：每格 engine-level RMSE 均值 ± seed sd、机数、seed 列表。
- 每个 Cycle 位置对 `none` 的合并差、95% CI、方向计数、5 个 seed 级差。
- **所有位置两两**的成对合并 CI（不只是胜出者）——防止只报有利比较。
- 参数量并排：总参数与**有效（可训练）参数**。任一相对 `none` 差 >1% →
  必须在表旁注明，且该位置不能仅凭 RMSE 胜出，需容量匹配对照（同宽头 + 零列）。
- **多重比较**：3 个位置各做一次对 `none` 的比较，未做校正；同时报
  **98.33% CI**（Bonferroni，α = 0.05/3）。若胜出者的 98.33% CI 跨 0，
  文档必须写「方向一致但未过校正门槛」，不得称「显著胜出」。
- **按机数加权**的合并差作敏感性单列；若与等权符号相反，必须写
  「结论对聚合权重不稳健」。

## 5. 边界与披露

- **TEST 绝不参与选择**。胜出位置必须在计算任何 TEST 数字**之前**冻结
  （以本文件 commit + 结果 JSON 的 `frozen_at` / `rule_version` 为准）。
  四个位置的 TEST 可在冻结后作描述性报告，不得据此改选。
- **`dual_mixer` 的妥协**：它用自己的对比损失，联合训练会改它的目标函数，
  所以只能冻结基座、只训头。这**不是**「架构无关插件」的完美实现，是已知实现妥协，
  必须写进 S1-A 边界说明，不得在正文里消失。
- **缺格**：任一位置在任一子集缺格或缺 seed → 该位置不具备 `Q` 资格，直到补齐；
  不得插补、不得用 4 seed 近似 5 seed。
- **已落地格子不得因结果不理想重跑**；失败、缺失、作废如实记录。
