## 1. 精度事实（必须先读）

仓库里保存的 `val_pred.csv` / `test_pred.csv` 是 **BF16 autocast** 下产生的。用同一批 checkpoint 重跑：

| 检查 | 结果 |
|---|---|
| FP32 两次独立运行 | max\|Δ\| = **0.0000**（可复现） |
| FP32 重跑 vs 已存 BF16 预测 | **12/12 个 run 都不同**，max\|Δ\| 0.31–1.12 个周期 |
| BF16 重跑 vs 已存 BF16 预测 | 8/12 逐位一致，其余差 0.0156–0.5 |
| j=0 单独成批 vs 已存文件（FP32 单批） | 逐位一致（说明差异来自精度与归约顺序，不是权重不匹配） |

结论：**BF16 autocast 跨进程不可逐位复现**，同一份权重重跑都会漂移，所以它不能作为冻结读出研究的基础。S1-B 全部改用 FP32（与当前协议一致），基准读数因此与历史文件不同，二者不混表。

## 2. 做了什么

对每个 (子集, seed)：

1. 重建冻结验证点：每台验证机 5 个截断点 `round(f·n)`，f = 0.40/0.55/0.70/0.85/0.95（`paper_b/configs/protocol.json`）。
2. 重建官方 TEST 末窗预测（每台机 1 个点）。
3. 额外重建 j = 1…9 的平移窗口：窗口结束点前移 j 个周期，其对参考时刻 RUL 的估计为 `pred_j − j`。

成员定义：

- 非多窗口变体：同一评价点上的 **3 个 seed** 的预测。
- 多窗口变体：3 个 seed × j ≤ J−1 的窗口，权重 `decay^j`；`pred ≥ 125` 的成员不参与（末窗始终保留）。

17 个变体：`mean` / `median` / `quantile q∈{0.5,0.4,0.3,0.2}` / `mean − k·sd, k∈{0.25,0.5,1.0,1.5}` / `nasa_bayes`（在 [0,125] 上网格搜索使 NASA 惩罚期望最小的点）/ 多窗口 `J∈{3,5,10} × decay∈{1.0,0.9}`。

## 5. S1-B 判据

判据：验证集选定的读出，在官方 TEST 上 NASA Score 相对均值读出下降 ≥10%，且 RMSE 变化不超过种子标准差。

| 条件 | 实测 | 命中 |
|---|---|---|
| NASA 相对下降 ≥ 10% | **−10.87%**（1773.5 → 1580.8） | **是**（10.87 ≥ 10） |
| RMSE 变化 ≤ 种子 sd | −0.2455，最大子集 seed sd 1.140 | **是** |

**按 RMSE 主导的选择规则，判据命中，读出声明保留为配套。**

## 6. 必须一起报的三条限制

**① 结论依赖选择规则，而且另一个合理读法会失败。** 规格写的是「用 engine-level RMSE 与 NASA Score 选出唯一配置」，两者没有给优先级。本节按 RMSE 主导选择。若改按验证集 NASA 主导，会选中 `nasa_bayes`（val NASA 13210.8 最低），它在 TEST 上 NASA 只降 **0.3%**（1773.5 → 1767.8），**判据不命中**。

**② 验证集 NASA 不能预测 TEST NASA。** `nasa_bayes` 是验证集 NASA 最优的变体，在 TEST 上却几乎没有改善；反之选中变体验证集 NASA 只排中游，TEST 反而最好。这正是「风险感知读出」这个说法需要小心的地方——真正按 NASA 代价设计的那个变体没有迁移过去。

**③ 10% 只超了 0.87 个百分点，且 FD001 变差。** 选中的本质是**时间平滑**（用前 5 个窗口加权平均、扣掉时间偏移），不是概率意义上的风险感知。它在 3/4 子集上改善 NASA，FD001 上 RMSE 和 NASA 都变差。
