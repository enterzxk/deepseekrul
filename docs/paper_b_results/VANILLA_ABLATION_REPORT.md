# Vanilla Transformer 重建实验（2026-11-11）

> 供外部评审。**取代此前的 DSPT-Backbone 消融。**
> 代码 SHA 见文末。所有数字可复算。

## 1. 为什么重建

**旧版 base 不是 Vanilla Transformer**，而是「把 DSPT 的模块关掉」：

| 维度 | 旧 DSPT-Backbone | 新 Vanilla BASE |
|---|---|---|
| 输入通道 | 3（raw / 基线偏差 / 因果 EMA） | **1（raw）** |
| 绝对 cycle 编码 | 有 | **无** |
| 位置编码 | 可学习距离表 | **固定正弦** |
| 池化 | Dual-Span Gate | **Masked Mean** |
| 卷积 | 单层 k=3 | **无** |
| 传感器池化 | 可学习 softmax | **无** |
| 死参数 | 33k | **0** |
| 参数量 | 115,716 | **72,257** |

## 2. 新 BASE 定义（严格 Vanilla）

```
Linear(14→64) → 固定正弦 PE
→ 2× TransformerEncoderLayer(d=64, 4 heads, FFN=128, GELU, norm_first, padding mask)
→ LayerNorm → Masked Mean Pooling
→ Linear(64→64) → GELU → Linear(64→1)
```

## 3. 三个可开关模块

| 模块 | 接入 | 参数量增量 |
|---|---|---:|
| **MS** | 残差分支：LayerNorm(h + proj(mean(conv_k(h), k=3,5,7))) | +5,440 |
| **SA** | 残差分支：逐传感器投影 → 跨传感器 Transformer → 聚合 | **+37,888** |
| **HI** | 仅训练损失（λ=0.5, μ=0.1），标签每折只用训练发动机拟合 | +65 |

## 6. 五个假设的答案

| 假设 | 结论 |
|---|---|
| **H1** MS 优于标准 Transformer | ✅ 大体是：FD001 −12.8%、FD003 −6.3%、FD002 −0.8%；仅 FD004 +0.9% |
| **H2** SA 有利于多工况 | ❌ 相反：FD002 −1.4%、FD004 +0.6%；单工况 FD001 −7.4%、FD003 −12.2% |
| **H3** HI 有独立收益 | ⚠️ 很弱：仅 FD004 −1.0% |
| **H4** MS 与 SA 正向交互 | ❌ 无稳定交互 |
| **H5** FULL 优于 MS+SA | ❌ 从未；FD004 上比 BASE 差 2.6% |

## 10. 一个未解决的疑点（正在排查）

**同一个 DSPT-Full 架构、同样 115,716 参数、同样 L=70/seed 101/fold 0，**
**修复前后测试集差 16%（10.91 vs 12.70），但验证集几乎相同（9.04 vs 9.15）。**

误差按真值分箱：

| y_true 区间 | n | 旧 RMSE | 新 RMSE | 变化 |
|---|---:|---:|---:|---:|
| 0–50 | 30 | 3.17 | 2.45 | −0.72 |
| 50–80 | 15 | 14.20 | 13.22 | −0.98 |
| 80–100 | 21 | 13.21 | **17.30** | **+4.09** |
| 100–125 | 23 | 13.19 | 12.74 | −0.46 |
| **125+** | 11 | **9.12** | **17.33** | **+8.21** |

**修复后的模型在高 RUL 区间严重欠预测**（y=125 时预测 81.5，误差 −43.5）。

**正在用「修复回滚消融」定位是 padding mask / RUL 端点 / HI 泄漏 中的哪一个造成的。**
