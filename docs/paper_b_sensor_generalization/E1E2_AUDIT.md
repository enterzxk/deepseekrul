## 5. 判定

按 §7.1（含 2026-11-16 对 ENGINEERING-ONLY 前件的澄清，只改标签不改阈值）与 §7.2：

- **E1a**：唯一同时通过全部统计判据与护栏的臂。clean −0.545（CI 不含 0、4/4、去 FD001 仍 −0.512），
  seed 级 sd 0.040（效应是它的 13.6 倍），噪声压力三个 β 全 4/4，NASA 0.899。→ **ENGINEERING-ONLY，确认候选**。
- **E1b**：clean 点估计最大（−0.689），但 **NASA 1.141 触发 §7.2**，不得进入候选。→ **ENGINEERING-ONLY（RMSE），但不作候选**。
- **E2a**：clean −0.301 勉强，去 FD001 后 CI 跨 0（[−0.611, +0.015]）；噪声压力 β=0.25/0.5 稳定。→ **ENGINEERING-ONLY（弱）**。
- **E2b**：clean CI 跨 0（[−0.456, +0.118]），噪声压力 β=0.25/0.5/1.0 稳定。→ **ENGINEERING-ONLY（clean 不显著）**。

注：澄清后的 ENGINEERING-ONLY 前件没有效应量下限，四臂字面上都能进这一档；但证据强度差别很大
（seed sd 0.040 vs 0.326，去 FD001 后 CI 是否跨 0）。报告应按强度排序，不要因为「都过了」就写成四臂等效。

## 6. 与旧 study 的方向翻转

旧 study：mask 在 clean 上变差（G1 −0.14%、G2 −0.39%）；本轮两臂在 clean 上都显著变好。
四个差异来源并列：`fp32`（旧 BF16）、`split_seed`（7 → 17）、子集数（2 → 4）、指标口径
（pooled/engine-equal → mean-of-roots）。口径贡献已量化：同一批预测换聚合，E1a 合并 Δ 从 −0.545 变 −0.432，
差 **0.11 周期**，**只改幅度、不改符号**，不足解释翻转。

## 7. 边界

- 只报验证集，未打开官方 TEST；TEST 不参与任何选择。
- 统计单位为发动机，滑动窗口不当作独立样本。
- 噪声压力的 5 个噪声场共用一组固定随机数；场间不独立，故只作稳定性参考，不单独报显著性。
- `val_engine_equal_rmse` / `rmse` / `val_pooled_rmse` 与 pooled 恒等，仅作辅助。
