## 4. §7.2 护栏：两种实现给出相反结论（**以比值-均值-比为准**）

`val_engine_equal_nasa_mean` 的 arm/E0 比值，两种算法：

| 臂 | 比值之比（先聚合再比） | 逐格比值再平均 | 最大单格 |
|---|---:|---:|---:|
| E1a | **0.881** | 0.899 | 1.142 |
| E1b | **0.979** | 1.141 | **3.292** |
| E2a | 0.941 | 1.002 | 1.607 |
| E2b | 0.941 | 0.990 | 1.186 |

§7.2 的原文是「NASA mean 比值 > 1.10」，指 `val_engine_equal_nasa_mean` 这个量的比值，
因此应**先聚合、再相除**。按此实现，**四臂都不触发护栏**（最高 E1b 0.979）。
按「逐格比值再平均」则 E1b 得 1.141 会触发——但那个数被**一格的分母**主导：
E0 自己在 FD004/s303 的 NASA 是 **4.00**，而它的兄弟 seed 是 17.4 / 33.9（差 4~8 倍），
逐格比值 3.292 主要是除到了一个异常好的基线，不是臂本身异常坏。

绝对值可以印证：E1b 在 FD004 的 NASA 均值 20.82 对 E0 18.43（**+13.0%**，真实的温和恶化）；
而 E1b 那一格的绝对值 13.17 反而**好于** E0 三个 seed 的均值 18.43。

结论：**§7.2 未被任何一臂触发**。E1b 在 FD004 子集上的比值 1.130 略高于 1.10，
但由单个 seed 驱动（三个 seed 为 1.19 / 0.84 / 3.29），只作敏感性说明，不作排除依据。
E1b 的 seed 级 sd 0.215（E1a 的 5 倍）**只作稳定性描述**：它不是预注册判据，
不得用来增减候选（见 §5 的最终候选集与 `SENSOR_RESEARCH_PLAN.md` 08:15 条）。

## 5. 判定

按 §7.1（含 2026-11-16 对 ENGINEERING-ONLY 前件的澄清，只改标签不改阈值）与 §7.2：

- **E1b**：clean 点估计最大（−0.689，CI [−1.003, −0.372]，4/4，去 FD001 −0.623），NASA 聚合比值 0.979
  **不触发护栏**。seed 级 sd 0.215、三个 seed 均值 −0.789 / −0.443 / −0.836（跨度 0.39）——作稳定性描述写进报告，
  不作筛选门槛。→ **ENGINEERING-ONLY，确认候选（效应量第一）**。
- **E1a**：clean −0.545（CI 不含 0、4/4，去 FD001 仍 −0.512），seed 级 sd 0.040（效应是它的 13.6 倍），
  噪声压力三个 β 全 4/4，NASA 0.881。→ **ENGINEERING-ONLY，确认候选（效应量第二，稳定性最好）**。
- **E2a**：clean −0.301（CI [−0.543, −0.037] 不含 0、4/4），字面过 §7.1 三条；去 FD001 后 CI 跨 0
  （[−0.611, +0.015]）作敏感性披露。→ **ENGINEERING-ONLY，确认候选（效应量第三）**。
- **E2b**：clean −0.173，CI [−0.456, +0.118] **跨 0**、且未过 −0.3。→ **无增益，不进确认集**。

**确认集最终候选 = E1b + E1a + E2a（三臂，按效应量排序）。**

候选筛选只认三条预注册统计判据（CI 不含 0、≥3/4 子集同号、合并 ΔRMSE ≤ −0.3）加 §7.2 护栏。
本轮有两次**事后**尝试用别的理由裁人，都已撤回，性质相同：① 用 seed sd 0.215 排除 E1b；
② 用「−0.301 紧贴阈值、去 FD001 后 CI 跨 0」排除 E2a。两者都不是预注册门槛。
seed sd 与去 FD001 值仍必须逐臂报出，但它们只影响**强度排序与措辞**，不影响入选。

注：澄清后的 ENGINEERING-ONLY 前件没有效应量下限，四臂字面上都能进这一档；但证据强度差别很大
（seed sd 0.040 vs 0.326，去 FD001 后 CI 是否跨 0）。报告应按强度排序，不要因为「都过了」就写成四臂等效。

## 6. 与旧 study 的方向翻转

旧 study：mask 在 clean 上变差（G1 −0.14%、G2 −0.39%）；本轮两臂在 clean 上都显著变好。
四个差异来源并列：`fp32`（旧 BF16）、`split_seed`（7 → 17）、子集数（2 → 4）、指标口径
（pooled/engine-equal → mean-of-roots）。口径贡献已量化：同一批预测换聚合，E1a 合并 Δ 从 −0.545 变 −0.432，
差 **0.11 周期**，**只改幅度、不改符号**，不足解释翻转。

## 7. 边界

- 只报验证集，未打开官方 TEST；TEST 不参与任何选择。
- 统计单位为发动机，滑动窗口不当作独立样本。
- 噪声压力的 5 个噪声场共用一组固定随机数；场间不独立，故只作稳定性参考，不单独报显著性。
- `val_engine_equal_rmse` / `rmse` / `val_pooled_rmse` 与 pooled 恒等，仅作辅助。
