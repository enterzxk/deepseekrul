## 1. 读数约定

- 主指标 `val_engine_mean_roots_rmse`（逐发动机 RMSE 再平均）。
- **ΔRMSE 是「本臂 − `none` 臂」**，所以**正数 = 比基线差**。这一点容易看反。
- 配对基线是 E5 内部的 `none` 臂（同 h8、同 seed、同划分），不是 E0。
- CI：10000 次配对 bootstrap，种子 `20261116`，重采样单位是**发动机**，
  先按子集平均三个 seed、再在发动机上重采样。每个区间由
  (数据, 种子, 统计量) 唯一确定（见 `SENSOR_RESULTS_README.md` §4）。

## 3. 能主张什么、不能主张什么

**能主张（CI 不含 0 的那一条）**：在 `none` 基线上加 rank-4 低秩交互支路，
合并 ΔRMSE **+0.67 周期**（95% CI 全在 0 以上，4/4 子集同号为正），
去掉 FD001 后仍是 +0.56 且 CI 不含 0。**这是显著变差，不是「没效果」。**

**不能主张**：

1. **不能**说「低秩结构本身有害」——`lr4 − mlp` 的 CI 跨 0（[−0.0335, +1.0063]），
   所以「+0.67 是低秩带来的」这句话没有证据。它只能写成「这个 124028 参数的
   低秩支路整体有害」，害处里有多少来自低秩结构、多少来自等容量的额外支路，未分离。
2. **不能**说 full-rank 有增益：`lr14` CI `[−0.4023, +0.3405]` 跨 0，2/4 同号。
3. **不能**说等参 MLP 是「无害对照」：`mlp` 同样跨 0（2/4）。
4. **不能**把低秩因子解释成真实健康指标（预注册已禁，且本轮无任何逐因子证据支持）。

## 4. 与 E0 的关系（可写进论文的一句）

`none` 臂 12/12 逐位复现 E0（`==` 精确相等，`scripts/audit_e5_none.py`），
所以 **E5 的 `none` 就是 E0 那个模型**，四臂之间的差只能归因到 `lr_mode`，
不掺「换了 h8」这个变量。见 `FAIR_COMPARISON_AUDIT.md` §12。

## 5. H1–H4：N/A，不是「不成立」

`E5_PREREG.md` §4 的顺序门**在步骤 0 就截断了**：第一条要求 `lr4` 对 `none` 的四子集等权
ΔRMSE ≤ −0.3 且 CI 不含 0。实测 **+0.6714 [+0.2401, +1.1129]**，条件不成立，预注册规定
此时**不再问 H1–H4**。

所以 **H1–H4 全部标 N/A（未判定），不是「不成立」**。这两句话在论文里不同：
「不成立」是测了没通过；「N/A」是预注册规定在这种效应下不进入判定，所以既不能说它被证伪，
也不能说它被支持。按 §4「没有效应就没有可解释的东西」，机制谱那一轮已停
（脚本在仓库里，随时可重跑作描述性材料，但不再有判定权）。

臂级证据能支持的是一条关于**臂**的事实陈述，不是关于假设的判定：在 `none` 基线上加
rank-4 低秩交互支路，合并 ΔRMSE +0.67 周期、CI 全在 0 以上、4/4 子集同号为正——
**这个支路整体有害**。但秩约束与容量未分离（`lr4 − mlp` 跨 0），
所以不能升级成「低秩结构有害」。

### 5.1 支路活性（§9.6 报告义务，36 格）

三臂 × 12 格全部 `AWAKE`，`rel = ‖lr(H)−H‖/‖H‖` 在 **0.251–1.608**，阈值 `1e-6`，
`awake 36, dormant 0`。**没有一格是「支路根本没醒」**——所以这个负结果不是
「模块没接上」「梯度断了」或「零初始化没长出来」，而是**接上了、醒了、且有害**。
这一条对负结果的性质是决定性的：它排除了「实现失败」，于是负结果只剩一种解释——
**这条结构路线在效应层不成立**。注意这是对**路线**的判断，不是对 H1–H4 的判定：
H1–H4 仍是 N/A，因为它们按预注册根本没进入判定。

三臂 `rel` 均值排序 `lr4 0.868 > mlp 0.608 > lr14 0.473` 与 ΔRMSE 排序
`+0.671 > +0.184 > −0.035` 一致。**只有 3 个点，只能作假设、不能作结论**——
三个点的一致既可能是机制，也可能是容量或正则的伴随效应，本设计分不开。
