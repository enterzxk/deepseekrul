> **状态：FROZEN 2026-11-16。** 冻结后本文件只允许追加「是否满足」的实测结果，不得改动任何阈值、判据、臂定义或统计口径。
> 冻结前草案 v0.1 的三处待定（H1 阈值、`mlp` 等参定义、`G` 结构与 λ 初始化）已在 §7 逐条结清并留证。

## 1. 机制定义（已写死，不留实现自由度）

原 DSPT 时间编码器输出 `H: [B, T, 14, D]`（即 `dspt.py` 中 `sensor_score` 的输入张量，`D=64`）。

```
U       = qr(W_u)[0] * sign(diag(qr(W_u)[1]))   # 14×r，每次前向现算，W_u 是 raw 参数
F       = einsum('nr,btnd->btrd', U, H)          # [B,T,r,D]
G(F)    = g(F)                                   # 逐因子共享同一个 g，作用在 D 轴上
ΔH      = einsum('nr,btrd->btnd', U, G(F))       # [B,T,14,D]
H_new   = H + λ · ΔH                             # λ 可学习标量，初值 1e-2
```

**`g` 的结构（写死）**：`Linear(64→64)` → `GELU` → `Dropout(0.2)` → `Linear(64→64)`，**最后一层零初始化**。
零初始化使 `ΔH ≡ 0` 于第 0 步，支路从恒等开始，只作为扰动加进去——这同时消除了「早期大扰动把训练带偏」这个混杂。

**`U` 的初始化**：`qr(randn(14, r))` 取正交列。前向每次现算正交化并对 `diag(R)` 取符号，保证 `U` 的列方向可复现（H3 比较子空间时需要）。

**参数（`D=64`，`w=64`）**：`g` = 64·64+64 + 64·64+64 = **8320**。

| 臂 | 支路构成 | 参数量 | 相对 `lr4` |
|---|---|---:|---:|
| `lr4` | `U(14×4)=56` + `g`=8320 + `λ`=1 | **8377** | — |
| `lr14` | `U(14×14)=196` + `g`=8320 + `λ`=1 | **8517** | **+1.67%** |
| `mlp` | 同一个 `g` 结构直接作用于每个传感器通道（无低秩瓶颈、无跨传感器混合）+ `λ`=1 | **8321** | **−0.67%** |
| `none` | 无支路，`H_new = H` | 0 | — |

三臂支路参数量两两相差 ≤2%，**`g` 宽度固定为 64 使参数量与 `r` 无关**，因此 `lr4` vs `lr14` 是干净的秩比较，不掺容量。

**两个对照各自能分离什么（必须写在结果里，不能混为一谈）**：

- `lr14` 控**秩**：与 `lr4` 只差 `U` 的宽度，用于判断「低秩约束」是否有实际作用；
- `mlp` 控**容量**：参数匹配但完全没有跨传感器混合，用于判断增益是否只是「多了一个逐通道非线性」。
- 两者都不是对方的替代：`mlp` 不能证明「低秩结构」有效（它连混合都没有），`lr14` 不能证明「不是容量」（它容量更高）。H2 的判据只认 `mlp`。

低秩因子**不得**声称为真实健康指标。

## 2. 实验臂（四臂，4 子集 × 3 seed = 48 格）

| 臂 | 定义 | 作用 |
|---|---|---|
| `lr4` | 上式，r=4 | 主候选 |
| `lr14` | r=14（满秩），其余相同 | 判断「低秩」是否比「任意线性混合」更好 |
| `mlp` | 等参数量逐传感器 MLP（§1 表） | 判断增益是否只是容量 |
| `none` | 去掉低秩支路（`H_new = H`） | **E5 内部基线** |

**代码身份**：E5 必然改 `paper_b/models/dspt.py`，因此 **h8 会变**，与 E0–E2 的 `515eb76fc396` 不再是同一身份。规则：

- 四臂共用**同一个新 h8**，`none` 臂必须在同一新 h8 下重训，**不复用阶段 1 的 E0**；
- E5 的一切比较都是 within-E5 配对（`lr4/lr14/mlp` vs `none`，同 subset/seed）；
- 阶段 1 的 E0 只用于跨阶段的量级参照，不得当作 E5 的配对基线。

**协议**：split_seed=17、seeds 101/202/303、FP32、span=70、其余超参与 E0 完全一致；主指标 `val_engine_mean_roots_rmse`。

## 3. 四条假设（判据已冻结）

每条都给「怎么量、什么算成立、什么算不成立」。所有中间量（`U`、`G(F)` 输出、谱）必须落盘为 `.npz`，否则不可复核。

### H1 低秩谱结构

**问题**：`U` 张成的 r=4 子空间是否真的承载了 H 的主要方差，而不是一个任意 4 维切片？

**测量**：在验证集上抓 `sensor_score` 的输入张量 `H`（形状 `[B,T,14,D]`），按下式算协方差：

```
对每个特征维 d：C_d = 全部 (b,t) 上 14 维向量的协方差
Ĉ = (1/D) Σ_d C_d                      # 14×14
特征值 λ₁ ≥ … ≥ λ₁₄
ρ = trace(Uᵀ Ĉ U) / Σ_i λ_i            # U 为学习到的 r=4 基
```

零分布：随机正交 4 维子空间 1000 次，取 ρ 的 95 分位 `ρ_null`。

**成立**：`ρ ≥ 0.60` **且** `ρ > ρ_null`（95%）。
**不成立**：`ρ < 0.60`，或 `ρ` 落在零分布内。

**阈值 0.60 的实测依据**（冻结前在 E0 的 s101 上只读测过，见 §7.1）：

| 子集 | 最优 rank-4 可达 ρ | 随机零分布 95 分位 |
|---|---:|---:|
| FD001 | 0.8265 | 0.4155 |
| FD002 | 0.7872 | 0.4129 |
| FD003 | 0.8822 | 0.4294 |
| FD004 | 0.8834 | 0.4328 |

即：H 的传感器维本身强低秩（最优 rank-4 拿到 79–88%），而随机 4 维子空间只有 41–43%。`0.60` 落在两者之间，对应「达到可达上限的 70–76%」，既有意义又不会被低秩性自动满足。**该阈值在实测之后没有调整**——实测只是确认它不是随手写的。

**附加**：若 `lr14` 的谱与 `lr4` 的谱在 5–14 号特征值上无差别（差异小于 seed 间 sd），H1 也判不成立——那说明「低秩」这个约束没有实际作用。

### H2 非容量效应

**问题**：`lr4` 的收益是不是只来自多出来的参数？

**测量**：`mlp` 臂参数量与 `lr4` 支路匹配（8321 vs 8377，**−0.67%**），同预算训练；配对 ΔRMSE（vs `none`）。

**成立**：`lr4` 的 ΔRMSE 95% CI 不含 0，**且** `mlp` 的 ΔRMSE CI 含 0，**且** `mlp` 复现的收益 < `lr4` 的 50%。
**不成立**：`mlp` 拿到 ≥50% 的收益（→ 是容量，不是低秩），或 `mlp` 与 `lr4` 的 CI 重叠且点估计接近。

### H3 基跨 seed 稳定

**问题**：三个 seed 学到的 `U` 是不是同一个子空间？如果不是，「因子」就不能当结构解释。

**测量**：对每对 seed 的 `U`（14×4，正交列）算**最大主角度** `θ_max`（4 个主角度的最大值）。零分布：随机 4 维子空间对 1000 次。

**成立**：三对 seed 的 `θ_max` 全部 **< 30°**，且显著低于随机零分布（5% 分位）。
**不成立**：任一对 `θ_max ≥ 30°`，或与随机零分布不可区分。

### H4 工况条件刻画

**问题**：`G(F)` 的输出是否与工况（cluster）有可测对应，从而能说它「刻画了条件」？

**测量**：仅 **FD002 / FD004**（多工况；FD001/FD003 单工况，H4 不可测，标 N/A）。把 `G(F)` 在时间维池化，用**按发动机分组**的交叉验证训练线性分类器预测工况簇（n_cond=6），报 balanced accuracy；零分布：打乱工况标签 1000 次。

**成立**：balanced accuracy **≥ 0.50**（chance = 1/6 ≈ 0.167），且高于打乱零分布的 95% 分位。
**不成立**：接近 chance 或落在零分布内——那就不能说它刻画了工况，只能说是一个普通线性混合。

## 4. 判定顺序与结论档位

先看**效应**，再看**机制**——没有效应就没有可解释的东西：

| 步骤 | 条件 | 结论 |
|---|---|---|
| 0 | `lr4` vs `none`：四子集等权 ΔRMSE > −0.3 cycle，或 CI 含 0 | **无增益**：E5 停在「无效应」，不再问 H1–H4；按 §7.1 判无增益 |
| 1 | 有增益，H1 不成立 | 低秩谱不成立：收益不能用「低秩结构」解释 |
| 2 | H1 成立、H2 不成立 | **容量效应**：不是低秩，撤回机制表述 |
| 3 | H1/H2 成立、H3 不成立 | 因子不稳定：不能当结构解释，只能报「有增益但不可解释」 |
| 4 | H1–H3 成立、H4 不成立 | 不能说「刻画工况」；机制表述降为「无条件线性低秩混合」 |
| 5 | H1–H4 全成立 | 机制成立，但**档位仍是 ENGINEERING-ONLY**（新颖性已判不足） |

**无论哪种结果，都不允许**：事后改阈值、换 seed、只报通过的子集、把 H4 的 N/A 当成立。

## 5. 统计口径

- 主指标 `val_engine_mean_roots_rmse`（`mean_u RMSE_u`）；pooled/engine-equal 只作辅助。
- 配对：同 `(subset, seed)`；发动机级 bootstrap ≥10000 次（重采样发动机 ID，保留该机全部截点）。
- 跨子集：四子集等权合并，报合并 CI 与方向计数（≥3/4 同号为方向一致的辅助证据）。
- 不按单个子集宣称显著。
- 每格必须 `status=COMPLETE` 且八件产物齐全，并过 mtime 顺序检查（见 `FAIR_COMPARISON_AUDIT.md` §10.2）。

## 7. 冻结前待定项的结清记录

### 7.1 H1 的 `ρ ≥ 0.60` —— 保留，并补上实测依据

冻结前用 E0 的 s101 跑了一次**只读**谱统计（`scripts/probe_spectrum.py`，hook `sensor_score` 抓 `(B,L,N,D)`，不改模型、不改 h8）：

```
FD001 s101: rho_r4=0.8265 (null95=0.4155)
FD002 s101: rho_r4=0.7872 (null95=0.4129)
FD003 s101: rho_r4=0.8822 (null95=0.4294)
FD004 s101: rho_r4=0.8834 (null95=0.4328)
```

结论：`0.60` 落在「可达上限 0.79–0.88」与「随机 0.41–0.43」之间，**阈值不改**。
协方差定义已写进 §3 H1，避免「谱」这个词在实现时被自由解释。

### 7.2 `mlp` 的等参数量定义 —— 写死

`mlp` 臂用**与 `g` 完全相同的模块结构**（`64→64→64`，GELU、Dropout 0.2、末层零初始化）直接作用于每个传感器通道，即 `ΔH[:,:,:,s] = m(H[:,:,:,s])`，再做 `H_new = H + λ·ΔH`。

参数量 8321 对 `lr4` 的 8377（−0.67%），对 `lr14` 的 8517（−2.3%），全部在 ±2% 以内（对 `lr4` 的口径）。
**不含 `U`**：`mlp` 臂没有 `U`，这正是它与低秩臂的差别所在，不是遗漏。

### 7.3 `G` 的结构与 λ 初始化 —— 写死

`g` = `Linear(64→64)` → `GELU` → `Dropout(0.2)` → `Linear(64→64)`，**末层零初始化**；`λ` 为可学习标量，初值 `1e-2`。
`g` **逐因子共享**（同一个模块作用于 r 个因子），这是让参数量与 `r` 无关、从而让 `lr4` vs `lr14` 成为干净秩比较的关键设计，不得改成每个因子一个独立 `g`。
