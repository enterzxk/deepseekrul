## 1. 出发点（数字全部来自 `HEADROOM_DIAGNOSTIC.md`）

1. **误差是尾部，不是均值。** 20% 的发动机承担 75.3 / 86.7 / 80.9 / 87.4% 的平方误差
   （FD001–FD004）；把 top-20% 误差减半，RMSE 从 10.000 / 10.371 / 9.603 / 11.688 降到
   6.600 / 6.132 / 6.024 / 6.857；而**只修全局偏差**几乎不动（10.000 → 9.956）。
2. **尾部跨 seed 稳定。** 最差三台的误差 30–70 周期，seed 间 sd 只有 1.0–8.3——是系统性失败，
   不是噪声。这条决定了「可建模」。
3. **错在中段，且两端偏差符号相反。** 真实 RUL 75–100 桶：130 台、MAE **12.50**、偏差 **+5.94**、
   晚预测 **65%**；而 25–50 桶：84 台、MAE 4.21、偏差 **−2.38**、晚预测 27%。
4. **NASA 罚分同样在尾部**：top-10% 机器占 60 / 75 / 71 / 81%。

**这三条合起来给出的目标**：把「中段 + 离群机」的尾部误差压下去，而**不是**再追一次「平均降 0.2」
——后者落在 seed sd 0.2–0.9 的噪声里，本轮已经证明做不出来。

## 2. P0 前置门槛：现象必须在验证集上复现

**这是本文最重要的一条，放在所有设计之前。**

`HEADROOM_DIAGNOSTIC.md` 用的是 **TEST 逐机预测**（split 29 的 E0，5 seed）。按本轮约定，
TEST 只能用来**定位问题**、不能用来做设计选择。而「针对 TEST 上观察到的现象设计模块」正是
最危险的那种用法。

因此，**在训练任何模块之前，必须在验证集上复现同一现象**：

| 复现项 | 判据 |
|---|---|
| top-20% 机器占平方误差 | 四子集均 **≥ 60%**（TEST 为 75–87%） |
| RUL 75–100 桶偏差 | **为正**，且四子集合并后 **≥ +2.0 周期** |
| 尾部跨 seed 稳定 | 最差 10 台的 seed 间 sd 中位数 **< 误差中位数的 1/3** |

**复现失败即停止**：那说明尾部结构是 TEST 独有的（划分特性或标签特性），拿它设计模块就是
在拟合 TEST。停止后不追加诊断，直接记录为负结果。

**数据来源**：验证集 `validation_predictions.csv`（split 17 与 29，E0，5 seed）。零训练。

## 3. 三个必须先回答的问题

### 3.1 Q1：分段校准 vs「可靠性头」，哪个更可测？

**先给定义**（否则「校准」和「头」会被混着说）：

- **分段校准（A 类，输出后处理）**：在预测值上叠一个**按预测区间分段的仿射修正**
  `ŷ' = a_k·ŷ + b_k`（k 为 ŷ 的分段），参数 3–6 个，用**验证集发动机做交叉拟合**（out-of-fold）
  估计。推理时保留、有参数、但不看传感器特征。
- **可靠性头（B 类，结构）**：在网络里加一个**辅助输出头**，从传感器特征预测「这台机我不熟」
  的可靠性分数，用它缩放预测或放大区间。有参数、进网络图、**看特征**。

**结论：A 类显著更可测，但它只能当「必须超过的基线」，不能当贡献。**

| 维度 | A 分段校准 | B 可靠性头 |
|---|---|---|
| 能否零成本预检 | **能**（现有验证预测即可交叉拟合） | 不能，必须训练 |
| 自由参数 | 3–6 个 | 与隐藏维同阶 |
| 失效模式是否可见 | **是**（直接看 25–50 段是否恶化） | 否（要训完才知道） |
| 能否写成「模块贡献」 | **不能**——它是校准程序，不是架构 | 能（但必须超过 A） |

**所以顺序是**：先用 A 当探针，**量出「尾部到底有多少是输出可校准的」**；再决定 B 值不值得做。
如果 A 就能拿到大部分空间，B 必须**超过 A** 才算数——这和「必须超过训练期增强」是同一个逻辑。

### 3.2 Q2：怎么保证不把 RUL 25–50 那端的 −2.38 早预测放大？

**风险的确切形式**：诊断显示两端偏差符号相反（75–100 是 +5.94，25–50 是 −2.38）。任何**全局
单调压缩**（例如统一把预测往下压、或统一往上抬）都会修好一端、弄坏另一端。

**三条防护，从强到弱**：

1. **先量「可分离性」，再谈校准。** 如果 25–50 桶与 75–100 桶的**预测值 ŷ 分布高度重叠**，
   那么任何只依据 ŷ 的修正**在原理上无法**分开这两段——这时 A 类路线直接判死，不必浪费实验。
   这是一个**零成本、可判死**的检验（§4-P2）。
2. **修正必须条件化且带符号约束。** 只允许在偏差为正的区间向上修正，在偏差为负的区间保持恒等
   （或仅允许小幅）。**禁止**任何单调全局映射。
3. **预注册非劣护栏（硬判据）**：
   - 25–50 段 MAE 恶化 **≤ +0.5 周期**；
   - 0–25 段（临近失效，安全相关）MAE 恶化 **≤ +0.3 周期**。
   两条任一违反 → 方案否决，**不看主指标多好**。护栏必须在跑之前冻结。

### 3.3 Q3：用什么对照证明「超过只做训练期增强」？

**核心难点**：训练期增强（E1a）本身就有增益，而且它**零参数、零推理开销**。如果模块只是把
同一个效果换个壳，审稿人一句「同样的效果、更差的工程」就否掉。

**对照必须五臂，且全部在同一代码树上重训**（不同指纹之间不能配对，见 §10.3 的教训）：

| 臂 | 内容 | 作用 |
|---|---|---|
| **A** | 无增强、无模块 | 基线 |
| **B** | 仅训练期增强（E1a 配方：mask p=0.10） | **主对照**（必须超过它） |
| **C** | 仅模块、无增强 | 分离模块自身效应 |
| **D** | 增强 + 模块 | **主比较：D vs B** |
| **E** | 参数匹配对照（同参数量、无尾部机制） | 排除「只是加参数」 |

**三条主张各自需要什么证据**：

- 「模块有独立增益」= **D vs B** 达标（这是主判据）。
- 「增益不是来自额外参数」= **D vs E** 必须达标；否则只能说「多给参数有用」。
- 「机制方向一致」= **C vs A** 同号（辅助证据，不作主判据）。

**若 §4-P3 的校准探针通过**，再加第 6 臂 **F：仅分段校准**——模块还必须**超过 F**，
否则「用更复杂的东西做同样的事」同样不成立。

## 4. 四项零成本预检（跑任何训练之前，全部用现有预测）

| 编号 | 预检 | 输入 | 产出 | 判死条件 |
|---|---|---|---|---|
| **P0** | 验证集复现尾部现象 | 验证预测（split 17/29，E0） | 三项指标（§2） | 任一项不达 → **停止** |
| **P1** | 尾部误差的 seed 稳定性 | 同上 | 最差 10 台的 sd/误差比 | 比值 ≥ 1/3 → 尾部是噪声，**停止** |
| **P2** | 两段在 ŷ 空间的可分离性 | 同上 | 25–50 与 75–100 桶的 ŷ 重叠度 | 重叠严重 → **A 类路线判死**，只剩 B 类 |
| **P3** | 交叉拟合分段校准探针 | 同上 | ΔP90、ΔRMSE、25–50 段 ΔMAE | 见 §5 |
| **P4** | P90 的 seed 波动（定门槛用） | 同上 | E0 的 P90 逐 seed 值 | 用于把 §7 的门槛写成绝对值 |

**P2 的具体判法**（避免含糊）：对 25–50 与 75–100 两个桶，计算 ŷ 的分布；若 75–100 桶的 ŷ
中位数**落在** 25–50 桶的 ŷ 四分位区间内，即判「不可分离」——因为此时「ŷ 偏大 ⇒ 该往上修」
这条规则会把 25–50 的机器也一起往上推。

## 5. 决策门（预检结果 → 走哪条路）

```
P0 不通过 ─────────────────────────────► STOP（记负结果，不设计模块）
P0 通过 → P2 不可分离 ─────────────────► A 类判死；只允许 B 类（可靠性头），且风险登记为「高」
```

**P3「达标」的定义（冻结）**：合并 ΔP90 **≤ −0.5 周期**（负 = 更好），且 25–50 段 MAE 恶化
**≤ +0.5**。两条同时满足才算达标。

## 7. 预注册草案（执行前可改，改后冻结）

### 7.1 主指标（双主，AND）

1. **尾部指标 P90**：逐机绝对误差的 90 分位（**先按 seed 平均逐机误差，再在发动机上取分位**），
   先逐子集算、再四子集等权平均。**合并 ΔP90 ≤ −0.5 周期**（负 = 更好），95% CI 不含 0，
   **≥3/4 子集同号**。
2. **RMSE（engine-level）非劣**：合并 ΔRMSE **≤ 0**（不允许为 P90 牺牲 RMSE），且报 95% CI。

**为什么双主**：只报 RMSE 会被均值掩盖（诊断已证明），只报 P90 则可能靠「压缩极端预测」取巧。
两个都要过，才说明尾部真被改善而不是被摊平。

### 7.2 护栏（任一违反即否决，不看主指标）

- 25–50 段 MAE 恶化 ≤ **+0.5**；
- 0–25 段 MAE 恶化 ≤ **+0.3**；
- NASA 总和（逐台）不得恶化超过 **+5%**（仅报告口径，不作选择依据）。

### 7.3 对照与统计

- 五臂（A–E，必要时加 F），**同树重训**，每臂 **5 seed（42–46）**。
- 发现：`split_seed=17`，3 seed（101/202/303）先筛；确认：`split_seed=29`，5 seed。
- **确认集不得用于任何结构或超参选择**；确认集只跑已冻结的配置。
- 统计：发动机级 bootstrap 10000 次，**每个统计量独立 rng**；先按 seed 平均再重采样；
  报点估计、95% CI、逐子集值、seed 间方向一致计数。

### 7.4 判据（全部满足才算「模块成立」）

1. D vs B：ΔP90 与 ΔRMSE 双主指标达标；
2. D vs E：ΔP90 达标（排除「只是加参数」）；
3. 两条护栏不违反；
4. 确认集上复现（同 1–3）。

**任一不满足 → 模块不成立**，按「失败机制 → 修正假设 / 放弃」处理，不追加低价值诊断。

### 7.5 关于 split 29 的既有使用（必须披露）

`split_seed=29` 已被**传感器增强**那一轮用作确认集（判定 E1a/E1b/E2a）。它**没有**被用来选择
本模块的结构或超参，所以复用它在程序上成立；但严格说它不是「从未见过任何判定」的划分。

**建议**：若预算允许，最终论文数字用**全新划分**（如 `split_seed=43`）重跑 A/B/D 三臂作为
最终确认；预算不允许则如实写明 29 的既有使用。
