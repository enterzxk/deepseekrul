## 1. 出发点（数字全部来自 `HEADROOM_DIAGNOSTIC.md`）

1. **误差是尾部，不是均值。** 20% 的发动机承担 75.3 / 86.7 / 80.9 / 87.4% 的平方误差
   （FD001–FD004）；把 top-20% 误差减半，RMSE 从 10.000 / 10.371 / 9.603 / 11.688 降到
   6.600 / 6.132 / 6.024 / 6.857；而**只修全局偏差**几乎不动（10.000 → 9.956）。
2. **尾部跨 seed 稳定。** 最差三台的误差 30–70 周期，seed 间 sd 只有 1.0–8.3——是系统性失败，
   不是噪声。这条决定了「可建模」。
3. **错在中段，且两端偏差符号相反。** 真实 RUL 75–100 桶：130 台、MAE **12.50**、偏差 **+5.94**、
   晚预测 **65%**；而 25–50 桶：84 台、MAE 4.21、偏差 **−2.38**、晚预测 27%。
4. **NASA 罚分同样在尾部**：top-10% 机器占 60 / 75 / 71 / 81%。

**这三条合起来给出的目标**：把「中段 + 离群机」的尾部误差压下去，而**不是**再追一次「平均降 0.2」
——后者落在 seed sd 0.2–0.9 的噪声里，本轮已经证明做不出来。

**三个 artifact 已排除**（`HEADROOM_DIAGNOSTIC.md` §7，文献员提出、军师复核）：

- **125 封顶不是原因**：按 `RUL_FD00x.txt` 的 **raw RUL**（未截断）重新分桶，75–100 桶仍是
  n=130、MAE 12.50、bias **+5.94**、65% 晚预测，与按截断标签分桶逐位相同；封顶线之后的
  100–126 桶 bias 是 **−1.75**，不是 +5.94。
- **不是回归稀释**：`pred vs true` 斜率 **1.004 / 0.988 / 0.984 / 0.979**，`sd(pred)` 与
  `sd(true)` 几乎相同（41.4 vs 40.1 等），几乎没有向均值收缩。
- **不是子集构成**：四子集各自都有（FD001 **+7.75**、FD002 **+8.55**、FD003 **+6.37**、
  FD004 **+1.68**），FD004 较弱但同号。

**修正后的形状是驼峰，不是单调**（RAW RUL 桶 0–25 / 25–50 / 50–75 / 75–100 / 100–126 / 126+）：

```
bias:  −0.68   −2.38   +2.87   +5.94   −1.75   −4.04
                              ↑峰
```

这直接排除两类做法：**全局减常数**、**全局单调压缩**——两者都会在另一端制造新错误。修正必须
**条件化**。

## 2. 测量平台：P0 的前置条件（**比模块结构更重要**）

### 2.1 发生了什么：现有验证集测不到这个现象

`HEADROOM_DIAGNOSTIC.md` 用的是 **TEST 逐机预测**。按约定，TEST 只能**定位问题**，不能做设计
选择；所以第一步必须在验证集上复现。**结果没复现**（`7f6fbf56`）：

| 子集 | top20% 占比 | 尾部桶 n | 尾部 bias | 门 |
|---|---:|---:|---:|---|
| FD001 | 0.787 | 18 | **−0.87** | **FAIL** |
| FD002 | 0.837 | 47 | +7.78 | PASS |
| FD003 | 0.789 | 14 | +2.04 | PASS |
| FD004 | 0.822 | 37 | +4.87 | PASS |

**三条必须分开读，不能合并成一个「FAIL」**：

1. **P0b（每机只取最后一个截点）作废。** 验证集截点按各机自身寿命 40%–95% 取，最后一个截点
   的真实 RUL 只剩约 5%，**永远进不了 75–100 桶**——四个子集尾部 `n = 0`。这不是「没复现」，
   是**这个设计测不到**。
2. **P0（全部截点当样本）是 3/4 复现**，不是 0/4：FD002 / FD003 / FD004 都过门，只有 FD001
   反号，而 FD001 尾部桶只有 **18 台**、来自少数几台长寿命机。
3. **P1（校准探针）在这套平台上不赚**：5 参数分段偏移、按发动机 5 折交叉拟合，ΔP90 为
   FD001 **+1.260** / FD002 **−0.730** / FD003 **+1.517** / FD004 **+0.721**——只有 FD002
   两个指标都变好。**但这个负结果不能当结论，原因见 §2.2。**

### 2.2 一个被推翻的假设：选轮压制（**反例，别再用**）

**当时的推理（看着很硬，实测是错的）**：

- `best_ep` 按 `engine_equal_rmse = sqrt(mean_u MSE_u)` 挑（`paper_b/training/train.py`），
  是**平方误差口径**——误差 30–70 周期的机器在平方里权重是普通机器的几十倍；
- 于是推论：选轮等于在直接优化「压住尾部大误差」，**验证集不是没测到，是被选择过程抹平了**；
- 再推论：P1 的「校准不赚」也不算数，因为它是在被压制的集合上拟合的。

**实测（§2.6）：有选轮 +6.66，无选轮 +5.54——选轮不但没压制，反而略微放大了尾部偏差。假设推翻。**

**真凶是截断协议。** 旧协议用各机寿命的固定分数 40/55/70/85/95%，尾部桶虽然有人
（P0 的 FD001 n=18），但那是**非代表性子样本**——固定分数与寿命长度耦合，落进 75–100 桶的机器
被寿命筛过一遍。换成按 TEST 的 RUL 分布分层抽样后，**FD001 从 −0.87 变成 +2.62**。

**两条教训，写下来是为了不再犯**：

1. **「指标是平方口径 ⇒ 选轮会压制尾部」是推理，不是测量。** 没测就写进文档，等于拿一个错的
   理由去支持一个对的结论（平台确实要立），下次换个人还会错。
2. **现象在旧协议上不出现时，先怀疑截断/抽样协议，再怀疑模型和选择过程。**

### 2.3 平台要求（写死，不满足就不许往下做）

| 要求 | 含义 | 违反的后果 |
|---|---|---|
| **选择干净** | 诊断机**不参与**选轮、早停、超参、任何模型选择 | 诊断集被调过，结论就不能叫「未选择模型的偏差」。**注意：实测选轮并未压制偏差（§2.2），保留这条是为有效性，不是为了效应量** |
| **截断像 TEST** | 在寿命**任意处**截断，且抽样规则要**对上 TEST 的 RUL 分布** | 只测到寿命末段，尾部桶为空 |
| **启动前固定** | 哪些机做选轮、哪些只做诊断，**训练启动前固定并哈希** | 事后可挑，等于没预注册 |
| **不复用污染 checkpoint** | split 29 的 checkpoint 已因选轮被污染，**不得复用** | 带着旧偏差做新诊断 |
| **主指标与选轮指标分离（须在方法节写明）** | 我们报的主指标 `mean_u sqrt(MSE_u)` **从未用于选轮**；选轮用 `sqrt(mean_u MSE_u)` | 审稿人会问「为什么主指标不是选 checkpoint 的那个」，不写就是隐藏 |

**关于最后一条**：这本身不算错（报的量和选的量分离，甚至更干净），但**必须在方法节明说**，
否则读者会以为两个口径是一回事。

**截断抽样规则（建议，须冻结）**：对每台诊断机，从该子集 TEST 的 `RUL_FD00x.txt` **经验分布**
中抽一个目标 RUL（封顶 125），令截断点 = 该机寿命 − 目标；若目标 > 寿命则重抽。这样得到的
真实 RUL 分布与 TEST 同形，而不是固定 40/55/70/85/95%。

### 2.4 新划分 `split_seed=43`：配置、抽样、判据（跑前冻结）

**为什么不用「验证机分两半」**：`data.py:89 split_units()` 是**严格两路**（train/val），没有第三路，
诊断机只要在 `val` 里，`best_ep` 就一定看得到它；而且砍一半后 FD001 只剩 10 台诊断机、尾部约
2 台，测不出 +2.0。**这个方案建不出来，必须换。**

**采用方案：让选轮根本不发生。**

| 项 | 设定 |
|---|---|
| 划分 | `split_seed=43`（**不复用 29 的任何 checkpoint**） |
| 早停 | `patience = epochs = 40` → `ep - best_ep` 最多到 39，**永不触发** |
| 诊断模型 | `last.pt` 里的 **`model`（最后一轮）**，不是 `best.pt` |
| 诊断集 | **整个 `val`**（不砍半），样本量：FD001 20 / FD002 52 / FD003 20 / FD004 50 |
| 格数 | E0 × 4 子集 × 3 seed（101/202/303）= **12 格**，两卡约 2 小时 |

**硬前置检查**：`epochs_run` 必须 **== 40**。若不是 40，说明早停仍触发，`model` 就不是「未经选择」
的模型，**整个诊断作废**。

**双诊断口径（零额外成本）**：`last.pt` 同时含 `best_state` 与 `model`，一次训练拿两套结果：

- **`best_state`**：模拟「有选轮」的模型（用 val 选过）；
- **`model`**：**无选轮**的模型——正确诊断对象；
- **两者在 75–100 桶 bias 上的差 = 选轮压制量的直接测量**。这比任何推理都硬。

**截断抽样：按 TEST 的 RUL 经验分布分层（`RUL_FD00x.txt`，cap 125）**

| 子集 | n | 0–25 | 25–50 | 50–75 | 75–100 | 100–126 |
|---|---:|---:|---:|---:|---:|---:|
| FD001 | 100 | 19 | 11 | 13 | **23** | 34 |
| FD002 | 259 | 58 | 29 | 31 | **48** | 93 |
| FD003 | 100 | 15 | 14 | 20 | **18** | 33 |
| FD004 | 248 | 49 | 30 | 26 | **41** | 102 |

规则：按桶分层 + 比例分配（桶内目标台数 = `round(占比 × 诊断机数)`，余数按占比补齐）；桶内用
**固定种子**均匀取整数 `r`（`1 ≤ r ≤ min(L, 125)`）；截断点 = `L − r`；某机 `L` 太小落不进分配桶
则回退到可达最高桶并记 `fallback`。**种子、分配表、每台机 `(unit, r, truncation_cycle)` 训练前
落盘并哈希**（顺序：先提交，再起训练）。

**判据（先写死，不因结果改）**

| 项 | 判据 |
|---|---|
| **主判据** | **无选轮**（`model`）在诊断集 75–100 桶**四子集合并** bias **≥ +2.0** |
| **方向判据** | 四子集 **≥3/4 同号为正** |
| **禁止** | 用单子集 bias 数值下结论——尾部单子集只有 4 / 10 / 4 / 8 台，一台机就能翻转 |
| 成立 | 现象可复现 → 平台可用 → 进模块 |
| 不成立 | TEST 的 +5.94 **不可复现** → 立刻停，不再设计模块 |

**结论的作用域**：只适用于「固定 40 轮 + `model`（最后一轮）」这个协议，**不能直接搬到
`best.pt` 上报的模型上**——这一点必须写进任何引用该诊断的地方。

### 2.5 为什么这一节排在结构之前

结构选错，最多白做几轮；**平台选错，所有数字都是假的**——包括「有效」和「无效」两种结论。
本轮已经栽过一次（`test_metrics.json` 键名、clean 行判据、rng 共用流、脚本不存在），共同点都是
**测量工具没验过就开始量**。所以平台先立，再谈模块。

### 2.6 结果（GATE PASS，2026-11-18）

**前置检查**：split 43 的 **12 格 `epochs_run` 全部 = 40**——早停确实没触发，`last.pt` 的最后一轮
就是「未参与选择」的模型。前置条件成立。

**决定性结果**（同一批 TEST 式截断，12 格；逐子集三个独立实现完全一致）：

| 子集 | 无选轮（最后一轮 `model`） | 有选轮（`best_state`） | 尾部台数 |
|---|---:|---:|---:|
| FD001 | +2.62 | +4.11 | 5 |
| FD002 | **+4.63** | **+1.30** | 9 |
| FD003 | +9.58 | +12.97 | 3 |
| FD004 | +5.31 | +8.27 | 8 |
| **合并（按尾部台数加权，预注册 §4.3）** | **+5.04** | **+5.49** | 25 |
| **同号** | **4/4** | 4/4 | — |

**合并口径（写死，别再混）**：主表用**按尾部台数加权**（`(2.62×5+4.63×9+9.58×3+5.31×8)/25`），

差异来自 FD003 尾部只有 3 台机，简单平均却给了它 1/4 权重。

**判据核对**：无选轮合并 **+5.04 ≥ +2.0** ✓、**4/4 同号** ✓ → **GATE PASS**。

**三件事因此改变**：

1. **现象是真的，不是拟合 TEST。** 换划分（43）、换截断方式（TEST 式分层）、换模型（不参与选轮的
   最后一轮），四子集全部同号，量级 **+5.04 对 TEST 的 +5.94** 相当。
2. **「选轮压制偏差」的假设被推翻**（详见 §2.2）：选轮效应 **+0.45**（有选轮更大），不是压制。
   **但这只在 3/4 子集上成立——FD002 反向**（有选轮 +1.30 < 无选轮 +4.63，选轮反而减小了偏差），
   所以**不能写「选轮会放大偏差」这个通则**，只能写「合并层面略放大 +0.45，3/4 同向，FD002 反向」。
3. **测量平台立起来了**：选择干净（最后一轮）+ 截断像 TEST + 样本量够（四子集）。**后续所有模块

- **诊断机在发动机层面完全未见**：`split_units` 按发动机互斥切分，训练窗口只取 `s['tr']`；

- 结论只适用于「固定 40 轮 + 最后一轮 `model`」这个协议，**不能直接搬到 `best.pt` 上报的模型上**；

## 3. 三个必须先回答的问题

### 3.1 Q1：分段校准 vs「可靠性头」，哪个更可测？

**先给定义**（否则「校准」和「头」会被混着说）：

- **分段校准（A 类，输出后处理）**：在预测值上叠一个**按预测区间分段的仿射修正**
  `ŷ' = a_k·ŷ + b_k`（k 为 ŷ 的分段），参数 3–6 个，用**验证集发动机做交叉拟合**（out-of-fold）
  估计。推理时保留、有参数、但不看传感器特征。
- **可靠性头（B 类，结构）**：在网络里加一个**辅助输出头**，从传感器特征预测「这台机我不熟」
  的可靠性分数，用它缩放预测或放大区间。有参数、进网络图、**看特征**。

**结论：A 类显著更可测，但它只能当「必须超过的基线」，不能当贡献。**

| 维度 | A 分段校准 | B 可靠性头 |
|---|---|---|
| 能否零成本预检 | **能**（现有验证预测即可交叉拟合） | 不能，必须训练 |
| 自由参数 | 3–6 个 | 与隐藏维同阶 |
| 失效模式是否可见 | **是**（直接看 25–50 段是否恶化） | 否（要训完才知道） |
| 能否写成「模块贡献」 | **不能**——它是校准程序，不是架构 | 能（但必须超过 A） |

**一条来自诊断的先验（不是结论）**：75–100 桶的模型过估 +5.94，所以它给出的 ŷ 大约落在
**81–106**；25–50 桶欠估 −2.38，ŷ 大约落在 **23–48**。两段在 ŷ 上几乎不重叠——**只看模型自己的
输出就能判断「我大概在哪一段」**，不需要真值。这意味着分段校准很可能可分离（P2 大概率通过），
但**必须实测**，不能拿这个估计当结论。

**所以顺序是**：先用 A 当探针，**量出「尾部到底有多少是输出可校准的」**；再决定 B 值不值得做。
如果 A 就能拿到大部分空间，B 必须**超过 A** 才算数——这和「必须超过训练期增强」是同一个逻辑。

### 3.2 Q2：怎么保证不把 RUL 25–50 那端的 −2.38 早预测放大？

**风险的确切形式**：诊断显示两端偏差符号相反（75–100 是 +5.94，25–50 是 −2.38）。任何**全局
单调压缩**（例如统一把预测往下压、或统一往上抬）都会修好一端、弄坏另一端。

**三条防护，从强到弱**：

1. **先量「可分离性」，再谈校准。** 如果 25–50 桶与 75–100 桶的**预测值 ŷ 分布高度重叠**，
   那么任何只依据 ŷ 的修正**在原理上无法**分开这两段——这时 A 类路线直接判死，不必浪费实验。
   这是一个**零成本、可判死**的检验（§4-P2）。
2. **修正必须条件化且带符号约束。** 只允许在偏差为正的区间向上修正，在偏差为负的区间保持恒等
   （或仅允许小幅）。**禁止**任何单调全局映射。
3. **预注册非劣护栏（硬判据）**：
   - 25–50 段 MAE 恶化 **≤ +0.5 周期**；
   - 0–25 段（临近失效，安全相关）MAE 恶化 **≤ +0.3 周期**。
   两条任一违反 → 方案否决，**不看主指标多好**。护栏必须在跑之前冻结。

### 3.3 Q3：用什么对照证明「超过只做训练期增强」？

**核心难点**：训练期增强（E1a）本身就有增益，而且它**零参数、零推理开销**。如果模块只是把
同一个效果换个壳，审稿人一句「同样的效果、更差的工程」就否掉。

**对照必须五臂，且全部在同一代码树上重训**（不同指纹之间不能配对，见 §10.3 的教训）：

| 臂 | 内容 | 作用 |
|---|---|---|
| **A** | 无增强、无模块 | 基线 |
| **B** | 仅训练期增强（E1a 配方：mask p=0.10） | **主对照**（必须超过它） |
| **C** | 仅模块、无增强 | 分离模块自身效应 |
| **D** | 增强 + 模块 | **主比较：D vs B** |
| **E** | 参数匹配对照（同参数量、无尾部机制） | 排除「只是加参数」 |

**三条主张各自需要什么证据**：

- 「模块有独立增益」= **D vs B** 达标（这是主判据）。
- 「增益不是来自额外参数」= **D vs E** 必须达标；否则只能说「多给参数有用」。
- 「机制方向一致」= **C vs A** 同号（辅助证据，不作主判据）。

**若 §4-P3 的校准探针通过**，再加第 6 臂 **F：仅分段校准**——模块还必须**超过 F**，
否则「用更复杂的东西做同样的事」同样不成立。

## 3.4 Q4（文献员提出）：可靠性头到底有没有决策用途？

**这一问决定 B 类值不值得做。** 文献员已确认「confidence-aware RUL」是拥挤赛道（Zhang 2022
分位数回归、Diao 2026 分位数+conformal、RobustUQ 2025、DET-MCD 2026 evidential）——
**「加一个可靠性头」本身不新**。所以它必须回答：**这个分数被用来做什么决策？**

如果答案只是「输出一个方差/置信度」，那它**不是贡献**，只是又一个不确定性估计器。

### 三种可能的决策用途，每种必须配一个可测指标

| 用途 | 决策含义 | 指标 |
|---|---|---|
| **① 分诊（triage）** | 把「预计会错得离谱」的发动机挑出来优先复检 / 加密采样 | 对「真实 top-20% 误差机」的 **AUROC**、**precision@20%** |
| **② 保守化（降权）** | 不可靠时把预测往安全侧（偏早）收，避免晚预测 | 0–25 段漏检率、NASA 总和 |
| **③ 区间宽度** | 用它设 conformal 区间宽度，供维护排程用 | 覆盖率 / 平均宽度（PICP / MPIW） |

**①分诊是唯一直接对应维护动作的**：维护方不可能「不给预测」，但可以「先看哪几台」。所以这是
最像贡献的一条。

### 硬门槛：必须打赢两个免费基线

因为诊断已经证明 **ŷ 本身就能定位区段**（75–100 的 ŷ 落在 81–106），所以「按 ŷ 落点分诊」是
**零成本**的；另外**跨 seed 分歧**（同一台机 5 个 seed 预测的 sd）也是**免费**的可靠性代理。

> **判据**：可靠性头的 AUROC 必须 **≥ max(ŷ-基线, seed-分歧基线) + 0.05**，
> 或 precision@20% 高 **≥ 10 个百分点**。打不赢 → **没有决策用途，不做**。

这条门槛的作用：防止「加个头、报个 AUROC 0.7、说有用」——0.7 如果 ŷ 基线也有 0.75，那就是
纯装饰。

### 结论（写死）

- 若 §5 决策门放行 B 类，**必须同时通过本节门槛**，否则退回 A 类（校准）或停止。
- 若选 ①分诊，论文里必须报**决策指标**（precision@20% 之类），不能只报不确定性质量
  （NLL/CRPS）——后者是度量，不是用途。

## 4. 六项零成本预检（跑任何训练之前，全部用现有预测）

| 编号 | 预检 | 输入 | 产出 | 判死条件 |
|---|---|---|---|---|
| **P0** | 在**新平台**上复现尾部现象（§2.4） | split 43 诊断半（选择干净 + TEST 式截断） | 尾部 bias、四子集同号、top-20% 占比 | bias < +2.0 或不同号 → **停止** |
| **P1** | 尾部误差的 seed 稳定性 | 同上 | 最差 10 台的 sd/误差比 | 比值 ≥ 1/3 → 尾部是噪声，**停止** |
| **P2** | 两段在 ŷ 空间的可分离性 | 同上 | 25–50 与 75–100 桶的 ŷ 重叠度 | 重叠严重 → **A 类路线判死**，只剩 B 类 |
| **P3** | 交叉拟合分段校准探针 | 同上 | ΔP90、ΔRMSE、25–50 段 ΔMAE | 见 §5 |
| **P4** | P90 的 seed 波动（定门槛用） | 同上 | E0 的 P90 逐 seed 值 | 用于把 §7 的门槛写成绝对值 |
| **P5** | 决策用途检验（**仅当选 B 类**） | 验证预测 + 跨 seed 分歧 | AUROC / precision@20% vs 两个免费基线 | 打不赢 → **B 类不做**（§3.4） |

### 4.1 操作定义（跑前冻结，避免各人各写一套）

**P2 可分离性**（输入：诊断平台逐机 ŷ 与真值）

- 取真值 RUL ∈ [25,50) 与 [75,100) 两桶的发动机，比较其 **ŷ 分布**。
- 判「**可分离**」需同时满足：
  1. 75–100 桶的 ŷ 中位数**不在** 25–50 桶的 `[Q1, Q3]` 区间内；
  2. 用 ŷ 区分两桶的 **AUROC ≥ 0.85**。
- 任一不满足 → 判「不可分离」→ **A 类（输出校准）判死**，只剩 B 类。
  理由：若两段在 ŷ 上混在一起，「ŷ 偏大 ⇒ 该往上修」会把 25–50 的机器一起往上推。

**P3 交叉拟合校准探针**（5 参数分段偏移，零训练）

- 分段：按 **ŷ** 分 5 段 `[0,25) [25,50) [50,75) [75,100) [100,125]`，每段一个偏移 `b_k`。
- 拟合：`b_k` = 训练折内该段 `(y − ŷ)` 的**中位数**（不是最小二乘，抗离群）。
- 交叉拟合：**按发动机 5 折**（同一台机的所有截点在同一折），4 折拟合、1 折评估，轮换。
- 报告：ΔP90、ΔRMSE、25–50 段 ΔMAE。
- **达标**：合并 ΔP90 **≤ −0.5** 且 25–50 段 MAE 恶化 **≤ +0.5**（两者同时）。

**P4 P90 的 seed 波动**（定 §7.1 的绝对门槛）

- 在诊断平台上，逐 seed 算 E0 的 P90（定义见下），报 mean 与 **sd**。
- §7.1 的门槛取 **max(0.5, 1.0 × sd)**，在跑任何模块之前写死。

**P90 的定义（冻结）**：先按 seed 平均逐机误差 → 每台机一个 `|e_u|` → 子集内取 **90 分位** →
**四子集等权平均**。
> 合并方式说明：P90 是分位数，跨子集加权没有自然定义；而子集难度差异大（FD002/FD004 明显更难），
> 把发动机池起来算一个 P90 会被难度高的子集主导。故用「逐子集 P90 → 等权」，并在报告里附
> 「合并引擎池」的值作脚注。**这一条与 §2.6 的 bias 合并（按台数加权）不同，不要互相套用。**

**P5 决策用途**（仅当选 B 类）

- 任务：给每台机一个可靠性分数，用于「挑出真实 `|e_u|` 落在 top-20% 的机器」。
- 指标：**AUROC** 与 **precision@20%**。
- 两个免费基线：①按 ŷ 落点分诊（ŷ ∈ 中段则报警）；②按跨 seed 预测 sd 分诊。
- **达标**：AUROC ≥ max(两个基线) **+ 0.05**，或 precision@20% 高 **≥ 10 个百分点**。

### 4.2 P2–P4 结果（2026-11-18）

**P2 → 可分离，A 类路线活着。** `n(25–50)=17`、`n(75–100)=25`；75–100 桶的 ŷ 中位数
**96.7**，25–50 桶 `[Q1,Q3] = [29.4, 44.1]`——完全落在外面；**AUROC 0.998**。两条判据都满足。

**P3 → 主指标大幅改善，但被非劣护栏拦下（FAIL）**

| 指标 | 校准前 | 校准后 | Δ | 门槛 | 判 |
|---|---:|---:|---:|---|---|
| P90 | 19.470 | 15.904 | **−3.566** | ≤ −0.5 | ✓ |
| RMSE | 11.533 | 10.195 | **−1.337** | ≤ 0 | ✓ |
| **MAE（真值 25–50 段）** | 6.035 | 6.839 | **+0.804** | **≤ +0.5** | **✗** |

**失败机制（看偏移量就明白）**：五段偏移是**按 ŷ 分段**的，`ŷ∈[75,100)` 那段高达 **+8.3 ~ +9.4**，
其余段只有 +1.7 ~ +6.1 / −5.1 ~ −7.9。一台真值 25–50、但 ŷ 落进 `[75,100)` 的机器会被加上约
9 个周期——**过度修正**。这正是 Q2 预判的风险，只是形态不是「符号错」，而是
**「按 ŷ 分段会把边界样本分错段」**。

**措辞必须准确**：这是**护栏失败**，不是「校准没用」——校准把 P90 压了 3.57、RMSE 也降了 1.34，
代价落在 25–50 段。审稿人问「P90 好了 3.5 为什么要杀掉」，答案是**预注册的非劣护栏**。

**P4 → 门槛 = 0.870**：E0 逐 seed P90 = `[20.395, 18.683, 19.269]`，mean 19.449、**sd 0.870**，
`max(0.5, sd) = 0.870`。

**决策门后果（按 §5）**：`P0 通过 → P2 可分离 → P3 不达标` → **A 类（输出校准）判死**；
**只允许 B 类，且必须先做 P6（特征是否携带尾部信息）**。

**一个与旧证据的冲突，必须解释清楚**：`audit_tail_probe.py`（`7f6fbf56`）在**旧协议**上做过近似
P3 的实验，ΔP90 为 **+1.26 / −0.73 / +1.52 / +0.72**（三个子集变差）；而在新平台上 P3 的 ΔP90
是 **−3.57**，方向相反。已识别的三处差别：①旧协议截断（固定分数）vs TEST 式分层；②偏移用均值
vs 中位数；③旧实验没做 25–50 非劣检查。**解释清楚之前，不得把 −3.57 当成「校准有效」的定论**
——但这不影响本次判定，因为判定本来就是 FAIL。

**一条被挡掉的「显然能过」的改法**：「只在 ŷ ≥ 50 的段做校准」能过护栏，但那是**看到结果后改
口径**。要做必须**另立一次预注册**（新判据、新门槛、写死再跑），并与本次 FAIL 一起报，不得当作
P3 的重新解读。

### 4.3 P6：特征是否携带尾部信息（B 类的前置门槛）

A 类判死后，B 类（条件化在特征上）必须先证明**特征在 ŷ 之外还有信息**，否则加了头也是装饰。

- **任务**：在 **ŷ 段内**（控制 ŷ，例如只在 `ŷ∈[75,100)` 的机器之间比较），用传感器特征预测
  该机的 `|e|` 或残差 `(y − ŷ)`。
- **交叉拟合**：按发动机 5 折。
- **判据**：段内 **AUROC ≥ 0.65**，且 bootstrap 95% CI 下限 **> 0.55**。
- **理由**：P5 要求 AUROC ≥ 免费基线 + 0.05；若特征在 ŷ 之外几乎无信息，任何带参数的头都不可能
  跨过这道门槛。
- **不通过 → B 类也判死 → STOP**，记负结果，不再设计模块。
- 门槛若认为过严/过松，**必须在跑之前改**；跑完不改。

## 7. 预注册草案（执行前可改，改后冻结）

### 7.1 主指标（双主，AND）

1. **尾部指标 P90**：逐机绝对误差的 90 分位（**先按 seed 平均逐机误差，再在发动机上取分位**），
   先逐子集算、再四子集等权平均。**合并 ΔP90 ≤ −0.5 周期**（负 = 更好），95% CI 不含 0，
   **≥3/4 子集同号**。
2. **RMSE（engine-level）非劣**：合并 ΔRMSE **≤ 0**（不允许为 P90 牺牲 RMSE），且报 95% CI。

**为什么双主**：只报 RMSE 会被均值掩盖（诊断已证明），只报 P90 则可能靠「压缩极端预测」取巧。
两个都要过，才说明尾部真被改善而不是被摊平。

### 7.2 护栏（任一违反即否决，不看主指标）

- 25–50 段 MAE 恶化 ≤ **+0.5**；
- 0–25 段 MAE 恶化 ≤ **+0.3**；
- NASA 总和（逐台）不得恶化超过 **+5%**（仅报告口径，不作选择依据）。

### 7.3 对照与统计

- 五臂（A–E，必要时加 F），**同树重训**，每臂 **5 seed（42–46）**。
- 发现：`split_seed=17`，3 seed（101/202/303）先筛；确认：`split_seed=29`，5 seed。
- **确认集不得用于任何结构或超参选择**；确认集只跑已冻结的配置。
- 统计：发动机级 bootstrap 10000 次，**每个统计量独立 rng**；先按 seed 平均再重采样；
  报点估计、95% CI、逐子集值、seed 间方向一致计数。

### 7.4 判据（全部满足才算「模块成立」）

1. D vs B：ΔP90 与 ΔRMSE 双主指标达标；
2. D vs E：ΔP90 达标（排除「只是加参数」）；
3. 两条护栏不违反；
4. 确认集上复现（同 1–3）。
5. **若采用 B 类（可靠性头）**：必须通过 §3.4 的决策用途门槛（AUROC ≥ 免费基线 + 0.05，或
   precision@20% 高 ≥ 10 个百分点）。不通过 → 退回 A 类或停止。

**任一不满足 → 模块不成立**，按「失败机制 → 修正假设 / 放弃」处理，不追加低价值诊断。
