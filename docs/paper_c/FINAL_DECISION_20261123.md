## 4. 机制与排序

**机制（代码可验证）**：CADF 的输入是 `x` 的**确定性函数**——`z = [x, delta, e]` 中 `delta = (x − b)·mask`、`e = EMA(delta)`，而 `b` 由 `(x, cluster, mask)` 唯一确定，所以 `z` **不引入 `x` 之外的新信息**；且 `return x + g * proj(z)` 里 `x` 原样穿过，模块只能在上面加一个可学习变换。准确写法是「**输入层重编码，不引入新信息**」，不是「高通滤波把趋势扔了」——后者架构上做不到。

机制解释的三次迭代留痕（不得只留最后一版）：「预处理已含工况归一化、信息重叠」（被 `‖b‖/‖x‖ = 0.79–0.93` 证伪）→「高通滤波丢弃趋势信息」（被 `return x + g * proj(z)` 的架构证伪）→「输入层重编码」**（现行）**。

**排序**：**骨干间排序不可区分，不作归因**（补遗 #5 规则 5）。口径是组均值的标准误 `SE(Δ̄) = sd/√3`，不是逐 seed 的 sd；绝对参数量与 CADF 相对开销两个代理都不单调，均不得写入。

## 5. 必须单列的例外：唯一通过单元级的 `two_phase/FD004`

- 数字：`Δ̄ = 0.7863`，95% CI `[0.1698, 1.5114]`（**不含 0**），胜率 `0.60`，三 seed `0.8032 / 0.7087 / 0.8470`（3/3 同号），`p_null = 0.097`，`MDE = 0.972`，n = 50 台。
- **它不计票不是因为它不合格，是分档结构没有它的位置**：`full` 档要求同一骨干 FD001 与 FD004 同时达标，而 `two_phase/FD001` 是 `-0.1062`（反号）；`sc` 档按预注册只认 FD001。
- **三条必须并排出现，少一条就会被写成「唯一有效」**（军师 2026-11-23）：
  1. `t = 19.27`（df=2 临界 4.303）→ seed 间**可复现**；但 n=3 无功效，**不是证据**；
  2. `p_null = 0.097` → 零假设下 10 个单元本来就会出约 1 个这种量级；
  3. 它是全部单元里**误差最大的欠拟合基座**（CADF 臂 22.94–23.44，其余 ≤14.89，据 `docs/paper_c/B_FINAL_20261123.md`）→ 增益可能来自欠拟合而非模块。
  结论：**只记形态，不作归因。**
- **冻结设计的缺口（写进限制，不改判据）**：这套分档**没有「只在 FD004 成立」的位置**，而 `sc` 恰好是它的镜像。本轮不改；下一版预注册应补一个对称档，或明确写「只认 FD001 是有意为之」。不写这句，论文一定会被问「唯一通过的那一票去哪了」。

## 6. 限制

1. **分档结构缺口**：`full` 需两子集同时达标、`sc` 只认 FD001，无 FD004-only 档（§5）。
2. **`ffve` 的 VAE 采样噪声**：其 forward 含 `reparameterize()`，逐格 Δ 天生带采样噪声；两臂用 `fork_rng` 固定种子故可比，但其种子内噪声大于另外四个骨干，报告须单独标注。
