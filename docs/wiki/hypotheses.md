## H004 预注册（Codex L2 决策，2026-11-08）

**假设**：因果前缀信息 + 引擎-阶段覆盖正则，通过**选择性宽度分配**降低未见引擎的覆盖缺口。

**输入边界（硬约束）**
- 只允许：传感器、工况、已观测循环数、预测时刻的前缀汇总
- 禁止：引擎 ID embedding、未来观测、寿命比例、真实 RUL
- 阶段划分：用**冻结的中心预测**的 RUL 分三段（<125/3、125/3–250/3、>250/3）——这是可观测的阶段代理，不是真实退化状态

**训练目标**
```
L = mean_e mean_t [pinball_0.05(y, L_t) + pinball_0.95(y, U_t)] / 125
  + lambda * mean_e mean_k [0.90 - C_ek]_+^2
```
C_ek 用温度=1 个 RUL 循环的 sigmoid 边界做可微覆盖；引擎等权；只对占用的阶段取平均；保留全局 CQR，**不做分组校准**。

**对照（6 个变体 + 2 个参考）**
1. engine-balanced pinball only
2. prefix only
3. grouped penalty without prefix
4. **full H004**
5. full H004 with engine-only grouping
6. prefix-conditioned orthogonal quantile regression
+ CQR 参考、宽度匹配的均匀放宽控制

**判定门（训练前冻结）**：边际覆盖匹配 0.90（±0.005）下，四条全部满足
1. 引擎平衡阶段短缺相对 CQR 降低 **≥25%**，配对 95% CI 排除零
2. 至少 3 个子集的**每引擎覆盖第 10 百分位**提升 **≥5 个百分点**
3. 平均宽度与固定 α=0.1 的 Winkler 各自劣化 **≤2%**，且短缺低于宽度匹配的均匀放宽控制
4. 去掉前缀信息后短缺改善**至少减半**；去掉阶段分组后阶段短缺变差（配对 CI 排除零）

**统计单位**：发动机为聚类重采样单位（连同其窗口与重复评估）；报告全部子集、seed、阶段占用与最小覆盖。

**预算**：24 次内层选择拟合 + 480 次评估拟合（6 变体 × 4 子集 × 5 折 × 4 seeds）。

**失败处理**：任一条不满足即收窄或拒绝对应机制主张；写 `failures.md`，不改主线（CQR 仍为论文主张）。

## H005 预注册 · 2026-11-09 · 条件尺度何时有效（MC-Dropout sd 的校准侧可测条件）

> **写入时点**：在任何 H005 分析脚本运行之前写入（2026-11-09 12:0x）。
> **已观测现象（不是本假设要发现的东西）**：80 格名义水平下，MC-Dropout 尺度单独效应
> 逐子集为 FD002 19/20 胜 −7.05%、FD004 15/20 胜 −2.01%、FD001 8/20 胜 +17.63%、
> FD003 1/20 胜 +28.53%（`docs/tables/mcd80_cells.csv`，完整性门 `verify_mcd80.csv` 已过，
> 重训点预测与冻结 preds 逐位一致）。**H005 只解释这个分裂，不重新发现它。**
> **不得**把本假设写成「MC-Dropout 无效/有效」的总判断（D019 B3 已撤回该定位）。

### 记号（全部用冻结协议）

- 冻结划分：`engine_split(seed=42, frac=0.3)` → 校准发动机集 $C$、测试发动机集 $T$。
- 每台发动机 $i$：平均 dropout 尺度 $\bar s_i$，平均绝对中心误差 $a_i=\mathrm{mean}|y-\mu|$（仅在校准集上计算 $a_i$）。
- **$\rho_{cal}$** $=$ Spearman$\{(\bar s_i, a_i)\}_{i\in C}$ —— **校准侧可测**（校准集有标签，部署前可得）。
- **$\Delta_{eng}$** $=$ SD$_{i\in C}(\bar s_i)\ /\ \mathrm{mean}_{i\in C}(\bar s_i)$ —— 尺度的跨发动机离散度。
- **$\mathrm{shift}_{sd}$** $=$ $|\mathrm{mean}_{i\in T}\bar s_i-\mathrm{mean}_{i\in C}\bar s_i|\ /\ \mathrm{mean}_{i\in C}\bar s_i$。
- 结果量：$r_{scale}$ $=$ (MCD 名义 Winkler − 同中心常数宽度名义 Winkler)/同中心常数宽度 ×100（负=尺度有用）。
- 覆盖缺口：$\mathrm{gap}=\mathrm{coverage}_{MCD}-0.90$。

### 假设与判定门（阈值现在冻结，事后不得改）

| 编号 | 假设 | 判定门（全部在**折级 n=20**，seed 先平均） |
|---|---|---|
| **H005-A** | 尺度有用 ⟺ 它在校准集上能排序发动机难度 | **G-A**：Spearman$(\rho_{cal}, r_{scale})$ **≤ −0.35**，且 1000 次折级 cluster bootstrap 的 95% CI **上界 < 0** |
| **H005-B** | 该排序能力在多工况子集上更强 | **G-B**：$\overline{\rho_{cal}}(\text{FD002}\cup\text{FD004})-\overline{\rho_{cal}}(\text{FD001}\cup\text{FD003})$ **≥ 0.20**，且 5 折中 ≥4 折同号 |
| **H005-C** | MCD 欠覆盖由校准→测试的尺度漂移驱动 | **G-C**：Spearman$(\mathrm{shift}_{sd}, \mathrm{gap})$ **≤ −0.30**，bootstrap 95% CI 上界 < 0 |
| **H005-D** | 可部署的 go/no-go 规则优于「总是用」与「从不用」 | **G-D**：规则「$\rho_{cal}\ge\tau$ 才用尺度，否则退化为常数宽度」，$\tau=0.5$ **先验固定、不调**；其 80 格平均 $r_{scale}$ **≤ −2%**，且 **FD003 上平均 ≥ −2%**（即不重演灾难）；同时优于 always-use（均值 +9.3%） |

### 统计纪律

- 分析单位：**折（n=20）**；seed 先在折内平均。80 格只作明细。
- 20 折共享训练数据（D015），**不做独立样本显著性检验**；bootstrap 仅作描述性区间。
- 不选模型、不调 $\tau$、不改任何区间或校准；H005 只产出**诊断量与判定**。

### 预算与失败分支

- **0 GPU，CPU ≤30 min**；只用 `experiments/punet_mcd80/` 与 `experiments/punet_matrix/`。
