## 使用规则

1. 新增条目只追加，不覆盖；状态变化用"状态"列 + 日期。
2. 每条必须给**证据路径**（文件或实验目录），无证据不得登记为"已验证"。
3. 被推翻的假设保留原行，状态改为"已证伪"，并在备注写机制。
4. 与权威源冲突时，先修权威源，再同步本 Wiki。
