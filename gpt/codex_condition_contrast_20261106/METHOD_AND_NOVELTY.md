# 已实现的核心方法与创新边界

日期：2026-11-06。候选简称 CCT，仅为实验标识，尚不是已成立的论文方法。

## 1. 针对的实际问题

当前仓库的 FULL＋长窗口调度在两种子开发评估中降低 FD002/FD004 RMSE，但 FD004 NASA 从 9.943 上升到 37.764。结果支持“长历史可能有用”，并没有证明某个新交互机制有效，也没有证明长历史导致高估的具体原因。

本次只检验一个模型假设：在保持 PE/FULL 主干和观测信息一致的前提下，将长历史变成可学习、显式去除工况截距的趋势量，是否比直接长窗口、固定趋势特征和两个模型的窗口调度更有效。

## 2. 核心估计器

窗口末端为 t，只允许 s≤t 的观测。对 h∈{20,50,100}、传感器 n，令 u_s=(s−t)/h，工况簇为 c_s。簇只由训练折的操作设定量拟合，不使用寿命标签。

先按工况做不加权中心化，得到 x_s−mean_{c_s}(x)、u_s−mean_{c_s}(u)、工况内标准差与有效样本数。用共享小网络 gθ 生成有界权重 logits：

    l_s = 2 tanh(gθ(centered_x_s, centered_u_s, group_sd_s, group_count_s/h))
    w_s = masked_softmax(l_s)

再用这些权重重新计算各工况的加权均值 x̄_c、ū_c。可微趋势估计为：

    a_hn = Σ_s w_s (u_s−ū_c)(x_sn−x̄_cn) / Σ_s w_s (u_s−ū_c)^2

分母太小时将该斜率标记为不可辨识，输出零斜率，并保留跨度支撑量。编码器同时输出回归残差尺度、时间支撑量以及有效观测数。因为 u 已除以 h，a 的量纲是“该跨度内的传感器变化”，不是循环倒数。

把三个跨度、14 个传感器的统计量经小网络投影到 PE context，与既有 FULL 先验相加，再使用原回归头。投影最后一层零初始化，使同初始化的候选和 PE 在训练起点输出一致；后续训练可共同更新主干与趋势模块。该性质不保证最终性能不下降。

## 3. 可以证明的性质

固定工况标签、时间及观测掩码，对每个传感器/工况施加常数偏置 b_cn：

    x'_sn = x_sn + b_{c_s,n}

第一次中心化会抵消 b，所以网络输入及权重保持不变；第二次加权中心化同样抵消 b，因此斜率、回归残差、时间支撑和有效样本数保持不变。该结论已用非均匀学习权重做数值验证。

边界必须写清：

1. 这是趋势分支性质。PE 和 FULL 先验仍消费测量水平，整网不具备该不变性。
2. 只抵消窗口内固定的工况/传感器截距，不能抵消时变漂移、工况增益或条件误分配。
3. 共享局部斜率是建模假设；不同工况存在不同退化灵敏度时可能失效，固定趋势和无工况控制用于揭示这一点。
4. 权重是为了 RUL 目标学习的统计权重，不是物理噪声方差倒数；残差也不是校准置信度。
5. 对输入时间作平移不会改变趋势量；实际观测时刻和掩码参与运算，填充值不会被当成有效观测。

## 4. 最近邻检索与可主张的差异

检索不是完整的新颖性证明。下列已有方法意味着不能把“长窗口”“差分”“加权回归”三个名称直接当创新：

| 已有工作 | 已有内容及对本工作的约束 | 本候选待检验的差异 |
|---|---|---|
| [TCFT-BED，2025，§2.1/§3.4](https://arxiv.org/html/2511.04723v1) | 已按可用历史长度使用不同窗口模型；单纯窗口调度不是空白 | 一个共享预测器中的可微工况内趋势估计，而不是多个长度模型的选择 |
| [A Hybrid Degradation Modeling and Prognostic Method for the Multi-Modal System，2020](https://www.mdpi.com/2076-3417/10/4/1378) | 已结合累积动态差分与局部退化特征；差分和长短信息组合均已有先例 | 端到端学习观测权重，并保留工况截距抵消性质；必须超过同信息固定权重控制 |
| [Automatic multi-differential deep learning，2022](https://www.sciencedirect.com/science/article/pii/S0951832022001855) | 已做多传感器差异化特征与时间趋势学习 | 核心是受约束的回归估计层，不以“差异化注意力”命名替代实质差别 |
| [Robust HMM-Based RUL Estimation Using a Ridge-Regularized EM Algorithm，2026，Appendix A](https://pmc.ncbi.nlm.nih.gov/articles/PMC12944381/) | 已使用标准加权最小二乘斜率/截距；公式本身不是新数学 | 以操作工况作为待消去截距，权重由偏置不变输入端到端学习，作为 PE 的历史测量分支；是否足够新仍待审查 |

不能写“首次提出同工况差分”“首次长短窗口融合”“首次用 WLS 预测 RUL”。若 learned_trend 不优于 fixed_trend，就撤回“学习机制有价值”的主张；若不优于 unmatched_trend，就不能将预测收益归因于工况处理。

## 5. 尾部高估独立处理

主实验保留现有 MSE+非对称 MSE。只有结构筛选已显示正向 RMSE 但 MAE/NASA 门失败时，允许一次预先固定的尾部损失实验，并将同一损失同时用于各基线和固定趋势控制。

附加损失在 |error|/scale≤6 时等于 NASA 指数项，之后沿切线线性延拓，以保持非零、连续的尾部梯度。scale 为高估 10、低估 13，系数固定为 1.0。它是数值稳定的训练控制，不是新颖性主张；不能保证 NASA 改善。正式评分始终使用真实指数分数，不截断预测、不删异常发动机。

## 6. TIM 对接点

若结果通过，贡献叙述应围绕：多工况传感器测量中的截距混淆、有效时间跨度与趋势量估计，以及这些处理对间接 RUL 估计的影响。固定偏置干预与实际误差比较用于评价上述处理，不能把一般预测网络只换成“测量”措辞。

[TIM 官方范围](https://ieee-ims.org/publication/ieee-tim)包含测量信号调理、处理及测量信息分析；[作者指南](https://ieee-ims.org/publication/ieee-tim/information-authors)也要求核心增量属于 I&M。与范围相关并不意味着达到投稿或录用标准。

## 7. 明确的成功与失败解释

- learned 胜 fixed、普通长窗口和调度，且尾部不恶化：支持这一具体结构值得继续研究。
- fixed 与 learned 打平：长历史趋势特征有用，但不能声称可学习估计层带来增益。
- 只加尾部损失就让普通 PE 追平：收益来自目标函数，不是结构。
- 多种子下 RMSE 好而 NASA 坏：不通过，保留全部结果。
- 开发指标通过、官方基准未改善：报告泛化边界，不在官方标签上重新调结构或损失。
- 全部通过：仍需完整最近邻对比、成本披露与论文审阅；不自动输出 SOTA 或 TIM-ready。
