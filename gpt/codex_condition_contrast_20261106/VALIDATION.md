# 本地验证记录

日期：2026-11-06。性质：实现验证，不是 C-MAPSS 实验。

实际命令：

```text
python -m unittest discover -s tests -v
```

已通过 20 项检查：

- 非均匀学习权重下，工况/传感器固定偏置抵消。
- 已知线性趋势在有工况截距时被正确恢复。
- 未来观测不能改变当前趋势；缺测与补齐位置被掩码排除。
- 所有观测缺失时前向和反向均有限；不把不可辨识斜率变成 NaN。
- 均匀初始权重等于固定回归控制。
- 不匹配工况的控制会失去工况偏置抵消性质。
- 候选零初始化接入时输出严格等于同初始化 PE。
- 随机种子在模型构建之前设置；重复构建参数逐项一致。
- 六个模型臂可反向传播；零初始化后趋势权重实际收到梯度。
- 尾部损失在连接点导数连续，严重高估仍有非零梯度。
- 延长发动机未来轨迹只改变标签，不改变此前的输入、参考态和观测掩码。
- 内层 OOF 和外层训练排除相应留出发动机。
- 标准格式合成训练文件经过真实数据处理和 HGB 嵌套先验流程。
- 缓存往返保留键、目标及观测掩码。
- 只有 3 次观测的合成发动机仍进入最终推断，不需要读取官方标签。
- 检查点可以由官方推断入口载入并生成有限预测。
- 四指标按发动机等权计算；NASA 用原始指数定义。
- 重复键、删掉查询或不同目标值会被拒绝。
- 开发筛选、固定参考、三种子确认及后续队列正确衔接。
- 构造的“RMSE 改善而 NASA 恶化”不会通过验收。

本机 Windows 上的合成预处理验证出现 scikit-learn/MKL 的已知 KMeans 线程警告，测试仍通过。实验包没有更改全局环境；Linux worker 为自己的进程设置线程数。

尚未执行：真实 C-MAPSS 训练、真实 GPU 队列、真实官方预测评分、实际论文性能比较。Linux 进程组与锁按服务器执行路径实现，本地未启动真实 GPU 任务。全部科研增益、新颖性和投稿就绪状态均保持未确认。
