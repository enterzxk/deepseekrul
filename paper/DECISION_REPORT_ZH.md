## 0. 一句话结论

唯一在所有子集上都复现的效应是**时间通道**：去掉它，FD002 代价 +1.133 [+0.245, +2.023] RMSE（260 台），FD001 代价 +2.052 [+0.505, +3.733]（100 台），逆方差合并 **+1.347 [+0.568, +2.126]**（360 台）。

编码方式（有界正弦 vs 线性周期）、同一档内各架构的排序、以及候选模型与 Transformer 的差距，在两套协议下都**低于可分辨边界**。论文的主线应从「方法差异不可分辨」收窄为「**约 1.2 RMSE 以下的差异不可分辨**」。

## 7. 现在可以写 / 不能写

**可以写**

1. 时间通道效应跨四子集合并显著：dev +0.98 [+0.35, +1.61]（709 台），官方 test +0.48 [+0.04, +0.93]（653 台）——方向一致、幅度减半，均在测量分辨率边界量级。
2. 子集级效应符号跨协议不稳定（FD003：dev −1.32 → test +1.69 显著）——**单子集单协议的估计不是测量**，这是论文主题的最强证据。
3. 260 台留出发动机的可分辨边界约 1.1–1.5 RMSE；低于该值的差异在两套协议下都不可分辨。
4. 单折结论会被折间变异放大 2.4 倍（+2.693 → +1.133），论文必须用全折留出。
5. 效应保留率是效应大小的单调函数（1.5 RMSE → 1%，5.9 RMSE → 99%）。
6. 有界编码收益在 dev 三子集方向一致但均不显著，在 test 四子集全部消失（2 个 TOST 等价）。

**不能写**

1. 「有界编码非劣」——已在 E10/E18 撤回（C14），且 test 侧不外推（C42）。
2. 「候选模型优于 Transformer」——区间跨 0。
3. 「档内架构等价」——TOST 四组全部失败。
4. 「时间通道效应在每个子集都显著」——FD003 dev 侧反向不显著（I²=70%，必须报异质性）。
5. 任何 SOTA / 双冠声明，以及 P7/P9/P10 的 synergy-head 数字（13.209 / 14.155 / 13.753 均已作废）。
