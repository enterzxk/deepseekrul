## 0. 一句话现状

C-MAPSS 上的**预测精度已经具备竞争力**（自研 41,858 参数模型在官方测试集上 FD004 12.27，优于所调研的 7 篇 2025–26 文献），但**架构级创新连续四次失败**：PRC（统计推断）、ECS（先验/似然融合）、CIDO（状态空间）、CET（递归生存分布）全部 NO-GO。当前卡在"精度够、创新不够"。

## 1. 目标（不可妥协的三条）

1. 有**自己的模型框架创新**——审稿人能指出"这个算子/结构在文献里没有等价物"，而不是模块组合。
2. 实验效果**稳定优于公平强基线**（同输入、同预算、参数匹配对照）。
3. 能投 **IEEE TIM**（测量学气质：可复现、有校准、有审计，不接受纯刷分）。

## 3. 已经确立的事实（不要重复踩）

### 3.1 精度基线（这是资产，不是问题）

- **E21 统一官方测试**（capped 真值，653 台）：A 臂 RMSE **10.45 / 11.96 / 10.09 / 12.27**（FD001–004）。
- **E22a 全 707 台**：A 10.38 / 16.66 / 9.95 / 13.64；PE 在 FD002 11.51、FD004 11.79 最优。
- **E22b 公平复现 Dual-Mixer（RESS 2024）**：统一协议下 A-zscore **10.16** vs Dual-Mixer **13.39**（41.9k 参数 vs 115k）。
- 结论：**"模型太弱所以只能做评价研究"这条质疑已经被堵死**，架构创新不必再证明实力。

### 3.2 四次创新尝试为什么失败（关键，别重走）

| 线 | 主张 | 死因 |
|---|---|---|
| **PRC** | 协议稳健比较 + 同时置信带 | 同时带覆盖率 0.84–0.88（要求 0.93），且**四态 IUT 在三个场景直接击败它**（0.89–0.93 vs 0.23–0.31）。IUT 的拒绝域互斥，FWER≤α 可证，不需要同时带 |
| **ECS** | Weibull 年龄先验 × 传感器似然^α | α 的第二个因子 ρ（跨通道一致性）t=0.01 完全无效，按预登记退化为单因子；H2 校准失败（90% 覆盖 0.74） |
| **CIDO** | 共享-特异创新分解 + 证据条件化转移 + 首达时间 | 两个算子**都已被做过**：分解=因子分析做故障诊断（Apley&Shi 2001、Dunia 1996、JIVE 2013）；转移=**Si et al. 2013 MSSP 35:219 结构完全同构**。且自证的可辨识性命题被自己的实验证伪（仿射观测模型反而更准） |
| **CET** | 递归生存分布 + 条件证据创新算子 | **参数化不可训练**（见 §4） |

## 4. CET 的七个缺陷（工程知识，任何递归模型都会遇到）

按发现顺序，每个都单独致命：

1. **注意力/证据头输出标量广播到基函数** → log 空间常数偏移 → softmax 抹掉，等于零效果。任何"用基函数做 log-LR"的实现必查。
2. **赌注/门控初值为 0** → `d(loss)/d(score) ≡ 0` → 永久死锁。
3. **`clip(gate, 0, 1)` 是吸收态** → 撞到 0 后梯度为 0，永不恢复（实测 ep2 起冻结，永远预测 125）。
4. **高斯倾斜 `−z²` 在远端达 −4e4** → softmax 饱和、其余 bin 梯度为 0 → 一个 epoch 内 16.7→113。必须用 Student-t 之类重尾。
5. **信念建在 RUL 上并逐步平移** → 宽先验平移 N 次后尾巴流进低 R 区（实测 `q[:6]≈0.017`、sd 35，而均值几乎正确）。**必须建在绝对失效时间 T 上，存活条件化=截断而非平移**。
6. **`to_rul` 把 `age+R` 截到末 bin** → 数百个 R 混叠到同一 bin → 均值钉在水平线。
7. **观测模型读 `e[:,t]`（已含 y_t）** → ŷ≈y → **创新恒为 0**。必须用 `e[:,t−1]` 做一步预测。

修完 7 个之后仍失败的原因（结构性，非 bug）：`gate` 恒等 0.1345（std 1.5e-8），输入时间反转后预测只变 2e-5。**信念只通过 `gate × tilt` 依赖证据；gate≈0 ⇒ 证据通路无梯度 ⇒ direction 被 weight decay 压到 0 ⇒ score 恒 0 ⇒ gate 永不上升。** 常数下限不携带信息。全 BPTT 在 300+ 步被裁剪吃掉；截断 BPTT 反而删掉唯一能推动信念的梯度。

## 5. 评价口径：最容易犯的错（踩过的）

1. **不要用 capped 真值算 NLL/CRPS**（早期样本真值全是 125，分布退化为点质量，会奖励 σ→0）。要么只用 RUL<cap 的区间，要么在 cap 处用**右删失似然**。
2. **不要在发动机真实失效周期评估**——那里 RUL≡0，恒预测 0 就得 0 分。必须用**截断协议**（项目用 `build_windows_matched`，seed 2026）。
3. C-MAPSS 测试集的 RUL 是**已知的**，不是删失；训练集是全观测 run-to-failure，所以 survival 方法在标准 C-MAPSS 上没有删失优势，差异只来自参数化。
4. 只报边际覆盖会掩盖"早期 0.70、晚期 0.99"。要按 RUL 分箱 × 工况分层。
5. 校准集/测试集必须**按发动机划分**，重叠窗口随机划分会泄漏。
6. 覆盖率要和**区间宽度**一起报（Winkler / MPIW），否则奖励无信息区间。
7. 文献 CRPS 参考范围（C-MAPSS，单位=周期）：**6.6–10.1**；95% 覆盖 0.81–0.95。CRPS<5 要怀疑泄漏，>15 多半分布过宽。

## 6. 建议的新方向（我的判断，可以推翻）

**不要再尝试"递归一个高维分布"。** 四条线的共同失败模式是：机制在理论上漂亮，但在 300+ 步的递推上梯度不可用。

三个更可能成立的方向，按我的推荐排序：

### A. 紧凑递归状态 + 分布解码（最稳）
递归对象从 600-bin 分布换成 **8–16 维状态**，每步用新息更新；分布由状态**解码**（discrete-hazard 或 Weibull 头）。梯度路径从 300 步缩到常数级，生存语义保留在解码器里。
- 可检验的机制主张：把"新息更新"换成"直接拼接特征"，在**单通道异常注入**和**前缀一致性**上应出现可测差异。
- 风险：审稿人会说这就是 WTTE-RNN + 一个门。**必须找到真正不同的算子**。

### B. 换赛道：从"改模型"转向"改训练信号"
C-MAPSS 的标签是 `min(RUL,125)`，而真实寿命已知。训练目标换成**真实失效时间 + 删失似然**，并系统研究"标签定义如何改变模型排序"（已有 E22a 的证据：FD002 全集与保留集上 PE 领先幅度从 0.50 变 5.15）。这是测量学论文，TIM 对口，且不需要新网络。

### C. 在已有强模型上做"可证明的增量"
接受 A 模型为骨干，只改一个能被定理刻画的部分（例如：把 e-value 做成 anytime-valid 的**在线失效检测**，给出误报率 ≤α 的保证，并证明它对应某个决策规则）。这比"新算子"窄，但可证。
