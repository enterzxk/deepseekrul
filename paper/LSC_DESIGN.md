## 2. 核心机制与原创性边界

**核心算子（唯一创新主张）**：相位条件化相对注意力偏置。设 Λ̂ 为由前缀预测的寿命
尺度（对数正态：Λ̂=exp μ̂，不确定度 σ̂），注意力 logits 加性偏置

$$B_{ij}^{(h)} = \phi_h\!\left(\frac{t_i - t_j}{\hat\Lambda},\ \hat\sigma\right),$$

其中 φ_h 是逐头小 MLP，作用于**相位坐标** τ_ij=Δt_ij/Λ̂ 而非原始 Δt_ij。
科学假设：不同寿命尺度的退化过程在相位坐标下形状自相似；同一 Δt=20 对
T≈130 的发动机是"余生的六分之一"，对 T≈350 只是"二十分之一"——用 Λ̂ 归一化
让注意力按退化相位而非绝对时间组织证据，直接打击已测得的短寿命高估。
Λ̂ 由一个廉价的因果尺度头产生（见 §3），整个链路可微、只访问当前与历史观测。

**与已有工作的区别（2026-11-02 检索，两轮）**：

| 最近邻 | 机制 | 与本算子的区别 |
|---|---|---|
| Shaw et al. 相对位置偏置 | B=f(Δt)，固定坐标 | 本算子坐标是 Δt/Λ̂，随发动机状态改变 |
| WTE-Trans (RESS 2024) | 按信号幅值加权时间嵌入 | 权重来自输入幅值，不是预测寿命尺度 |
| soft-cluster prior attention (SciRep 2026) | 按工况簇条件化注意力 | 条件是工况，不是退化相位 |
| ADAPT-RULNet / AKDTW | DTW 把测试轨迹对齐到参考轨迹 | 两两序列对齐，离线相似度；本算子在网络内部逐前缀自条件 |
| 深度生存分析 | 输出层分布假设 | 不改变注意力内的时间交互结构 |

**明确不算创新、不得写进贡献的**：单调 HI（softplus 累加，物理约束而已）、
对数正态/离散生存读出（deep survival 已有）、τ 作为输入通道（乘性时间嵌入，
已有等价物——因此必须作为消融臂 A3 而不是主张）。

## 3. 架构

```
x_t (21→14 通道) --OCS 条件归一化--> z_t
z_{1:c} --GRU 尺度头(小, d=32)--> (μ̂, σ̂)，Λ̂=exp(μ̂)          [pass 0]
z_{1:c}, u_{1:c} --线性投影--> e_t (d=64) + 绝对位置嵌入
     --2× Transformer 层，注意力 logits += B_ij (§2)-->
h_c --均值+方差头--> RUL 分布（高斯 NLL）；Λ 头损失独立计数     [pass 1]
```

- 窗口 40、d=64、2 层、4 头、FFN 128；参数预算 12 万 ±2%（与 B 线 TCN 同预算，
  宽度自动微调达标）。
- 训练损失：高斯 NLL（RUL）+ 对数正态截断 NLL（Λ 头，只在训练引擎上，
  T 为 train 文件内该发动机的真实完整寿命；条件 T>c 截断按交接文件 §二执行）。
- 单调状态 h_t=h_{t−1}+softplus(g_t)：实现为可消融结构开关，不进贡献列表。

## 6. GO / NO-GO（预注册，实验后不得修改）

- **机制 GO**：F−B2（去掉相位偏置换标准相对偏置）在 ≥2 个机队的开发折上
  RMSE 上升 ≥1.0 且发动机聚类 bootstrap CI 不含 0；且 B4（随机 Λ̂）劣于 F——
  两者同时成立才算机制成立。
- **精度 GO**：F 在开发折上优于 B1 与 TCN；官方测试一次性运行后 FD002
  RMSE 进入 13 以内（公开最好约 12–13）。
- **NO-GO 1**：F−B2 ≈ F 或 B4 ≈ F → 机制主张死亡；若只有 Λ 头的多任务监督
  在起作用（B3 就能拿到大部分增益），定性为多任务学习，不是架构贡献。
- **NO-GO 2**：F 逊于 B1 → 整线终止，如实记录。
- 任何一条 NO-GO 触发：保留全部失败实验，记录后终止本线，不做叙事抢救。

## 8. 实现追记（2026-11-02，按时间顺序）

1. **rmse_last 是伪指标**：训练集发动机全部运行到失效，末窗 RUL 恒为 0，
   预测 0 即可得低误差。开发集评价改为全窗口 RMSE + 寿命四分位分层 +
   固定年龄（c∈{50,100,125}）诊断，与阶段 1 闸门同口径。
2. **Λ 头 clamp 切断梯度**：初版在 ScaleHead 输出上 clamp(log50, log500)，
   初始 μ=0 在区间外，梯度恒为零，头部冻结（pooled corr=0）。clamp 只允许
   出现在偏置路径（Λ̂ 进入注意力前），损失路径用原始 μ。
3. **尺度头输入改为长历史**：40 行窗口撑不起寿命识别（闸门：corr 随前缀
   长度 0.27→0.93）。尺度头改吃近 200 循环、步长 4 的降采样历史（50 行），
   并先单独预热 25 epoch（所有臂同一流程）再联合训练。
4. **参照系**：闸门 HGB 的 pooled corr——age 0.222 / age+ops 0.161 /
   **sensor 0.732**。GRU 尺度头当前 0.41–0.48，显著好于 age-only，距 HGB 尚有
   差距；改进尺度头是合法的共享基础设施工作（所有臂同享）。
5. **偏置 tanh 限幅**：加性注意力偏置通路（连标准相对偏置 rel 都）在无界
   输出下训练不稳；偏置输出改为 tanh 有界。
6. 新增 `both` 臂：coords=[Δt, Δt/Λ̂, log σ̂]，检验"相位坐标是否需要在
   Δdt 之外的增量信息"。
7. 参数预算：尺度头 d=64 后全体 ~130.6k，FFN 296→256 回到 ~120k。

## 9. 小矩阵结果（FD002，4 臂 × 3 折，种子 2027，2026-11-03）

参数匹配 120k（各臂差 <0.3%），同骨干/同折/同预热流程；Λ 头为共享基础设施，
各臂质量一致（pooled corr 0.27–0.42，MAE ≈ 40 循环）。RMSE 为开发折全窗口。

| 臂 | RMSE(all) | sd | MAE@c100 | bias@c100 |
|---|---:|---:|---:|---:|
| `plain`（B1，无相对偏置） | 13.96 | 0.29 | 27.72 | −10.13 |
| `rel`（B2，标准 Δt 偏置） | **13.87** | 0.17 | 28.17 | −9.89 |
| `both`（Δt, Δt/Λ̂, logσ̂） | 14.75 | 0.27 | 28.59 | −11.46 |
| `full`（F，Δt + Δt/Λ̂） | 15.32 | 0.92 | 29.24 | −10.30 |

配对引擎聚类 bootstrap（MSE 单位，95% CI）：

- `full` vs `plain`: dMSE +40.4 CI [+19.5, +62.2] —— F 显著更差
- `full` vs `rel`:   dMSE +43.6 CI [+22.5, +66.3] —— F 显著更差

**读数**：

1. 相位臂在每一个固定年龄（c=50/100/125）上都更差，伤害是全局的，不是某段寿命的分层假象。
2. 短寿命高估（q0 bias +13.1）没有被相位坐标修正（full 13.9 vs plain 13.1），机制预定的靶点没有命中。
3. `rel`≈`plain`：标准相对偏置是中性的；伤害特定于 Λ̂ 条件化，不是加性偏置通路本身。
4. 待决诊断：`oracle`（真 T，机制上界）与 `rand`（打乱 Λ̂，噪声对照）正在运行。
   - oracle ≈ plain → 机制死刑（NO-GO 1），如实记录；
   - oracle ≫ plain → 瓶颈在 Λ 头质量（corr 0.41 vs 闸门 HGB 0.732），改进尺度头后重测 F；
   - rand ≈ full → 伤害来自噪声注入本身，Λ 头改进的收益上限存疑。

### 9.1 诊断臂判决（oracle / rand，2026-11-03）

| 臂 | RMSE(all) | sd | q0 RMSE/bias | 判读 |
|---|---:|---:|---:|---|
| `oracle`（真 T） | **10.12** | 0.38 | 11.21/+0.91 | 机制上限巨大：−3.8 vs plain |
| `plain` | 13.96 | 0.29 | 19.62/+13.07 | 基线 |
| `rand`（打乱 Λ̂） | 14.03 | 0.11 | 19.72/+13.56 | ≈ plain：噪声注入无害 |
| `full`（学习 Λ̂） | 15.32 | 0.92 | 20.77/+13.93 | 比 rand 还差（CI [+18.9,+60.0]） |

**三个事实**：

1. **机制有巨大 headroom**（oracle 10.12 vs plain 13.96，dMSE CI [+116,+173]）。
   寿命尺度条件化在 Λ̂ 正确时是本线最有力的增益来源。
2. **机制预定靶点被命中**：短寿命高估 q0 bias 从 +13.1 降到 **+0.9**——
   oracle 条件化几乎消除了 R3 审计指出的核心系统性偏差。
3. **学习的 Λ̂ 比随机噪声更有害**（full 15.32 vs rand 14.03，CI [+18.9,+60.0]）。
   这不是噪声问题（rand 无害），而是**协同优化污染**：偏置路径的梯度回流让尺度头
   可以学成"对注意力有利"而非"对寿命诚实"的估计，产生误导性结构。

**由此产生的可检验假设**：切断偏置路径梯度（`--detach_lam`），Λ̂ 只由寿命 NLL 训练。
若 full+detach 显著改善（→ plain 以下），协同优化假设成立；改善幅度距 oracle 的
差距则度量 Λ 头质量瓶颈。attn 池化尺度头（`--scale_head attn`）作为头部升级同步测试。

### 9.2 detach 判决（2026-11-03，full+det × 3 折）

| 臂 | RMSE(all) | sd | q0 RMSE/bias | vs full+det 的 dMSE CI |
|---|---:|---:|---:|---|
| `full`（无 detach） | 15.32 | 0.92 | 20.77/+13.93 | +18.2 [+7.3, +30.3]（full 更差） |
| `full+det` | **14.73** | 0.10 | 20.09/+13.39 | — |
| `plain` | 13.96 | 0.29 | 19.62/+13.07 | +22.2 [+5.7, +38.7]（full+det 更差） |
| `rand` | 14.03 | 0.11 | 19.72/+13.56 | +20.9 [+4.3, +36.9]（full+det 更差） |
| `oracle` | 10.12 | 0.38 | 11.21/+0.91 | +125.3 [+102.5, +148.9] |

**判决**：

1. **协同优化污染假设成立**：detach 使 full 臂 RMSE 15.32→14.73，dMSE −18.2
   CI [−30.3, −7.3]，显著改善。梯度回流确实把 Λ 头拖向"对注意力有利"。
2. **但 detach 不够**：full+det 仍显著差于 plain（+22.2）与 rand（+20.9）。
   排除协同优化后，预测 Λ̂（corr 0.36）注入的尺度特征仍是净伤害——
   Λ 头质量本身是瓶颈，而非仅训练耦合。
3. **oracle 的 q0 偏差修正（+0.9）在所有学习 Λ̂ 臂中均未兑现**（≈+13.4）。
   上限与现实的差距完全归因于 Λ̂ 精度。

**下一步**：`--scale_head attn`（attn 池化尺度头）18 任务队列已启动，
目标是把 lam_corr 从 0.36 提升到接近闸门 HGB 的 0.73，再检验 full+det 是否兑现收益。

### 9.3 hgb 臂预注册（2026-11-03，写入于跑之前）

attn 池化头早期结果已判决失败（plain+attn 两折 lam_corr 0.053 / −0.008，≈0，
远差于 GRU 头的 0.31；单 query 软注意力把 40 行轨迹累积信息均匀池化掉，
LayerNorm 又抹掉行间幅度差）。Λ̂ 质量瓶颈的出路不在头部结构，在信息来源：
阶段 1 闸门已证明 HGB（引擎工况 + 运营统计，corr 0.73）能从可观测特征读出寿命。

**hgb 臂定义**：Λ̂ 来自闸门 HGB 的 5 折 OOF 预测
（每机组恰属一折的测试集 → 对任何下游使用无泄漏），按窗口年龄对
(c ∈ {50..200} → 预测) 曲线做分段线性插值，边界常数外推。偏置路径与
`full` 臂完全相同（coords = [Δt, Δt/Λ̂]），Λ̂ 为外部常量（天然 detach）。
冒烟确认插值后 Λ̂-寿命 corr = 0.81（train/val 一致）。

**预注册判据（跑之前冻结）**：
1. 主：hgb 的 RMSE(all) 相对 plain 的 dMSE 引擎聚类 bootstrap CI 排除 0 且为负
   （hgb 更好）→ 机制可用性闭环（可部署的 Λ̂ 来源兑现 oracle 方向收益）。
2. 主：hgb 相对 full+det 的 dMSE CI 排除 0 且为负 → Λ̂ 质量（0.81 vs 0.36）
   是 full 臂失败的根因这一解释成立。
3. 参考（非判据）：hgb 与 oracle 的差距度量"Λ̂ 剩余误差"的代价。
