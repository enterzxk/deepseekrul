45: ## 4. Fair ablation design
46: 
47: ### 4.1 Parameter matching
48: 
49: - The w/o SSM LSTM control must be within +/-3% of the Full Model parameter
50:   count. The matched hidden width and any output projection must be recorded
51:   in config.json.
52: - Parameter counts are checked automatically before training.
53: 
54: ### 4.2 Graph topology controls
55: 
56: AdaptiveSpatialBranch supports graph_mode:
57: 
58: - learnable: A = (1 - alpha) I + alpha * softmax(ReLU(E1 E2^T)),
59:   alpha initialized to 0.1 and learned.
60: - identity: A = I.
61: - random_fixed: a fixed, row-stochastic random matrix stored as a buffer.
62: 
63: The identity-graph control distinguishes graph propagation from extra
64: parameters. The random-fixed control checks whether any fixed mixing is
65: sufficient.
66: 
67: ### 4.3 Final P3 variants
68: 
69: 1. Full Model: learnable graph + SSM + full physics loss.
70: 2. w/o A-GCN: independent per-sensor branch + SSM + full physics loss.
71: 3. Identity-Graph: A = I + SSM + full physics loss.
72: 4. w/o SSM: learnable graph + parameter-matched LSTM + full physics loss.
73: 5. w/o Physics Loss: learnable graph + SSM + pure MSE.
74: 6. w/o Mono Loss: learnable graph + SSM + MSE + asymmetric term only.

76: ## 5. Metrics and gates
77: 
78: Main metrics:
79: 
80: - RMSE (clip125)
81: - NASA asymmetric score (clip125)
82: - MAE
83: - Mean signed error (positive = late prediction)
84: - Late_Fraction: fraction of samples with y_pred > y_true

86: - Mono_Violation_Rate: fraction of valid adjacent trajectory pairs with

95: variance. Final results must report all five seeds, mean, standard deviation,

98: ## 6. Physics loss protocol
99: 
100: The production loss supports four pre-registered variants:
101: 
102: 1. Loss-MSE: pure MSE.
103: 2. Loss-Asym: MSE + asymmetric late-penalty.
104: 3. Loss-Mono: MSE + trajectory monotonic penalty.
105: 4. Loss-Full: MSE + asymmetric + monotonic.
106: 
107: The total objective is:
108: 
109: L = MSE + lambda_asym * L_Asym + lambda_mono * L_Mono
110: 
111: with L_Asym using weight 2.0 for late errors and 1.0 for early errors.
112: gamma/late_weight, lambda_asym, and lambda_mono are selected on validation
113: only. The trajectory for L_Mono is the per-cycle RUL trajectory returned by
114: return_trajectory=True. If no trajectory is supplied, L_Mono is exactly zero
115: and monotonic_available is recorded as 0.
