# PREREG R2-C：可观测历史是否补足局部窗口

- 登记时间（UTC）：2026-10-22T03:09:50.826Z
- 状态：先登记后计算；本文件写入时实验尚未运行
- 预算：外层 CPU 拟合 **恰好 30 次**（2 个模型类 × 3 个视图 × 5 折），无网格、无内层选择

## 1. 数据与隔离
- 来源：仅 FD001 / FD002 的**训练**文件（既有 dev 池）。
- 不读取：FD003 / FD004 任何文件；官方 test / RUL 文件一律不读。
- 不做新切分：沿用现有 dev 池的发动机，5 折按发动机划分，同一发动机所有截断同折。

## 2. 截断规则（事先固定，不依赖 T）
- 绝对周期集合 C = {60, 100, 140}。
- 发动机 u 在截断 c 上有观测当且仅当 T_u > c；无观测则记录为缺失，不插补、不按列表位置匹配。
- 该规则本身不使用 T；但“是否纳入”仍由 T 决定，此点如实记录（不可完全避免）。
- Protocol B（寿命比例）只作附属回顾性诊断，不进入主判据。

## 3. 三个信息视图（定义先固定）
- **V0**：截至 t=c 的最后 50 个周期的传感器读数（14 通道）。
- **V1**：V0 + 可观测的 cycle=t + 3 个 operational settings + 工况簇编号（用既有 OperatingConditionScaler 的可观测输出）。
- **V2**：V1 + **仅截至 t 的前缀摘要**：
  - 每传感器在 [t−50, t] 与 [t−100, t]（若历史足够）上的线性斜率；
  - 每传感器在 [t−100, t] 上的一阶差分标准差；
  - 截至 t 的各工况簇暴露计数占比。

**已披露的重叠**：原候选模型本身已启用 use_ema_features=True（窗口内 EMA）。因此 V2 的“趋势”部分与模型既有 EMA 有部分重叠，V2 的增益不能全部归因于“新增历史”。

## 4. 模型类与超参（预固定）
- 岭回归：标准化后 α = 10。
- RBF 核岭回归：γ = 0.005，α = 1.0（取此前核实验网格的中位点，非按本轮结果挑选）。
- 所有标准化、核矩阵、缺失处理**全部在折内训练集上拟合**。

## 5. 标签与特征合法性
- 标签：合法训练期 RUL，主 cap = 125。
- 在线特征不含：真实 T、未来观测、由未来估计的工况统计、验证标签。

## 6. 输出
- 每 (视图, 模型, 折) 的逐发动机配对预测（显式键：dataset, engine, cutoff, view, model, fold）。
- pooled / macro RMSE、NASA 分数、late_fraction、severe-late（RUL≤30 且误差>0）。
- V2−V1 的发动机级聚类 bootstrap 95% 区间（配对，同发动机同截断）。

## 7. 判据（事先固定）
- **支持**：V2−V1 的 95% 区间整体为负（RMSE 改善），且两个模型类方向一致。
- **不支持/证据不足**：区间跨 0，或两个模型类方向相反。
- 任一情形都不表述为“信息存在/不存在”，只表述为“该前缀表示是否提取到稳定预测力”。
- 即使支持，也只能表述为“新增历史信息带来收益”，不得直接称方法创新。

## 8. 停止条件
- 30 次外层拟合完成即停止；不因结果不佳更换摘要、不换 seed、不追加模型类。
