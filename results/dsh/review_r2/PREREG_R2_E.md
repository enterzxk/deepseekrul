# PREREG R2-E：用**窗口之前**的历史能否改进当前 RUL（路线 1 的可区分前提检验）

- 时间（UTC）：2026-10-22T03:30:31.763Z
- 背景：`PREREG_R2_D` 的检验已判 VOID（同一窗口内 h 与 μ 代数近恒等）。本登记修正该缺陷：
  **自变量取自窗口之前的历史**，与因变量所用窗口**不相交**。
- 预算：外层 CPU 拟合 **10 次**（2 规格 × 5 折）。零训练预算，不训练神经网络。
- 数据：仅 FD001/FD002 **训练**文件；不读 FD003/FD004、不读官方 test/RUL。

## 构造（固定）
- 截断 c ∈ {100, 140}（需 c ≥ 100 才能切出两段不重叠、各 50 周期的窗口）。
- 窗口 A = [c−100, c−50)（**仅过去**）；窗口 B = [c−50, c)。
- 先用每个传感器在**该发动机前 20 周期**的均值/SD 标准化（只用过去信息），再算：
  - `mu_prior` = 窗口 A 上跨传感器平均标准化信号的线性斜率；
  - `sd_prior` = 窗口 A 上同一信号的一阶差分标准差；
  - `lvl_cur` = 窗口 B 末端水平；`slope_cur` = 窗口 B 斜率；`sd_cur` = 窗口 B 差分标准差。
- 标签：RUL = min(T−c, 125)（合法训练期标签）。

## 两个规格（唯一差别是是否加入“过去”信息）
- **S1（当前窗口）**：特征 = 每传感器 window-B 的 mean/sd/last/slope（14×4）+ cycle。
- **S2（当前 + 过去）**：S1 + `mu_prior` + `sd_prior`（共 +2 维）。
- 模型：岭回归，α = 10，标准化在**折内**拟合。
- 两规格用**完全相同**的折划分与相同的特征工程，唯一差别是 2 个过去特征。

## 判据
- 配对（同发动机、同截断）发动机级 bootstrap 2000 次，比较 S2−S1 的 RMSE 差。
- **支持**：区间整体为负。**不支持/证据不足**：区间跨 0。
- 若支持，仅说明“过去窗口的漂移信息对当前 RUL 有增量预测力”，**不是方法创新**，也**不替代**与强基线的比较。

## 停止条件
- 10 次拟合完成即止；不改特征、不换 α、不加模型类。
