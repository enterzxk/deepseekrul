# 可辨识性分析：个体读数何时更可信？（负结果，2026-11-05）

本文件记录"观测证据能否预测个体读数的可靠性"这一问题的全部检验。
所有数值由 `evidence_gate.py`、`evidence_engine.py`、`agree_gate.py`、
`sensitivity_gate.py` 生成，数据为完整预算外层验证 FD002 第 0–3 折（32,865 窗口，
208 台发动机），种子 101。

## 1. 问题

若个体读数（窗口模型 M0）与总体参考（年龄+工况先验 OPS）的误差可由某个可观测量
预测，就可以构造逐观测的自适应修正，逼近逐窗口 oracle。逐窗口 oracle 在 FD002
上为 10.97，而最佳固定融合为 12.89、最佳单臂 FULL 为 13.07——存在 15% 的空间。

## 2. 已检验的可观测量与结果

| 可观测量 | 层级 | 与 `|e_M0|−|e_OPS|` 的相关 | 与"个体更好"的 Spearman |
|---|---|---:|---:|
| 相对早期参考态的偏差 deviation | 窗口 | +0.023 | −0.014 |
| 抖动 jitter | 窗口 | −0.019 | +0.006 |
| 早期参考稳定性 spread | 窗口 | +0.016 | −0.010 |
| 趋势噪声比 DENR | 窗口 | −0.007 | +0.013 |
| 观测年龄 end_cycle | 窗口 | −0.002 | −0.005 |
| deviation / jitter / DENR / 寿命 | 发动机 | 见 evidence_engine | \|ρ\|<0.05 |
| 跨模型分歧 \|M0−OPS\| | 窗口 | −0.073 | — |
| 跨模型分歧 \|M0−FULL\| | 窗口 | +0.041 | — |
| 跨模型分歧 \|OPS−FULL\| | 窗口 | −0.060 | — |

全部 \|ρ\| < 0.08。

## 3. 门控的实测效果（FD002，4 折）

| 方案 | RMSE |
|---|---:|
| M0（个体读数） | 13.489 |
| OPS（总体参考） | 13.387 |
| FULL（先验注入） | 13.065 |
| 固定 0.5 融合 M0+OPS | 12.890 |
| deviation 四分位门控 | 13.136 |
| DENR 四分位门控 | 13.030 |
| jitter 四分位门控 | 13.098 |
| 年龄门控（c≥75/100/125/150 用 OPS） | 13.45–13.52 |
| 分歧门控（\|M0−OPS\|>5/10/15/20 用 OPS） | 13.43–13.62 |
| 逐窗口 oracle（不可实现） | 10.971 |

结论：任何基于可观测量的门控都劣于固定融合；自适应修正不可辨识。

## 4. 一个例外：灵敏度系数预测误差**大小**

对输入窗口施加 σ=0.05/0.10/0.20 的观测噪声，重复 5 次，取预测标准差作为
GUM 意义上的灵敏度系数（sensitivity coefficient）。它与 \|e_M0\| 的相关为
0.37–0.39（Spearman 0.41），即**能预测个体读数的不确定度大小**；
但与"个体是否优于总体参考"的相关仅 0.002–0.023。

因此灵敏度系数可作为**逐观测的不确定度代理**（可用于报告测量不确定度），
但不能用于选择修正方向。基于它的门控（k=1/2/4）给出 13.03/13.13/13.23，
仍劣于固定融合 12.96（该折）。

## 5. 对论文的含义

1. "观测证据驱动个体修正"这一直观设计在本测量设置下不可实现；
2. 可辩护的做法是固定逆方差加权，并把灵敏度系数作为不确定度报告；
3. 若审稿人要求自适应方案，必须给出可观测量的预测能力证据——本项目给出了
   系统的负证据。
