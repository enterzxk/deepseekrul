## 0. 摘要

v2 的结论是「观测跨度调度 + 尾部保护」把 A 打通（−5.55%），但「加模块」全面失败（同宽度 +7.4%，加宽度 +21%，强正则 +42%）。

本计划书的判断是：**失败的原因不是调参，是有效样本量。** FD002 训练折有 33k 个窗口但只有 208 台发动机，窗口高度相关，有效样本量是 208。42k 参数已是每样本 200 参数，719k 是 3400 参数每样本——量级上不可辨识。

因此本阶段的路线是**用约束换自由度**，而不是用参数换表达力。五个方向中三个是零参数、一个近零参数，全部可干净消融。

### 1.2 失败的数学诊断

**诊断一：有效样本量 208。** 同一发动机的窗口共享轨迹，相关性接近 1。参数/有效样本比：42k/208 ≈ 200，719k/208 ≈ 3400。任何以参数换表达力的改动都会被方差吞掉。

**诊断二：均值池化是正确的归纳偏置。** 给定退化状态，窗口内 50 个位置近似可交换，此时样本均值是充分统计量、零参数、方差最小。注意力池化放弃可交换性假设，在 208 个有效样本下学到的权重是噪声。这是同宽度 +7.4% 的主因。

**诊断三：冻结配方放大容量代价。** 协议固定 80 轮、取末轮、无轮次选择。大模型在第 20 轮进入过拟合区，第 80 轮是过拟合最深处。**「不许早停」让容量的边际代价单调上升**，所以 42k 不是碰巧合适，是该约束下的正确选择。

**诊断四：训练损失与评测泛函失配。** 训练用 $e^2 + 0.5\cdot1.8\,e^2_{e>0}$（线性非对称），评测用 $\exp(e/10)-1$（指数）。失配恰好发生在尾部——这解释了为什么 RMSE 降了而 NASA 崩了。

## 2. 研究假设

**H1**：RUL 的瓶颈不是表达力，是缺失的物理与统计约束。把约束注入训练，可以在不增加参数的前提下降低方差、压缩误差尾部。

**H2**：NASA 尾部崩塌的本质是误差分布的尾部没有被约束，任何只优化均值的代理损失都会留下这个尾部。

**H3**：在 208 个有效样本下，零参数改动（约束、重参数化、正则）的期望收益高于任何参数增量。

可证伪点：若 A/B/C/D 四个零参数方向在 2 折筛选中均无正向增益，则 H1–H3 被否定，届时如实记录并回到 v2 的结果。

## 3. 五个方向

### A. 轨迹单调性约束（零参数，训练期）

**动机**：RUL 沿轨迹单调不增，且每前进 Δ 循环必须恰好下降 Δ。当前模型逐窗口独立预测，完全不知道这条约束。

**与已排除的 isotonic 的区别**：isotonic 是推理期后处理，用了未来窗口（泄漏）；本方向把约束放进**训练损失**，约束从训练集的窗口对学出，推理时逐窗口独立预测，不触碰未来数据。

**损失**：

$$\mathcal{L} = \mathcal{L}_{\text{task}} + \lambda_1 \mathbb{E}_{t<t'}\left[\max(0, f(x_{t'}) - f(x_t))^2\right] + \lambda_2 \mathbb{E}\left[\mathbb{1}\{f(x_t)>125\}\left(f(x_t)-f(x_{t'})-\Delta\right)^2\right]$$

- 第一项：只惩罚「RUL 上升」，永远非法，无需标签。
- 第二项：在未截断区（$f>125$）强制斜率 −1；截断区差值为 0，不适用。
- 配对方式：同发动机、时间差 Δ ∈ {10, 20, 30}，训练时随机采样。

**预期**：直接压缩尾部。单台高估 96 循环在单调约束下必须由整条轨迹解释，不可能凭空跳上去。

**消融**：λ1=0（关闭）、λ1>0 且 λ2=0（只单调）、λ1,λ2>0（完整）、λ 扫描 {0.1, 0.5, 1.0}。

### B. 度量匹配损失（零参数）

**动机**：训练是线性非对称，评测是指数。

**做法**：加高阶分位数损失，压上尾而不爆炸：

$$\mathcal{L}_{\text{tail}} = \rho_{\tau}(e) = \max(\tau e,\ (\tau-1)e), \quad \tau = 0.9$$

$$\mathcal{L} = \mathcal{L}_{\text{task}} + \lambda_3 \mathcal{L}_{\text{tail}}$$

**为什么不直接优化 $\exp$**：指数损失梯度无界，在 $e>50$ 时爆炸，训练不稳定。pinball 在高分位线性增长，可控。

**消融**：τ ∈ {0.5, 0.75, 0.9}，λ3 ∈ {0, 0.1, 0.5}。

### C. 输出重参数化：预测寿命而非 RUL（零参数）

**动机**：$\text{RUL}(t) = \min(125, L - t)$ 在 $t = L-125$ 处有拐点，且早期窗口大量标为 125，模型学不到 $L$ 的信息。

**做法**：网络输出 $\hat{L}$，RUL 由公式解析导出：

$$\hat{\text{RUL}}(t) = \min(125,\ \hat{L} - t)$$

损失按 $\mathbb{1}\{L-t<125\}$ 加权——只在 RUL 未截断的区间监督 $L$，正好是信息量足够的区间。

**预期**：目标在发动机内平稳，拐点由公式精确处理，不进入训练。

**风险**：早期窗口的 $L$ 不可辨识；加权后有效样本进一步减少。若 2 折无增益则放弃。

**消融**：全窗监督 vs 加权监督。

### D. 发动机级正则化（零参数）

**动机**：有效样本量是 208，应在发动机层面做方差缩减。

**D1 Engine-level mixup**：

$$\tilde{x} = \lambda x_i + (1-\lambda) x_j,\quad \tilde{y} = \lambda y_i + (1-\lambda) y_j,\quad \lambda \sim \text{Beta}(\alpha,\alpha)$$

$i,j$ 是不同发动机。等价于在发动机分布上做线性插值，直接对抗 208 个样本的约束。

**D2 随机效应收缩**：$y_{ij} = f(x_{ij}) + b_i$，$b_i \sim \mathcal{N}(0,\sigma^2)$。当前「早期参考」是 $b_i$ 的粗糙代理，无概率结构。

**消融**：α ∈ {0.2, 0.4}，D1 开/关。

### E. 跨传感器混合（196 参数）

**动机**：通道独立设计丢掉了传感器间的联合结构。

**做法**：每个位置加一个 14×14 混合：

$$h' = h + W h,\quad W \in \mathbb{R}^{14\times14}$$

**消融**：W 固定为 0（等价于现状）、可学习、参数匹配的随机固定 W。
