## 1. 口径（最重要）

项目里存在两套不可混用的口径：

| 口径 | 定义 | 用途 |
|---|---|---|
| **A** | 官方 test 发动机，每台取末窗口，目标 = RUL_FDxxx.txt 封顶 125 | **论文主表唯一可用口径** |
| **B** | 5 折外层验证，训练发动机的全部窗口 | **只能进消融表** |

同一模型在两套口径下 FD002 差约 1.2（A 11.51 vs B 12.75）。混用即作废。

## 2. 数据划分

- 5 折发动机互斥，`split_seed = 7`，划分由 `np.random.default_rng(7 + 20261020).permutation(units)` 决定。
- fold f 取该置换的第 f 个连续块作为验证集，块大小 `max(1, round(0.2 * n_units))`。
- **划分种子与模型种子分离**：划分固定 7，模型种子 101/202/303。
- 任何引擎不得同时出现在训练与验证。

## 3. 预处理

- 传感器：`OperatingConditionScaler(cols, n_clusters=6, random_state=split_seed)`，**只在训练折上 fit**。
- 工况聚类：`KMeans(n_clusters=6, random_state=split_seed, n_init=10)`，只在训练折上 fit。
- 健康参考：`ref = n/(n+2) * xbar_early + 2/(n+2) * pop_ref[cluster]`，`n` = 该工况簇内前 30 周期内的早期样本数（≤5）。
- `pop_ref` 由训练折中 cycle ≤ 15 的样本按簇求均值。
- **官方 test 的 scaler 与 kmeans 一律来自训练折，禁止在 test 上重拟合。**

## 4. 训练

| 项 | 值 |
|---|---|
| 优化器 | AdamW |
| 学习率 | 1e-3 |
| 权重衰减 | 1e-4 |
| 调度 | CosineAnnealingLR, T_max = epochs, eta_min = 1e-5 |
| 批大小 | 256 |
| 梯度裁剪 | 1.0 |
| 最多轮次 | 80 |
| **早停** | **patience 20，按 val_rmse（clip125）存最佳 epoch** |
| dropout | 0.2 |

**早停是相对 V3 冻结协议的唯一改动**，理由：mixup 在冻结协议 −1.4~−3.8%、在早停协议 +2.3%，符号翻转说明冻结协议系统性惩罚容量。

## 5. 损失

```
L = MSE(clip125) + 0.5 * asym(1.8, e)
  + 0.5 * (L_A + L_B) / 2        # 逐流监督
asym(w, e) = w * e^2 if e > 0 else e^2
e = pred - true
```

- **不加单调项**（V3 已证 +4.3%）。
- **不加 mixup**（V4 已证在早停协议下 +1.6%）。

## 6. 评估

- 主指标：RMSE（clip125）。辅：MAE、NASA 评分、bias。
- 区间：**发动机聚类配对 bootstrap，5000 次**，重采样单元 = 发动机（不是 engine×seed）。
- 多种子：报告均值 ± sd，**sd 必须与效应量并列**。
- 集成与单模型**分表报告**。
