## 2. 核心方法

**观测跨度调度 + 预注册尾部保护。**

**发现**：50 循环窗口是文献惯例，不是数据要求。FD002 fold 2，同一批晚窗（年龄 ≥100）：w50 = 11.030、w100 = 7.503；年龄 ≥150：w50 7.035 / w100 5.089 / w150 4.972。

**调度**：t < 100 用 50 循环模型、t ≥ 100 用 100 循环模型，两者都按冻结预算训练（80 轮、全部窗口、固定末轮、无轮次选择）。

**尾部保护**（`PROTOCOL.md` §8.8，先写后算）：当 |pred_w100 − pred_w50| > 50 循环时回退到 pred_w50。

## 6. 负结果：结构化主干无效

用户要求增加模块。实现了 `DeepBody`（并行 k=3/5/7 多尺度时序卷积 + 额外 Transformer 层 + 注意力池化），结果全部退化：

| 配置 | 参数量 | FD002 f2 M0 | 变化 |
|---|---:|---:|---:|
| 基线 d64/1 层 | 42,306 | 13.732 | — |
| **C3 d64/1 层 + 仅模块** | **116,483** | **14.753** | **+7.4%** |
| C1 d96/1 层 + 模块 + 强正则 | 257,667 | 16.605 | +20.9% |
| 深模型 d128/2 层 + 模块 | 719,107 | 16.620 | +21.0% |
| C2 d128/2 层 + 模块 + 更强正则 | 719,107 | 19.546 | +42.4% |

FULL 臂同样退化：12.751 → 15.928（+24.9%）。

**结论**：模块本身有害（同宽度 +7.4%），宽度再叠加伤害。41k 训练窗口撑不起这个复杂度；注意力池化在 50 个位置上自由加权学到的是噪声。

**未做**：数据增强。时间优先给了尾部保护，后者直接解决了 A 的四指标条款。
