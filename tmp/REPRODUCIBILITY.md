# 可复现性与初始化噪声（重要披露，2026-11-05 21:10）

## 1. 发现

在 `run_full_fold.py` / `run_full_fold2.py` / `run_full_fold3.py` 中，模型是在
`ida.set_seed(seed)` **之前**构建的：

```python
net = build_arm(arm)      # 消耗当前 torch RNG 状态
ida.set_seed(seed)        # 之后才重置
net = net.cuda()
```

而 `main()` 在第一个臂之前没有调用 `set_seed`，PyTorch 默认 RNG 在进程启动时由
非确定性源初始化。因此：

1. **同一命令重跑不会得到完全相同的结果**（初始化不同）；
2. **同一 run 内不同臂的初始化不同**（后一个臂继承前一个臂训练后的 RNG 状态）；
3. 差异不是浮点级：FD002 fold 2 的 M0 在两次运行中分别为 13.73 与 13.31
   （约 3%），与本研究要检验的效应量同量级。

## 2. 影响评估

| 影响 | 说明 |
|---|---|
| 单种子比较的精度 | 每次运行是一个随机抽取；bootstrap 区间只覆盖发动机抽样，不覆盖初始化/训练噪声 |
| 3 种子均值 | 部分平均掉该噪声；协议本身要求 3 种子，因此主结论以 3 种子均值为准 |
| 机制淘汰结论 | NORM +7.7%、PHASE +28% 的效应远大于 3% 的噪声，淘汰结论稳健 |
| FULL vs M0（3.5%） | 与噪声同量级，**必须用 3 种子判断**；FD002 的 202/303 种子正在运行 |
| 可复算 | 精确复现需要在同一进程内按同一臂顺序运行；`queue*.sh` 与 `tasks*.txt` 记录了顺序 |

## 3. 修正

后续运行应改为：

```python
ida.set_seed(seed)
net = build_arm(arm)
net = net.cuda()
```

本研究已完成的运行**不重跑**（成本与时间不允许，且重跑会改变全部数字）；改为：
1. 在论文与交付中明确披露该噪声；
2. 主结论只用 3 种子均值或远大于噪声的效应；
3. 把本文件与 `PROTOCOL.md` §8 一起交付。

## 4. 对结论的影响（诚实评估）

- **A 判定不变**：没有任何机制候选在单种子下达到 +3%，3 种子均值只会更保守。
- **FULL 相对 M0 的 3.5% 优势需要重新评估**：若 3 种子均值下该优势缩小到噪声内，
  则连"既有方法有效"这一前提也需要修正。这将进一步支持本项目的核心结论——
  在本测量设置下，个体化带来的收益处于噪声量级。
- **测量学结论（可观测性、可辨识性、端点依赖）不受影响**：它们不依赖 3% 量级的
  差异，而依赖 0.26→0.92 的相关性变化、|ρ|<0.08 的零相关、以及端点间的排序反转。
