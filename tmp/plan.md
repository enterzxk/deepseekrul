# 从"更大"到"更有结构"：四项可消融的领域创新 + 持续学习机制

## 1. 目标与成功标准

把 42k 单层主干换成**结构化深层主干**，每个新增模块都是领域特定的创新、且天然对应一个消融。持续学习作为其中的机制来源。

**完成标准**（全部满足才算完成）：
1. 新主干在 FD002 + FD004 各 5 折上跑完 w50 与 w100 两臂；
2. 每个模块都有对应的"关掉它"的消融结果，且方向可解释；
3. 相对**同骨干 w50 基线**的主效应 ≥3%，且四指标不劣于该基线；
4. 相对**历史锁定参考**（42k 的 13.054 / 13.253）的结果一并报告；
5. 全部产物进 `assemble_delivery.sh`，`MANIFEST` 与官方复算保持一致。

## 2. 现状与关键证据

刚完成的容量探针给出一个**反例**，它决定了整个方案的方向：

| 模型 | FD002 fold 2 M0 RMSE |
|---|---:|
| 42k（d=64, 1 层） | **13.732** |
| 719k（d=128, 2 层 + 多尺度卷积 + 额外层 + 注意力池化） | **16.620（+21%）** |

**结论：这个基准上容量不是瓶颈，41k 训练窗口撑不起 719k 参数。** 继续加大只会更差。

所以方案不是"把模型做大"，而是**加有归纳偏置的结构 + 加正则**，并且每个结构必须能被消融证明有用。

## 3. 设计原则

1. **每个模块必须带归纳偏置**，不是单纯加参数；
2. **每个模块必须可关掉**，关掉就是消融；
3. **参数量对齐**：每个模块配一个参数匹配的对照（如共享适配器 vs 条件隔离适配器）；
4. **训练配方不动**：80 轮、全部窗口、固定末轮、无轮次选择。只有模块明确要求的项（如损失项）才改，且权重写死进协议。

## 4. 持续学习如何映射到 RUL 测量

| 持续学习概念 | RUL 测量中的对应 |
|---|---|
| 任务序列 | 同一发动机轨迹上依次到达的窗口 |
| 灾难性遗忘 | 新窗口的证据覆盖早期证据，估计沿轨迹跳变 |
| 经验回放 | 保留早期窗口作为一致性锚点 |
| 弹性权重巩固（EWC） | 对早期证据重要的参数/表示加弹性惩罚 |
| **参数隔离** | **按工况簇分配独立适配器**（FD002/FD004 的 6 个工况是定义特征） |
| 测试时适应 | 用发动机自身无标签历史更新参考态 |

这套映射不是类比，而是可实现的：工况簇在推理时已知（终端窗口的工况），发动机早期历史无标签可得。

## 5. 四个模块

### I1 多尺度时序卷积（已实现）

并行 k=3/5/7 卷积 + 门控融合，捕捉短/中/长三种退化模式。
- 消融：换成单尺度 k=3
- 参数匹配对照：单尺度但加宽通道

### I2 工况自适应 FiLM（领域特定）

`γ, β = MLP(cond)`，对编码器特征做仿射调制。6 个工况簇是 FD002/FD004 的定义特征，联合训练会让稀有工况欠拟合。
- 消融：去掉 FiLM（cond 只作为输入拼接）

### I3 工况隔离适配器（持续学习：参数隔离）

每个工况簇一个瓶颈适配器（`d → d/4 → d`），加在池化表示上，按终端工况选择。
- 消融 a：无适配器
- 消融 b：**共享适配器**（参数匹配对照，验证"隔离"本身是否有用）
- 消融 c：隔离但无瓶颈（参数更多）

### I4 弹性参考适应（持续学习：测试时适应 + 弹性锚定）

推理时按时间顺序处理窗口，用发动机自身历史更新参考态，并向总体参考做弹性锚定：
`ref_t = (1-λ)·ref_pop + λ·ref_engine,t`，λ 由证据量决定（与现有证据计数机制一致）。
- 消融：λ=0（冻结参考）、λ=1（完全自适应）、固定 λ
- **这一项直接针对 FD004 的 NASA 尾部崩塌**：灾难性高估来自参考态漂移

### 外层机制：观测跨度调度（已验证）

t < 100 用 w50 模型、t ≥ 100 用 w100 模型。作为测量层贡献保留。
